# 论文速读：When-Is-Tracking-Affordable-A-Movement-Budget-Feasibility-Th

## 一句话总结
本文首次研究了在线凸优化中硬移动预算对动态遗憾的影响，证明了存在一个以 $D + P_T$ 为关键尺度的可行性阈值：当总移动预算 $S$ 不足时，即使环境平稳度允许无界情况下的次线性学习，硬预算也会导致线性遗憾；而当 $S$ 超过阈值时，预算自适应的投影 OGD 可实现次线性动态遗憾。

## 研究问题与动机
- **核心问题**：在在线学习中，learner 的决策移动受到硬预算 $S = \sum_t \|x_t - x_{t-1}\| \leq S$ 限制时，何时能够实现次线性动态遗憾 $R_d = o(GDT)$？
- **现有不足**：经典动态遗憾理论假设 learner 可自由移动，仅用比较器路径长度 $P_T$ 刻画难度；但在实际时序系统（如控制器重配置、投资组合再平衡）中，每次调整消耗有限资源，硬预算约束被长期忽略。
- **关键洞察**：$P_T$ 本身不足以衡量预算限制下的学习难度（如随机游走比较器路径长但空间集中，无需大幅移动即可适应），真正决定可行性的是比较器迫使 learner 穿越的“范围（range）”。
- **研究空白**：针对动态遗憾的硬距离预算可行性阈值此前无人研究，相关文献多聚焦静态遗憾或软惩罚形式。

## 核心贡献（创新点）
1. **提出移动预算可行性阈值定理**：证明当 $S \leq c P_T$ 时，任意预算可行算法都会遭遇确定性对抗策略迫使 $R_d = \Omega(GDT)$，揭示了预算而非环境波动导致的学习不可行性。与已有工作的本质区别：首次将动态遗憾的可行性归因于硬移动预算，而非比较器路径长度。
2. **设计预算自适应的投影 OGD**：通过选取 $\eta = \min(\sqrt{D(D+2P_T)/(G^2T)}, S/(GT))$ 在满足 $\mathrm{SC} \leq S$ 的同时实现 $R_d = o(GDT)$。与已有工作的本质区别：不引入新的优化器，而是通过步长设计直接嵌入预算约束，给出上界匹配的构造性证明。
3. **建立预算依赖上界并明确开放问题**：给出 $R_d = O(\min\{G\sqrt{D(D+2P_T)T} + \frac{GTD(D+2P_T)}{S},\ GDT\})$，明确阈值以上的已知上界与未知下界之间的 gap。与已有工作的本质区别：明确区分“可行性门槛”与“阈值上方的精细速率刻画”，不宣称乘积律成立。
4. **提供严格对抗构造与多维度实验验证**：使用全量程方波（square-wave）确定性对手证明下界，并在五个真实时间序列上验证过渡位置与 $1/S$ 衰减。与已有工作的本质区别：将“预测能力”与“干预成本”解耦，证明即使比较器完全可知，物理/操作层面的移动预算仍会构成硬性障碍。

## 方法详解
- **问题设定**：决策集 $\mathcal{K} \subset \mathbb{R}^d$ 直径为 $D$，每轮损失 $f_t$ 为凸且 G-Lipschitz。比较器路径长度 $P_T = \sum_{t\geq 2} \|u_t - u_{t-1}\|$，动态遗憾 $R_d = \sum_t [f_t(x_t) - f_t(u_t)]$，切换代价 $\mathrm{SC} = \sum_t \|x_t - x_{t-1}\|$。要求算法满足 $\mathrm{SC} \leq S$。
- **可行性阈值（Theorem 1）**：
  - **不可能性**：对任意 $P_T \in [D, DT]$，存在确定性方波比较器（在 $[0,D]$ 端点间交替，块长度 $\tau = \lfloor T/(n+1)\rfloor$，$n = \lfloor P_T/D \rfloor$），使得任意 $\mathrm{SC} \leq S$ 的算法满足 $R_d \geq c_0 GDT(1 - c_1 S/P_T)$。当 $S \leq c P_T$ 时遗憾为线性。证明基于块配对计数：每对块内 learner 的移动量 $M_i$ 受限，累积跟踪误差下界为 $\tau(D - M_i)$，求和并代入 $\sum M_i \leq S$ 即得。
