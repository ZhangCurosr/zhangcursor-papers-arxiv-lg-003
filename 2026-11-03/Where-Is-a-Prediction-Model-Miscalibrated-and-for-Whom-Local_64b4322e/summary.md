# 论文速读：Where-Is-a-Prediction-Model-Miscalibrated-and-for-Whom-Local

## 一句话总结
本文提出一种基于“结果学习口袋（Outcome-Learned Pockets）”的本地化审计框架，仅需特征、结果与黑盒预测值即可运作，通过随机森林相似性与岭回归加权聚类冻结分组地图，结合集群鲁棒联合置信区间，精准定位预测模型在哪些相似样本集中系统性偏差（where），以及在该集合内不同人口统计学群体间是否存在预测误差差异（for whom）。

## 研究问题与动机
1. 整体校准度与AUC等排序指标会掩盖局部集中误差或正负相消的系统性偏差，无法回答模型在哪些特征-结果相似子群中失真、对哪类人群失真。
2. 现有切片发现方法多针对单一模型的残差进行分组，导致所发现的子群高度依赖被审计模型本身，难以跨模型复用。
3. 群体级公平性审计无法区分“某群体集中分布在普遍失准口袋”与“同口袋内不同群体间误差存在差异”两类机制，干预策略可能错位。
4. 多子群审计面临三大实战挑战：搜索空间爆炸不可行、子群数据/正例不足易产生误报、同单元重复观测（如同一医院患者）非独立导致传统推断失效。

## 核心贡献（创新点）
1. **可复用的结果学习审计地图**：口袋仅在探索样本上从结果中学习并冻结，审计阶段只需特征与预测值，无需模型内部信息，同一地图可同时比对多个黑盒模型。
2. **统计证据而非单纯告警**：引入允许组内观测相关性的集群鲁棒联合置信区间，配合显式支撑规则，不仅报告显著误差，还输出“已排除的误差量级”与“数据不足无法测试的口袋”。
3. **误差定位优于现有分组基线**：在17个模拟场景中联合审计以$F_1$提升0.17–0.35击败最强替代分组（15/17场），在12/15个局部失准场景中比所有可用替代方法更优定位误差，且掩码抵消设计下整体检验几乎无信号而本方法能捕获。
4. **三大部署级模型审计应用**：揭示care-management算法隐藏的正负抵消局部误差及种族/性别双重偏差机制，定位APACHE IVa在ICU的已知高估口袋，以及胸片分类器在特定投照视角下的抵消误差。

## 方法详解
- **数据角色三分离**：整体单元按固定种子划分为开发集（40%，拟合待审模型）、探索集（30%，从结果学习口袋地图并冻结分配规则）、审计集（30%，仅读取预测误差与组间差异，绝不参与地图构建）。
- **双路径口袋构建**：
  1. *随机森林相似性口袋（$C_F$）*：在探索集训练预测目标的RF（200棵树，每叶≥20观测，分裂候选特征$\sqrt{p}$），以共现叶节点数定义相似度，构建互惠近邻图（约30条边），采用嵌套度校正随机块模型（SBM）检测社区，按最小描述长度选层，再以更严格的支撑规则投影选最优层级。
  2. *岭回归加权线性口袋（$C_R$）*：特征中位数填补并标准化后乘以岭回归系数绝对值（逻辑回归/线性回归视结果类型而定），K-means聚类且口袋数与森林图对齐，专门捕获沿单一强线性预测器的误差。
  3. *冻结分配与弃权*：审计观测通过计算与各口袋平均亲和度分配；若最高亲和度或领先优势低于校准集第1百分位则弃权，弃权观测计入总体统计。
- **估计目标**：口袋$c$的局部校准误差 $\mu_c = \mathbb{E}[f(X)-Y|C=c]$，局部校准缺口 $\delta_c = \mathbb{E}[f(X)-Y|C=c,S=1] - \mathbb{E}[f(X)-Y|C=c,S=0]$（$S=1$为焦点组，$S=0$为参考组）。
- **支撑规则（Support Rule）**：仅当细胞满足≥100观测（连续≥50）、二元结果期望事件/非事件≥10、有效聚类数≥15且单聚类占比≤20%时纳入检验；不满足者仅报告为“无法测试”。
- **联合推断**：基于Mammen两点权重的集群野Bootstrap（$B=4,999$）生成零分布，取绝对值最大标准化估计量分位数作为临界值$q$，构造一步法Max-$t$联合置信区间；罕见二元结果对标准误设下界防止虚假精确。两地图联合时各用$\alpha/2$水平，Bonferroni保证总体错误率≤$\gamma$。

## 实验与结果
- **模拟设计**：17个“for whom”场景（连续/二元结果、非线性风险、掩码抵消、缺失值、医院单元依赖、真实WiDS/糖尿病协变量）与15个“where”场景（全局植入误差）。对比基线包括K-means、Mahalanobis K-means、风险分箱、CEM/CEM top-3、基于残差的离散差异目标分组及误差导向分组。
- **主要结果（For Whom）**：联合审计在17个场景中15个以$F_1$提升0.17–0.35胜出；森林单图赢14场，Ridge单图在强线性特征上更优，两者互补驱动联合设计。
- **主要结果（Where）**：在15个场景中12个（较小误差幅度0.2 SD或5点）以$F_1$击败所有可用替代方法；掩码设计（整体误差近零）中联合审计$F_1$达0.45–0.62，整体检验仅0.7%误报。在误差落在无关特征或U型单尾时略逊于残差导向分组。
- **误差控制**：$\delta$审计在独立与依赖单元下假阳性率均≤5%（校准水平）；$\mu$审计在150个强依赖单元下单图水平需收紧至0.0025以达标（当前0.0125下约9.1%）。
- **真实应用**：
  1. *Care-management算法（Obermeyer合成数据）*：健康映射分数整体误差不显著（$\mu=-0.003$），但森林口袋显示最病重口袋低估0.78个慢病条件，其他口袋高估0.19–0.72；Ridge口袋捕获极端低估（预测4.3 vs 实际7.7）。Black-White缺口整体-0.65，且在高血压口袋内仍存-0.61缺口，证明集中分布与口袋内差异并存。
  2. *APACHE IVa（WiDS 2020，91,713次ICU住院）*：整体高估2.9%；树切口袋在通气患者口袋（+4.3%）与低风险口袋（+3.0%，预测5.
