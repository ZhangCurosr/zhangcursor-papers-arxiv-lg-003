# 论文速读：When-Does-Adaptive-Halting-Win-Selection-Rules-Matter-in-Looped-Language-Models

## 一句话总结
论文在冻结的 Ouro-1.4B 循环语言模型上，通过预注册的密封测试证明：哪种自适应暂停方法表现更优取决于所选的操作点选择规则，而非方法本身；训练的稳定探针在 Bootstrap 筛选规则下优于原生门控，但与无训练的 KL 散度读出来表现相当，且在分布外基准上会违反精度预算。

## 研究问题与动机
1. **选择规则的隐性影响**：现有比较每种暂停方法时都将其简化为单一操作点，由某种选择规则（如目标精度或精度损失预算）决定，但该规则本身对比较结果的影响未被系统研究。
2. **训练探针的实际价值**：在冻结模型上附加训练好的探针（π1-x），相比 Ouro 原生门控和无训练的轨迹读出来，能否在节省计算的同时保持精度。
3. **分布外泛化能力**：在开发数据上选择的策略，能否在未见过的分布外基准上保持预定的精度预算。
4. **评估严谨性需求**：通过预注册和密封测试设计，避免数据窥探，提供因果可信的结论。

## 核心贡献（创新点）
1. **预注册密封测试评估**：首次在冻结循环 LM 上对暂停信号进行预注册、密封测试评估，展示两种预注册选择规则（点规则 vs. Bootstrap 筛选规则）导致相反的偏好顺序。
2. **训练探针价值有限**：证明训练探针相对于无训练收敛读出来（r-kl）未显示出显著优势，且训练探针在分布外基准（Social IQa）上存在精度预算违反（损失 3.26 pp）。
3. **评估方法论建议**：提出六条评估暂停方法的具体建议，核心是将每次比较视为信号与选择过程的比较，并强调报告操作点、包含强无训练基线、进行分布外检查等。
4. **规则依赖性实证**：揭示选择规则对结果的决定性影响：在 Bootstrap 筛选规则下 π1-x 优于原生门控（+0.053 宏观节省），在点规则下原生门控优于 π1-x（−0.022），且点规则下的操作点多数违反 1 pp 预算。

## 方法详解
1. **模型与设置**：使用冻结的 Ouro-1.4B 模型（bf16 精度，4 个循环），所有权重不变。每个基准为多项选择题，采用 packed scoring 进行单个前向传播。
2. **暂停信号**：
   - **Native gate (native-pb)**：基于 Ouro 原生门控的累积分布函数（CDF）作为统计量。
   - **Learned probe (π1-x)**：每个循环一个 L2 正则逻辑回归分类器，输入 9 个特征（置信度、熵、CDF 等），预测稳定性标签（后续循环答案不再变化的概率）。
   - **Untrained readouts (r-*)**：包括 r-conf、r-margin、r-ent、r-kl（连续循环答案分布的 KL 散度）、r-dlogit、r-hl2、r-hcos。
3. **选择规则**：
   - **Point-only rule**：候选操作点的点估计精度损失 ≤ 1 pp。
   - **Bootstrap-screened rule**：点估计损失 ≤ 1 pp 且单侧 95% Bootstrap 上界 ≤ 1 pp（2,000 次重采样）。
4. **评估方式**：从存储的全深度轨迹中 retrospectively 评估，而非实际截断执行。节省量为模拟值（基于循环数估算），探针开销单独测量。
5. **净节省计算**：扣除探针额外开销（ρ_score 和 ρ_rest），以单次循环时间为单位。

## 实验与结果
1. **数据集**：密封测试集共 8,517 个问题，包含三个主要基准（OpenBookQA 3,000、CommonsenseQA 1,000、HellaSwag 750）和两个分布外基准（PIQA 1,837、Social IQa 1,930）。
2. **主要结果（Bootstrap 筛选规则）**：
   - π1-x 比 native-pb 节省更多循环：+0.053 宏观节省，95% CI [+0.049, +0.057]，验证通过。
   - 净节省（扣除探针开销）：+0.038 [​+0.033, +0.042]。
3. **次要结果（点规则）**：
   - 原生门控优于 π1-x：−0.022 [​−0.026, −0.018]。
   - 但点规则下的操作点多数违反 1 pp 预算（5/6 benchmark-method 单元格）。
4. **与无训练基线比较**：
   - π1-x 与 r-kl 表现相当：+0.00125 [​−0.0041, +0.0065]。
   - r-kl 是所有无训练读出来中表现最强的（宏观节省 0.238）。
5. **分布外结果**：
   - 在 Social IQa 上，π1-x 精度损失 3.26 pp（上界 4.72 pp），违反预算。
   - 原生门控在两个分布外基准上均保持预算内。

## 相关工作脉络
1. **ACT / PonderNet**：早期学习暂停的 RNN 方法，添加 sigmoid 暂停单元或条件暂停分布。本文不训练骨干网络，探针仅附加在冻结模型上。
2. **Ouro 原生门控**：本文主要比较基线，通过线性头输出每循环退出概率。本文 adaptation 为单问题决策，而非释放实现的每 token 决策。
3. **Popescu et al. (2026)**：首次系统比较 Ouro 门控与后验轨迹读出来，发现读出来可匹敌或超越门控。本文在其基础上引入选择规则变量和预注册评估。
4. **Geiping et al. (2025)**：基于连续步骤 KL 散度的收敛退出机制。本文的 r-kl 类似但应用于答案选项分布而非词汇分布。
5. **CALM / Fast yet Safe**：带正式风险控制的早期退出方法（Learn then Test、UCB 界）。本文 Bootstrap 筛选规则无此类保证。
6. **PABEE**：基于耐心的层早期退出，连续层分类器一致则退出。本文稳定性标签设计受其启发。

## 局限性与未来方向
1. **模型与设置限制**：仅在一个模型（Ouro-1.4B）、4 个循环、多项选择评分上测试，未扩展到生成任务或更大模型。
2. **评估方式局限**：节省量为模拟值（基于存储轨迹），非实际墙钟时间测量；探针开销单独测量，未计入端到端延迟。
3. **无正式风险保证**：Bootstrap 筛选规则为启发式方法，无有限样本保证，且存在选择偏差。
4. **数值路径问题**：bf16 精度下不同 GPU 执行存在数值差异，虽不影响决策但影响可重复性评估。
5. **未来方向**：正式风险控制选择（LTT/CRC/UCB）、分布外 guards、Ouro-2.6B 扩展、截断执行的端到端延迟评估、新密封测试集验证。

## 研究启发与可借鉴点
1. **选择规则敏感性**：任何算法比较都应系统测试不同选择规则下的结果，单一操作点可能掩盖重要差异。
2. **预注册与密封测试**：为评估研究提供高严谨性范式，有效避免 data snooping 和 p-hacking。
3. **无训练基线的重要性**：在声称新方法有价值前，应与简单无训练基线充分比较，避免过度拟合。
4. **分布外检查必要性**：开发数据上表现良好的策略可能在分布外失败，必须包含 OOD 评估。
5. **节省量定义透明化**：明确区分循环节省、FLOPs 节省、墙钟时间节省，并说明评估方式（实际执行 vs. 轨迹回放）。

## 关键术语表
**Adaptive Halting**：循环语言模型根据输入难度动态决定迭代次数，以平衡计算效率与性能。
**Ouro**：带学习退出门控的循环语言模型，通过累积退出概率决定何时停止迭代。
**π1-x probe**：附加在冻结模型上的逻辑回归分类器，预测答案稳定性以指导暂停决策。
**Bootstrap-screened rule**：结合点估计和 Bootstrap 上界的阈值选择规则，要求两者均满足精度预算。
**r-kl**：基于连续循环答案分布 KL 散度的无训练退出规则，衡量分布变化程度。
**Gross/Net Saving**：粗节省指循环数减少比例，净节省扣除探针额外计算开销。
**Sealed Test Set**：预注册研究中预先固定且不可更改的测试数据集，确保评估 unbiased。
**Stability Label**：训练探针的监督信号，表示后续循环答案是否保持不变。
