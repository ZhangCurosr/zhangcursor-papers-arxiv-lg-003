# 论文速读：ViAdminShift-A-Vietnamese-Benchmark-for-Event-Level-Knowledg

## 一句话总结
本文提出了 **ViAdminShift**，一个基于越南 2025 年行政区划改革事件的越南语基准测试，用于评估大型语言模型（LLMs）在事件级别知识更新上的表现；研究发现即使模型知晓改革，在无时间线索提示时仍普遍默认使用旧地图，且将日期置于问题中比置于系统提示中更能有效触发新知识。

## 研究问题与动机
- **现实更新多为事件驱动**：现有基准常采样孤立的事实变更（如球员转会、官员更替），而真实世界的知识更新往往以单一事件引发大量事实同步变更（如本次行政改革将 63 个省合并为 34 个、废除所有区级政府），需评估模型能否将事件级更新推广至所有相关事实。
- **低资源语言缺乏事件级基准**：多数时间知识基准集中于英语，越南语因行政名称特殊（无空格分词、名称重复、声调变体、无重音书写普遍）难以直接翻译，需专用资源与评分器。
- **模型可能“知道却不用”**：模型参数中可能已包含新地图，但未在被问及时主动使用，即存在 **时间默认（temporal default）** 现象，需设计能分离“知识缺失”与“默认惰性”的评估方法。
- **日期提示位置影响未系统研究**：现有工作对日期放在系统提示、问题中或工具中的效果结论不一，需在同一基准上控制变量对比。

## 核心贡献（创新点）
- **官方来源驱动的确定性基准**：基于越南国家统计办公室（NSO）官方转换表重建 10,566 对（旧乡，新乡）映射，而非依赖 LLM 生成或人工抽样，保证答案精确、可追溯。
- **内置 2×2 控制设计**：通过省是否合并（pc）和乡是否变更（wc）两个标志，将乡级项目分为四格，纯控制格（pc=0, wc=0）可分离过时答案与其他随机错误，提升因果推断能力。
- **成对预/后改革检索上下文**：为每个项目配对比对的前后维基百科修订或 dated templates，支持“混合段落”条件下评估模型处理冲突信息的能力。
- **越南语特有评分器与验证**：处理无重音匹配、声调变体统一、单位名称序列比较，并通过两名母语作者盲评验证（Cohen’s κ = 0.91 / 0.89）。
- **揭示时间默认现象与提示工程启示**：发现 14/20 知晓者无提示时仅 11% 以下答案为新省份，而日期在问题中（“截至 X 年 X 月”）比在系统提示中更能彻底消除过时答案。

## 方法详解
- **数据来源与 canonical tables**：以 NSO 的官方旧→新转换表为核心，交叉验证两个独立谱系（vietnamadminunits、undertheseanlp/address），解决分歧（以国会常委会决议为准），重建五张规范表（省、县、乡、映射对等）。
- **2×2 控制框架**：每个乡级项目标记 pc（旧省是否被合并）与 wc（乡本身是否变更），形成四格：纯控制（pc=0, wc=0）、仅省变（pc=1, wc=0）、仅乡变（pc=0, wc=1）、两者皆变（pc=1, wc=1）。纯控制格用于剔除非过时的其他错误。
- **七类项目（T0–T6）**：涵盖头条事实（T0）、反向归属（T6）、组成（T2）、成员资格（T1）、新名称存在性（T3）、地址转换（T4）、后继者（T5），共 7,995 项（5,320 道多选题 + 2,675 道简答题）。
- **检索上下文构建**：对每个省、县文章取最后一次改革前修订（2025-06-12 前）与第一次改革后修订（2025-07-15 后），节选最多 1,250 字符；无文章的乡则用 dated templates（引用具体决议）生成，共 2,281 个段落。
- **双轨道评估**：
  - **探测轨道（probing track）**：使用配对短答案集，仅在时间线索（无 / “截至 X 月” / “2025 年区划调整之后”）、日期位置（系统提示 / 问题内 / 更早对话轮次 / 工具调用）上差异，比较吸收格（旧省已合并）与保留格的表现。
  - **基准轨道（benchmark track）**：运行全部 7,995 项，分闭卷与检索（新/混合/仅旧段落），报告严格准确度、过时答案比例等。
- **评分规则**：
  - 探测轨道评分器：去除推理文本、剥离单位类型词（如“thành phố”）、Unicode NFC 标准化、全音节序列匹配，并设别名表；将答案分为严格正确（仅新名称）、过时（仅旧名称）、两者（按首名称计）、其他。
  - 基准轨道评分器：解析多选题字母、分段评分地址（三级地址视为过时）、按关系动词后首个片段或过去从句外名称打分。

## 实验与结果
- **数据集规模**：7,995 个项目（含 400 个无重音地址双胞胎）、2,281 个检索段落（1,002 维基百科摘录 + 1,279 模板）、10,566 对映射。
- **评估模型**：67 个模型（26 本地开源 1.7B–35B、41 API 包括 DeepSeek、Claude、GPT、Kimi 等），其中 20 个通过知识门（absorbed T1 在改革线索下严格准确度 ≥50%）。
- **核心发现**：
  - **时间默认普遍**：14/20 知晓者无提示时对吸收格仅给新省份的比例 ≤11%，旧省份-only 答案占 14–100%（图 5、6）。
  - **日期线索有效但位置关键**：改革线索（直接提及调整）可使 8 个知晓者达 100% 严格准确度；日期线索（不提调整）使 6 个知晓者达 100%。且日期在问题中（“截至 X 月”）比在系统提示中（“今天是 X 日”）更能降低过时答案（图 7）。
  - **小模型在混合段落中易过时**：7 个不知晓改革的小模型在相同来源新旧段落混合条件下，过时答案比例达 14–30%；5 个基准轨道知晓者仅 0–5%。
  - **2×2 控制验证误差来源**：小模型在纯控制格准确率 73–91%，但在省合并且乡变更格仅 0–1%（88–95% 答案为改革前），证明其错误主要来自过时而非随机。
- **最强表现**：Claude Sonnet 5.5 无提示严格准确度 51%，加日期线索新-first 达 96%；DeepSeek-V4.1-Flash 无推理时日期线索 gain +68 点（建立）。

## 相关工作脉络
- **EvolvingQA（Kim et al., 2024）**：同样存储旧答案并使用不变事实作控制，但由 GPT-3.5 自动编写问题，针对 T5 持续预训练而非部署 LLM 的提示行为，本文更贴近真实用户查询与事件级更新。
- **PTC benchmark（Hossain et al., 2026）**：测量参数时间冲突（旧职位得分高于新职位），但聚焦 Wikidata 职位变更的孤立事实，本文覆盖单一事件引发的数千事实同步变更，并提供内置控制。
- **FreshQA / WikiRecentChanges**：处理时间知识更新，但日期提示位置固定或仅一种变体，本文系统比较系统提示、问题内、更早轮次、工具四种放置方式。
- **VLegal-Bench（Nguyen et al., 2026）**：越南法律基准，报告“近期盲区”，但未围绕真实世界知识更新构建，也无成对检索上下文与 2×2 控制。
- **TimeQA / TempReason**：英语时间问答基准，依赖 Wikidata 和合成日期算术，本文采用越南语真实行政数据与官方来源，填补低资源语言空白。

## 局限性与未来方向
- **局限性**：
  1. **范围局限**：仅覆盖单一事件与单一语言，模板问题非自然用户查询，结论外推需谨慎。
  2. **数据时效**：黄金答案基于 2025-07-01 结构，未包含 2026 年单位类型变更（如 Đồng Nai 升格为直辖市）；部分划分乡、特殊经济区乡未充分覆盖。
  3. **知识门为行为定义**：无法验证模型训练数据实际截止期，部分知晓者可能仅见过报道而未深度吸收。
  4. **API 结果不可控**：提供商可能自动注入日期或改变模型版本，无-date 条件可能隐含提示。
  5. **评分器验证有限**：探测轨道评分器仅验证 200 个答案，基准轨道评分器未经独立验证。
- **未来方向**：
  1. 扩展至其他事件级更新（如政策调整、自然边界变更）与多语言。
  2. 探索微调或知识编辑技术是否能从根本上改变模型的默认行为，而非仅依赖提示。
  3. 研究更复杂的日期放置策略（如动态生成、多日期对比）以提升服务可靠性。

## 研究启发与可借鉴点
- **2×2 控制设计**：可迁移至其他事件级基准，通过标志位分离过时答案与其他错误，增强评估的因果解释力。
- **成对检索上下文构建**：预/后版本段落配对，可用于评估模型在冲突信息下的知识整合与冲突解决能力。
- **时间线索系统实验**：固定其他变量仅改变提示位置，为提示工程提供实证依据，适用于任何时间敏感任务。
- **低资源语言特有处理**：无重音匹配、声调变体统一、名称序列比较、单位类型剥离等策略，可应用于其他东南亚语言资源建设。
- **开源完整栈**：数据集、代码、评分器、datasheet 全部开源，促进可复现研究与后续迭代（如版本 2026-07-01 将重建）。

## 关键术语表
- **ViAdminShift**：基于越南 2025 年行政区划改革的越南语基准测试，包含 7,995 个项目与成对检索上下文。
- **时间默认（Temporal Default）**：模型参数中已包含新知识，但未提示时间线索时仍默认使用旧知识回答的现象。
- **2×2 控制设计**：通过省变更（pc）与乡变更（wc）标志将项目分四格，纯控制格（pc=0, wc=0）用于分离过时答案与其他误差。
- **知识门（Knowledge Gate）**：判断模型是否知晓改革的阈值（absorbed T1 在改革线索下严格准确度 ≥50%）。
- **旧答案（Outdated Answer）**：改革前正确但改革后已过时的答案，用于量化模型默认行为。
- **探测轨道（Probing Track）**：使用配对短答案集，系统比较不同时间线索与位置的效果。
- **基准轨道（Benchmark Track）**：运行全部 7,995 项，评估模型在闭卷与检索条件下的整体表现。
- **参数时间冲突（Parametric Temporal Conflict, PTC）**：模型内部旧知识得分高于可恢复的新知识的情况。
