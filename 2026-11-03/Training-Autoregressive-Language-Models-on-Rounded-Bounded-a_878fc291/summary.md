# 论文速读：Training-Autoregressive-Language-Models-on-Rounded-Bounded-a

## 一句话总结
本文提出 **boundary marginalization（边界边际化）**，首次让预训练自回归语言模型通过现有数字 token 对舍入区间、单边界和删失观测计算**精确事件似然**，无需辅助输出头、插补目标或采样 rollout；实验在受控分布恢复、真实药物安全数据（hERG）和代码延迟数据集（KBSS）上均显著优于完整样本 CE 和插补 CE。

## 研究问题与动机
- 数值标签常以**不完整形式**出现：测量值被舍入到某精度（如 1.2 代表 [1.15, 1.25)），实验室报告仅给出上下界（如 IC50 > c），程序在超时 c 时未完成任务（Y > c）——这类报告在 cardiac-safety 数据中约占三分之一。
- 标准序列交叉熵要求单一精确目标数，现有做法要么**丢弃**这些删失/区间报告，要么**插补**为区间中点代表值，导致信息浪费或引入偏差。
- 自回归 LM 已通过数字 token 定义了数值分布，但对一个包含数千个数的区间，逐个枚举计算概率不可行。
- 核心问题：**如何在已有数字 token 上高效计算数值区间（及更一般的数值事件）的精确似然及其梯度？**

## 核心贡献（创新点）
- **Boundary marginalization 算法**：仅需至多两条长度 $d = \log_b M$ 的 teacher-forced 边界路径，以 $O(b \log_b M)$ 标量运算计算区间对数概率，避免枚举任意数量的兼容数值。与现有工作的本质区别在于：以前方法要么丢弃不完整标签，要么需要独立的连续混合密度头；本文直接利用 LM 原有数字 token 计算精确事件似然。
- **单一损失统一多种观测类型**：一个事件似然目标同时处理精确标签（退化为序列 CE）、舍入区间和单边界（删失），各类型可在同一 mini-batch 中混合训练；与插补 CE 的本质区别是后者学习代表值的分布而非观测事件的概率约束。
- **精确分布查询与 CRPS 训练**：相同计算框架直接支持尾概率/分位数查询，以及无偏阈值采样 CRPS 梯度，无需生成模型输出 rollout。

## 方法详解
- **有序固定宽度数值分布**：将输出支撑集设为 $M = b^d$ 个有序网格值，每个网格索引 $k$ 编码为 $d$ 位基数 $b$ 的字符串（高位优先）。LM 在第 $j$ 位使用 softmax over $b$ 个数字 token 输出条件概率 $p_\theta(a \mid x, s)$，完整数位的概率为各位置条件概率之积（式 3）。
- **观测建模为兼容集合**：将每种观测类型（精确值、闭区间、舍入区间、严格下界/上界）转换为网格索引区间 $[l, u]$（Table 1），训练目标为事件似然 $\mathcal{L}_{\text{event}} = -\log\sum_{k \in [l,u]} p_\theta(k \mid x)$（式 4）。
- **边界路径 CDF/Survival 计算**：对阈值 $k$ 的数字串 $z$，inclusive CDF $F_\theta(k) = \sum_{j=1}^d P_\theta(z_{<j})\sum_{a<z_j} p_\theta(a \mid x, z_{<j}) + p_\theta(k \mid x)$（式 7），survival $S_\theta(k)$ 同理（式 8）；两者均只需沿一条 teacher-forced 路径的 $d$ 个条件分布，在单次前向传播中获得。
- **稳定区间对数概率（LogSumExp）**：为避免浮点 CDF 相消，将区间分解为边界数值加若干前缀子树的 disjoint union（图 1），以 log-prefix-mass 形式求和（式 10-11），用 LSE 实现数值稳定。
- **梯度解析（Proposition 2）**：对前缀 $s$ 的第 $j$ 位 logits，梯度为 $w_s[p_\theta(a|x,s) - t_s(a)]$，其中 $w_s$ 是该前缀在条件事件下的后验概率。子树完全在区间内或外的节点梯度为零，**仅边界跨越节点接收非零局部梯度**，保证了精确且稀疏的梯度流。
- **CRPS 训练（Section 5.4）**：对精确标签，CRPS 通过独立采样阈值并加权估计，其梯度经链式法则回传到共享 LM 参数，是无偏估计（Proposition 4）。

## 实验与结果
- **受控分布恢复**（输入均匀 [-1,1]，条件双分量高斯混合截断到 [-2,2]）：随精确标签比例 $\rho$ 降低，事件似然明显优于完整样本 CE 和插补 CE。$\rho = 0.1$ 时 ISE 6.993 vs 15.923（CE）vs 29.156（插补），相对完整样本 CE 降低 56.1%；$\rho = 0$（仅舍入+界）时 ISE 6.801 vs 插补 34.121，降低 80.1%。
- **hERG 心脏安全数据**（ChEMBL 37，14,850 条 IC50，29.8% 训练为左界/右界，36.2% 测试为界）：事件似然 NLL 4.675，优于完整样本 CE 5.083（改善 0.408 nats）；删失报告 NLL 0.823 vs 2.076（**降低 60.3%**）。
- **KBSS 代码延迟**（Triton GPU kernel，45.2% 训练超时删失）：物理 CRPS $8.262 \times 10^{-3}$ ms，较完整样本 CE 降低 6.8%；log₁₀(ms) CRPS 0.0878，降低 10.5%。预算 Brier score 0.1281 vs 0.1550。
- **Qwen3-4B-Base 跨骨干验证**：物理/log CRPS 分别改善 5.3%/11.5%，与 Qwen2.5 结果一致。
- **精确标签上的 CRPS vs CE**：阈值采样 CRPS（$m=2$）仅比序列 CE 高 1.5%，验证了同一框架的统一性。
- **精度扩展**：$d$ 从 2 增至 6（$10^2 \to 10^6$ 支撑），更新时间和峰值内存几乎不变（0.87–0.89s / 11.2–11.3 GiB，256 prompt tokens），比 dense per-value 输出节省 43–68% 内存。

## 相关工作脉络
- **LLMTime / Decoding-based regression**：前者对数字序列建模为分层数值分布，后者研究序列化回归训练——本文与它们的区别是不构造独立数值解码头，直接利用预训练 LM 已有的数字 token 计算事件似然。
- **Regression-aware fine-tuning (RAFT)**：对枚举候选值的期望进行平方损失微分——本文避免枚举，直接计算区间概率及其梯度。
- **Number Token Loss / NTIL / DEL / SMMD**：在 token 级别施加数值距离损失——本文不构造点估计目标，而是对完整观测事件分配概率。
- **Coarsened data / Censored likelihood heads**（Heitjan & Rubin; Svensson et al.）：前者形式化删失数据似然理论，后者为分子预测设计独立删失似然头——本文直接微调 LM 数字分布，无需额外输出头。
- **Hierarchical softmax / PATH**：基于有序分箱的层次 softmax——本文用边界边际化代替构造 leaf 分布，支持任意区间而非仅相邻分箱。

## 局限性与未来方向
- **有限网格假设**：输出支撑集固定为 $M$ 个网格值，无法表达超出声明范围的值。
- **条件可忽略报告假设**：事件似然的统计解释要求 $q(A|k,x) = c(A,x)\mathbf{1}\{k \in A\}$；非可忽略报告机制（如报告概率依赖于真实值本身）需要建模报告过程。
- **尾部识别不确定性**：当 $\rho = 0$ 时，控制实验中舍入和阈值设计导致部分尾部网格概率不可识别。
- **经验范围有限**：hERG 删失报告的尾部不可观测；KBSS 使用合成超时作为代理；仅测试了两个 Qwen backbone，未覆盖大尺度 seed 变异性。
- **未来方向**：扩展到非可忽略删失机制；探索更灵活的网格（如对数等比网格已支持多数量级）；将方法推广至非整数数值场景。

## 研究启发与可借鉴点
- **边界路径分解技巧**：将区间概率分解为沿端点前缀的子树概率之和（log-domain LSE），这一计算范式可迁移到任意有序分类/数值输出的区间概率评估任务。
- **"仅在边界节点有梯度"的稀疏监督性质**：对于宽区间，内部前缀子树的梯度自然为零，模型仅在区间边界处学习；这一特性可用于设计高效的**区间感知正则化**。
- **CRPS 通过阈值采样的无偏估计**：无需 rollout 即可获得分布评分的梯度，可与任何自回归模型的分布训练结合，尤其适合**需要校准概率预测**的科学计算场景。
- **统一多类型数值标签的 single-objective 设计**：舍入、界、精确值共存于同一 loss，对真实世界多源异构标签（医疗、药物发现、系统测量）有很强通用价值。

## 关键术语表
- **Boundary marginalization（边界边际化）**：沿事件区间的上下端点数字前缀路径，将区间概率分解为前缀子树概率之和的高效计算方法。
- **Event likelihood（事件似然）**：将观测（精确值、区间或界）映射为兼容网格索引集合后，对该集合内所有数值概率求和得到的对数似然。
- **CRPS（Continuous Ranked Probability Score）**：对预测 CDF 与观测阶跃函数的平方差按数值距离积分的严格proper打分，用于评估概率预测质量。
- **Threshold-sampled CRPS**：从阈值集合中独立采样少量点估计 CRPS，其梯度经自动微分回传是 unbiased 的。
- **Conditionally ignorable reporting（条件可忽略报告）**：观测报告 $A$ 出现的概率仅取决于 $A$ 本身而非具体网格值 $k$，保证事件似然具有统计意义。
- **Prefix subtree（前缀子树）**：固定前缀后所有可能的后缀扩展所构成的数值集合，其总概率等于该前缀的出现概率。
- **Complete-case CE（完整样本交叉熵）**：仅使用精确标签进行序列交叉熵训练，丢弃所有区间/删失观测的方法。
- **Imputed-label CE（插补标签交叉熵）**：将每个区间/删失报告替换为代表性数值（如中点或边界）后进行 CE 训练。

## 可复现要素
- **数据集**：受控合成数据（自建）、hERG（ChEMBL 37，公开）、KBSS（Code-Regression 子集，公开）；论文未声明开源预处理后的数据集，但提供了提取规则和 manifest。
- **代码/权重**：论文未声明开源代码仓库或模型权重。
- **关键超参**：Qwen2.5-1.5B / Qwen3-4B-Base；rank-16 LoRA（α=32）；AdamW，lr=1e-4，β=(0.9, 0.999)，weight decay=0，梯度裁剪=1.0；有效 batch size=32；数字网格位数 d=4（精度扩展实验 d=2~6）；训练轮次 3 epoch（受控/hERG/KBSS）或 9 epoch（精确标签对比）。
