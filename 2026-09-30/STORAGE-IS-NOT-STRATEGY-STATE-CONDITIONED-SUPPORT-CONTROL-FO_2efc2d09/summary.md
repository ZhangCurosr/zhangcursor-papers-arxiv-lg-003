# 论文速读：STORAGE-IS-NOT-STRATEGY-STATE-CONDITIONED-SUPPORT-CONTROL-FO

## 一句话总结
本文证明在LLM机器遗忘中，高精度参数定位（storage localization）并不等价于最优干预选择，且静态支持集在优化过程中会因参数演化而失效。作者提出目标条件化的初始参数选择评分 Intervention Score，并配合基于短探针门控的检查点动态重排机制 DIR-R，以极低额外计算代价显著提升遗忘收益与保留行为的平衡。

## 研究问题与动机
1. **定位与干预解耦缺失**：现有定位优先方法默认“与遗忘数据关联最强的参数组”即为“最适合执行特定遗忘目标的干预区域”，但定位质量（描述性问题）与干预效能（规范性决策）未被严格分离。
2. **静态支持集会过期**：多数工作选定参数子集后全程冻结，然而持续遗忘研究与后训练分析表明，随着优化推进参数分布变化，初始机械定位会迅速变得过时。
3. **目标强依赖性**：相同参数预算下，NPO 与 SimNPO 独立选出的干预子集 Jaccard 相似度仅约 0.143，说明干预选择必须绑定具体遗忘目标，而非跨目标通用。
4. **评估混淆风险**：过往文献常以定位 AUROC 高间接宣称方法优越，缺乏控制变量实验验证定位信号对实际终端效用 $J$ 的预测力，导致方法排序存在系统性偏差。

## 核心贡献（创新点）
1. **定位与干预的受控分离**：在 Qwen2.5-7B 合成注入实验中证明，即便存储定位 AUROC 达 0.981，其与最优干预的一致性仅 17/36（47.2%），而 LoRA 接口胜率达 35/36（97.2%），从根本上证伪“定位即策略”假设。
2. **目标条件化初始选择（Intervention Score / STATIC-IV）**：提出基于一阶近似的干预评分函数，联合评估遗忘方向收益、保留/受保护行为的附带损伤与非特异性漂移，按目标导向贪心生成固定支持集，提供可复现的静态基线。
3. **检查点条件化选择性修订（Selective DIR-R）**：设计短探针门控，仅在校准信号超过阈值时触发候选支持族的完整对比，以远低于 16× 穷举参考的计算代价捕获 29.1%~58.3% 的可用增益。
4. **细粒度基准审计与字段敏感性剖析**：在 Natural-TOFU 与 LACUNA 上系统解构初始选择与动态修订收益，揭示 GradDiff 目标下 Birth City 等字段对静态排名的反向驱动效应，提出“支持控制应作为独立设计与评测问题”的框架。
