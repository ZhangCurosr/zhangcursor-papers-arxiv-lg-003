# 论文速读：TabFM: A Zero-Shot Foundation Model for Tabular Data

## 一句话总结
本文提出 TabFM，一个 400M 参数的表格基础模型，将监督表格预测重构为单次前向传播的上下文学习（In-Context Learning）任务；模型完全在由结构因果模型（SCMs）生成的合成表格上预训练，无需任何任务特定微调即可在 TabArena（51 个数据集）上输出校准的零样本预测，并依托冻结权重的推理时增强（TabFM+ / TabFM-Auto）超越多个调优后的 AutoML 管线。

## 研究问题与动机
1. **每数据集定制开销巨大**：传统表格机器学习高度依赖 GBDT、Random Forest 及 AutoML 流水线，每个新任务均需从头进行数据清洗、特征选择、分裂搜索与超参调优，无法复用已有知识。
2. **表格结构的注意力瓶颈**：表格中行可交换而列混合连续/离散类型，原生全单元格注意力复杂度为 $O(T^2 H^2)$，导致现有上下文表格模型（如 PFN 系列）难以处理超过千行的序列。
3. **真实标注数据稀缺/敏感**：许多领域缺乏大规模高质量标注表格，如何仅凭合成数据训练出可零样本迁移到真实世界的通用表征仍是开放问题。
4. **冻结权重下的二次开发潜力**：基础模型部署后通常不允许微调，如何通过推理时特征变换、集成与外部代码合成挖掘其潜力，对工业落地具有实际价值。

## 核心贡献（创新点）
1. **提出 TabFM 行列解耦 Transformer 架构**：通过二元特征分组与学习型傅里叶频带嵌入单元格，结合交替的线性时间列向 ISAB 与带 RoPE 的行向 SAB，将上下文扩展至 16,384 行。与 TabPFN/TabICL 的本质区别在于显式分离特征编码与跨实例推理，并引入频谱嵌入保留数值精度。
2. **纯合成 SCM 数据预训练策略**：完全基于结构因果模型随机生成的表格进行预训练，配合四阶段课程学习渐进扩展上下文长度。与依赖真实数据继续预训练的工作（如 RealTabPFN）相比，本文证明了无需真实数据即可学习到可迁移的通用表格后验预测映射。
3. **冻结权重的双轨增强范式**：TabFM+ 通过 32 视角多视图特征扩展（乘积交叉+SVD）与非负最小二乘集成+Platt 校准提升性能；TabFM-Auto 将冻结的 TabFM 包裹在 Gemini-3.8-Flash 的交叉验证闭环中自动合成特征工程管线。两者均不更新任何模型参数，与需要在线调优的 AutoML 形成鲜明对比。
4. **TabArena 零样本领跑与系统化评测**：在 51 个数据集（38 分类/13 回归）的统一 Bradley-Terry Elo 排行榜上，零样本 TabFM 位列默认基础模型第一，且 TabFM-Auto 拿下综合榜首；提供了从基线、特征工程到集成校准的完整对比视野。

## 方法详解
1. **频谱单元格嵌入（Cell Embedder）**：输入表格 $\mathbf{X} \in \mathbb{R}^{T \times H}$ 先进行二元分组，第 $j$ 列与偏移量为 $2^g-1$（$g \in \{0,1,2\}$）的列组成大小为 $G=3$ 的槽。每个槽的标量值通过 32 个学习到的傅里叶频率 $\boldsymbol{\omega}_g$ 映射为 64 维正弦/余弦向量，连续列与分类型列使用独立的频率 bank 与投影矩阵
