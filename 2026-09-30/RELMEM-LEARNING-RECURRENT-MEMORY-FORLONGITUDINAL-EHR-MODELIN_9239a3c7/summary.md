# 论文速读：ReLMem: Learning Recurrent Memory for Longitudinal EHR Modeling

## 一句话总结
本文提出 **ReLMem**，一种通过冻结 LLM 配合轻量级压缩适配器学习固定容量递归患者记忆的方法，用于高效建模纵向电子健康记录（EHR）；在多粒度优化策略下，该方法在药物预测任务上仅用完整历史 2.9% 的存储量即可逼近 Full History 性能，同时降低 97.1% 的历史存储开销。

## 研究问题与动机
- 纵向 EHR 建模需整合多次就诊产生的新增信息，但完整历史持续累积会导致 LLM 的计算和内存成本激增（注意力计算随序列长度呈二次方增长，KV cache 线性增长）。
- 现有上下文压缩方法（如 SnapKV、KVzip）将历史压缩为独立表示再追加，仍会导致上下文持续增长；反复全量重压缩则需重读早期记录，无法实现资源高效的增量更新。
- 固定容量递归更新面临核心挑战：每次更新需在融入新信息的同时保留对下游预测有用的历史信息，而早期 visit 的信息只能通过前一时刻的记忆间接获取，任何步骤的信息丢失都会在后续递归中累积。
- 仅依赖最终答案监督无法保证中间记忆状态有效保留历史证据，需要一种多粒度优化策略来约束递归更新过程。

## 核心贡献（创新点）
- **提出 ReLMem 框架**：学习固定容量递归患者记忆，以冻结的 LLM + 轻量级压缩适配器在每个 visit 处将新记录与前一记忆融合为等容量新状态，避免重读早先记录。
- **设计多粒度优化策略**：通过中间注意力对齐（让压缩记忆与完整历史的注意力输出在相同查询下匹配）和最终预测交叉熵监督联合优化，分别约束历史证据保留与临床预测准确性；两者互补且缺一不可。
- **引入课程学习训练策略**：从短历史样本起步，逐步引入更多就诊次数的样本，帮助模型在递归深度增加时稳定学习并保持信息保留。
- **在 MIMIC-IV 上的全面验证**：在药物预测和下一次就诊诊断预测两个任务上，ReLMem 在相同记忆预算下比最强压缩基线 CCM-merge 分别提升 macro-F1 4.66 和 micro-F1 4.75 个百分点，同时将平均历史存储减少 97.1%。

## 方法详解
- **任务适配（Task-Specific Adaptation）**：首先在完整患者历史上用 LoRA 对 LLM 进行监督微调（SFT），最小化答案 token 的交叉熵；训练后将 LoRA 权重合并入预训练权重 θ 并冻结，作为后续递归记忆更新的骨干网络。
- **记忆表示**：将患者记忆表示为层级的 KV 对 $M_t = \{(K_t^\ell, V_t^\ell)\}_{\ell=1}^L$，每层每个 KV head 固定为 $B$ 个 memory slot，总容量恒定。
- **递归更新步骤**：
  1. **记忆条件编码**：冻结骨干将当前就诊 $v_t$ 以 $M_{t-1}$ 为上下文进行 KV 计算，得到 $P_t = \text{KV}_\theta(v_t | M_{t-1})$。
  2. **固定容量更新**：在 $P_t$ 后追加 $B$ 个 memory token，通过 token-conditional 低秩适配器（仅在 memory token 位置激活）处理，输出新的固定容量记忆 $M_t = \text{KV}_{\theta,\phi}(\langle\text{mem}\rangle_{1:B} | [M_{t-1}; P_t])$。
- **中间注意力对齐损失**：在第 $s$ 步，独立编码完整历史 $H_s$ 得到参考 $F_s$，用相同的查询向量 $\mathbf{Q}_s$（来自下一就诊或最终任务查询）分别从 $M_s$ 和 $F_s$ 读取注意力输出 $\mathbf{O}_s^M$ 和 $\mathbf{O}_s^H$，最小化归一化平方差 $\mathcal{L}_{\text{inter}}$，迫使压缩记忆保留完整历史的信息检索能力。
- **最终预测损失**：基于最终记忆 $M_T$ 和任务查询 $q$ 预测答案，最小化交叉熵 $\mathcal{L}_{\text{pred}}$。
- **联合优化目标**：$\min_\phi \mathbb{E}[\mathcal{L}_{\text{pred}} + \frac{\lambda}{T}\sum_{s=1}^T \mathcal{L}_{\text{inter}}(\phi;s)]$，其中 $\lambda=0.1$ 控制中间对齐权重；完整历史参考仅在训练时使用。
- **课程学习**：每阶段 $e$ 从满足 $T \leq \tau_e$ 的样本中采样，阈值 $\tau_e$ 单调递增，同时保留部分短历史样本以维持递归深度的监督。
- **位置编码策略**：遵循 RoPE 惯例，memory token 与历史 token 共享索引但不推进历史 token 计数器，因果注意力按物理序列顺序处理。

## 实验与结果
- **数据集**：MIMIC-IV，包含药物预测（预测首次 24h 内的 ATC level-3 药物类别）和下一次就诊诊断预测两个任务；按患者划分 train/val/test，无重叠。
- **评估指标**：Macro-F1、Micro-F1、P@k、R@k（k∈{5,10}），以及历史存储（MiB）、峰值 GPU 显存（GiB）、更新延迟、预测延迟。
- **主要结果（药物预测，Qwen3-4B，B=1,024）**：
  - ReLMem：Macro-F1 = 61.93%，Micro-F1 = 63.24%，历史预算 1,024 slots，接近 Full History（62.22%/63.32%），存储仅为 Full History 的 2.9%（144 MiB vs 4,961 MiB）。
  - 相比最强压缩基线 CCM-merge（57.27%/58.49%），ReLMem 提升 macro-F1 4.66 pp、micro-F1 4.75 pp。
  - KVzip 表现次优（52.53%/54.52%），RMT 较低（47.28%/48.42%），表明层间 KV 表示优于仅用最后一层 hidden state。
- **消融实验**：
  - 仅 $\mathcal{L}_{\text{inter}}$：Macro/F1 仅 0.37%/0.55%（几乎无预测能力）。
  - 仅 $\mathcal{L}_{\text{pred}}$：Macro 47.67%/Micro 48.65%，去掉中间对齐后分别下降 14.26/14.59 pp。
  - 课程学习进一步从 61.00/62.24 提升至 61.93/63.24。
  - 4 层对齐与 8 层对齐效果相近，4 层节省 2.4% 训练时间。
- **资源效率**：ReLMem 峰值 GPU 显存 9.24 GiB（Full History 的 48.8-49.1%），更新延迟降低 26.3%，预测延迟降低约 19%。
- **记忆容量分析**：将预算从 1,024 降至 128（8 倍压缩），Macro/Micro-F1 仅下降 2.81/3.00 pp；128 slot 时仍优于 KVzip 在 2,048 slot 的表现。
- **长历史扩展**：在平均 16.72 次就诊（最大 69 次）的扩展历史上，ReLMem 仅比 Full History 低 0.54/0.22 pp，而 CCM-merge 大幅落后（40.71/48.04）。
- **跨模型泛化**：在 Qwen3-8B 和 Llama-3.1-8B 上，ReLMem 与 Full History 的 F1 差距均小于 2.5 pp。
- **患者特异性验证**：记忆互换导致 Macro-F1 下降 24.80 pp（p<0.001），证明性能提升来自正确历史而非固定容量机制本身。

## 相关工作脉络
- **纵向 EHR 建模**：早期模型如 RETAIN、Doctor AI 使用 RNN；后续 TransformEHR、BEHRT、Med-BERT 采用预训练 Transformer；近期 EHR-R1、EHRAgent 扩展至 LLM 推理与多步查询；本文聚焦在冻结 LLM 上学习递归记忆而非全量微调。
- **上下文压缩**：LLMLingua/LLMLingua-2 通过剪枝缩短 prompt；Gisting、In-context Autoencoder 编码为紧凑表示；KVzip、SnapKV、H²O 在 KV cache 层级选择性保留；本文相比这些一次性压缩方法的关键差异在于支持**递归增量更新**而非每次重压缩。
- **递归记忆**：Transformer-XL 通过分段递归扩展上下文；Compressive Transformer 用注意力重建监督压缩历史；RMT 用隐藏记忆 token 跨段传递；CCM 支持在线交互的递归压缩；本文在递归记忆的基础上引入**中间注意力对齐**和**多粒度监督**，专门针对 EHR 长程预测场景优化信息保留。
- **KV 压缩基线**：SnapKV、KVzip、Attention Matching 直接适配到递归场景效果较差，说明简单的缓存压缩策略难以迁移到增量更新设定。

## 局限性与未来方向
- 仅在单一中心 MIMIC-IV 数据集上做了回顾性评估，未跨机构验证或在前瞻性临床场景测试。
- 仅覆盖 Qwen 和 Llama 系列 4B/8B 规模模型，未探索更大参数规模或其他模型架构。
- 当前为每个任务（药物预测/诊断预测）单独适配骨干和记忆模块，尚未实现任务无关的通用记忆表示。
- 扩展到其他 EHR 下游任务（如风险预测、疾病轨迹建模）有待验证。
- 论文指出未来方向包括：多任务通用记忆学习、跨机构泛化、更大模型规模验证。

## 研究启发与可借鉴点
- **多粒度对齐监督**：中间注意力对齐（用压缩记忆与完整历史的 attention output 匹配）是一种值得借鉴的信息保留正则化手段，可迁移至其他需要递归压缩的序列建模任务（如对话系统、长期文档理解）。
- **任务适配+冻结骨干+轻量适配器**的两阶段范式：先在完整数据上 SFT 适配任务能力，再冻结骨干只训练压缩适配器，兼顾表达能力与训练效率，适用于资源受限的长期记忆学习场景。
- **课程学习促进长序列记忆学习**：从短递归深度逐步过渡到长深度，有效缓解信息累积丢失问题，策略本身可与任意递归记忆架构结合。
- **层间 KV 表示优于层末 hidden state**：本文发现 RMT（仅最后一层）显著劣于使用层间 KV 的方法，提示跨层信息的保留对长程任务至关重要。
- **可复用的位置编码策略**：memory token 与历史 token 共享 RoPE 索引但不推进历史计数器的做法，可被其他 KV 压缩框架借鉴以避免位置混乱。

## 关键术语表
- **ReLMem (Recurrent Longitudinal Memory)**：本文提出的递归纵向记忆框架，通过固定容量的 KV 记忆增量整合每次就诊，以冻结 LLM 完成高效 EHR 建模。
- **纵向 EHR (Longitudinal EHR)**：跨越多次就诊按时间顺序累积的患者临床记录，包含诊断、用药、操作和病历文本等多维度信息。
- **中间注意力对齐 ($\mathcal{L}_{\text{inter}}$)**：在递归更新的每一步，使用相同查询从压缩记忆和独立编码的完整历史中读取注意力输出并最小化归一化差异，以约束历史信息保留。
- **多粒度优化 (Multi-granularity Optimization)**：结合中间层注意力对齐和最终预测监督的联合训练策略，分别保障历史证据保留和临床预测准确性。
- **Token-conditional Low-rank Adapter**：仅在 memory token 位置激活的低秩适配器，使固定容量的 memory token 能融合先记忆与当前就诊的 KV 信息。
- **课程学习 (Curriculum Learning)**：训练初期仅使用短历史样本，逐步扩大递归深度上限，帮助模型稳健地学习多步记忆压缩。
- **KV Cache Compression**：通过选择性保留或压缩注意力计算中的 key-value 状态来减少上下文存储与计算开销的技术。
- **Macro-F1 / Micro-F1**：前者对每个样本独立计算 F1 后平均，后者在所有样本上聚合 TP/FP/FN 后计算 F1，分别反映类别平衡性和整体预测性能。

## 可复现要素
- **数据集**：MIMIC-IV（Johnson et al., 2023b），需通过 PhysioNet  credentialing 获取，数据使用受原始协议约束；论文未公开原始数据处理脚本。
- **代码**：论文声明"Code will be publicly released upon acceptance"，截至论文版本暂未开源。
- **模型权重**：使用 Qwen3-4B（默认）、Qwen3-8B 和 Llama-3.1-8B 作为骨干，需自行获取；LoRA 适配权重合并入骨干后冻结。
- **关键超参**：
  - 记忆槽数 $B = 1{,}024$（默认）
  - 对齐权重 $\lambda = 0.1$
  - 中间对齐层数 $|S| = 4$
  - 任务适配学习率 $10^{-4}$，1 epoch；记忆学习学习率 $3\times10^{-4}$，最多 5 epochs
  - LoRA rank=8，alpha=16（适配）/8（记忆）
  - AdamW，weight decay 0.01，BF16 精度
  - 课程学习阈值：药物预测 $(4, 6, \infty, \infty, \infty)$，诊断预测 $(6, 8, \infty, \infty, \infty)$
- **硬件**：8× NVIDIA A800-SXM4-80GB GPU；推理评估在单卡 A800 上进行。
