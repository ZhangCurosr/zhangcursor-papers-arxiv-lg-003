# 论文速读：WHERE-PRIVACY-BELONGS-PLACEMENT-DIAGNOSISAND-CERTIFIED-SELEC

## 一句话总结
论文针对图神经网络（GNN）反事实解释中的隐私泄露问题，提出 **PRIVCFS**（Private CounterFactual Selection）框架，通过将候选解释集从数据无关的公共先验中固定构建，并结合有效性门控的有界效用与指数机制采样，首次为完整的图反事实解释发布提供了 **纯 ε-差分隐私（pure ε-DP）** 保证，同时实证表明隐私噪声是管线中最便宜的环节，主要成本在于公开披露强度。

## 研究问题与动机
1. **核心矛盾**：GNN 反事实解释需要访问敏感图结构以确定最小干预，而直接发布解释会泄露该结构；现有隐私化方案存在“放置（placement）”缺陷。
2. **图级隐私化的失败**：在解释前先对邻接矩阵加噪（DP）会污染低边际节点（borderline nodes）的预测目标，导致解释器在错误目标上优化，产生**虚假翻转（spurious flips）**——在私有图上翻转但真实图上不翻转的干预。
3. **解释级扰动的认证缺口**：在干净图上解释后再扰动发布结果，虽避免了目标污染，但标准启发式输出扰动（基于每条目灵敏度假设）无法认证完整发布向量；论文重审发现其实际全发布预算高达 **573–753（Cora）** / **256（CiteSeer）**，远超广告值，且最坏单条泄露 AUC 达 1.0。
4. **需求**：需要一种可构造性认证（certification‑by‑construction）的放置方式，在严格隐私保证下保持反事实解释的有效性。

## 核心贡献（创新点）
1. **隐私‑解释放置诊断原则**：形式化区分图级 DP 与解释级 DP，诊断出预测污染与虚假翻转为图级放行的两大失效通道，并量化验证启发式输出扰动的认证缺口（附录 A）。
2. **PRIVCFS 框架**：提出基于数据无关候选宇宙的反事实选择机制，边缘候选取自公共先验图，特征候选取自公共模式，通过有效性门控与裁剪效用实现全局灵敏度 Δu≤1，无需优化器灵敏度分析。
3. **纯 ε‑DP 完整发布保证**：利用指数机制在固定支持上直接采样发布，证明所发布干预集合满足纯 ε‑DP（δ=0），且查询可组合（Corollary 1）；据称是图反事实解释领域首个此类保证。
4. **隐私‑效用前沿作为可购买价格表**：实证表明在 ε=8 时采样发布保留支持受限非私有最优的 **83–97%**；主要成本是公开披露强度（公共先验比例 ρ），形成单调可购的价格清单，而隐私噪声成本最低。
5. **攻击审计验证**：最优似然比边推理攻击在真实相邻对上达到平均 AUC 0.50、最坏对 AUC 0.59，远低于启发式基线最坏条目 AUC 1.0，实证支撑理论保证。

## 方法详解
1. **问题设定**：给定带属性图 G=(V,E,X) 与冻结 GNN 分类器 f，对目标节点 v 寻找干预 S=(S_E,S_F)（删除若干边、遮蔽若干特征维度），使 f(G⊖S)[v] 翻转至次优类（runner‑up），且干预最小。威胁模型为边级纯 DP（δ=0）。
2. **数据无关候选支持**：固定公共上下文（先验图 G_pub、特征 X、骨干 f、目标 v），构建候选宇宙 C_v。边候选 U^E_v 来自 G_pub 中 v 的邻接对（截断 k_E=12）；特征候选 U^F_v 取 v 的特征中非零维度按公共一阶影响排序的前 k_F=12 维。**删除不存在的边视为空操作（no‑op）**，确保相邻图的支持相同（Lemma 1）。
3. **有效性门控效用**：
   - u(G,S)=w_c（S=∅）；
   - u(G,S)=w_f + w_c·γ(s) + w_p·plaus(S_E)（若 S 使预测翻转，即 f(G⊖S)[v]≠ŷ_orig）；
   - u(G,S)=0（否则）。
   其中 s=|S_E|+|S_F|，γ(s)=1−s/k_max，plaus(S_E)=|S_E∩E|/|S_E|（真实边比例）。权重 w_f=0.7,w_c=0.2,w_p=0.1，总和为 1。该效用将翻转有效性作为门控，非翻转候选被赋予较低效用但不被排除出支持，维持支持独立性。
4. **全局灵敏度界定**：每个效用项均属于 [0,1]，且仅通过相邻边变化最多改变 1/|S_E|≤1；因此 |u(G,S)−u(G′,S)|≤w_f+w_c+w_p=1，即 Δu≤1（Lemma 2）。该界由公共裁剪范围直接保证，无需分析优化器敏感行为。
5. **指数机制发布**：以概率 ∝ exp(ε·u(G,S)/(2Δu)) 从 C_v 中采样输出 S*（Algorithm 1）。由 Lemma 2 与指数机制标准定理直接得出纯 ε‑DP（Theorem 1），且 k 次自适应查询消耗 kε 预算（Corollary 1）。效用保证（Theorem 2）给出采样效用不低于 OPT−(2Δu/ε)(ln|C_v|+ln(1/β))。

## 实验与结果
- **数据集**：Cora（2,708 节点）、CiteSeer（3,327 节点）；规模迁移测试采用 ogbn‑arxiv 的 15,000 节点度数核心子图。
- **骨干网络**：两层 GCN（隐层 32），在 Planetoid 训练集上 Adam 优化 200 步（lr=0.01，weight decay=5×10⁻⁴）后冻结；Cora 测试准确率 0.809，CiteSeer 0.682。
- **机制超参**：公共先验强度 ρ∈{0.5,0.7,1.0†}；k_E=12,k_E^max=2；k_F=12,k_F^max=3；权重 (0.7,0.2,0.1)；预算网格 ε∈{0.1,0.5,1,2,4,8}；每个单元格 100 次蒙特卡洛采样；结果取 3 个种子均值±标准差。
- **评估指标**：有效反事实率 CSR（clean graph 验证翻转）、随机翻转率 Spur.、预测污染率 Poll.、空输出率、效用遗憾、发布碰撞率等。
- **主要结果**：
  - **一般群体**（Table 1）：ε=8 时，Cora ρ=0.5/0.7/1.0† 保留非私有上限（starCF）的 **84%、85%、83%**；CiteSeer 对应 **95%、95%、92%**。
  - **边缘群体**（Table 2，10 个最低边际节点）：ε=8 时保留 **97%、97%、96%**（Cora）与 **95%、94%、96%**（CiteSeer）。
  - **最强结果**：CiteSeer 边缘群体 ρ=0.7 时 CSR 达 **0.534±0.468**；ogbn‑arxiv 核心 15K 节点边缘群体 ε=8 时 CSR 达 **0.963±0.026**（Table 6）。
  - **对比基线**（Table 3）：图级 DP（NaiveDP/LapDP/RR‑LDP）污染 60–92% 目标、虚假翻转 23–37%；启发式输出扰动（PrivCF‑out）虽 CSR=1.000 但**未认证**（实际全发布预算 573–753/256）。同操作空间下，PRIVCFS 以 ε=8 实现纯 DP 保证，且无虚假翻转/污染。
  - **攻击审计**（Fig.3, Sec.4.5）：似然比攻击 AUC 平均 **0.50**、最坏对 **0.59**；启发式基线最坏条目 AUC **1.0**；实测灵敏度 0.96≤1.0，发布概率比最大值 35.3 远低于 e^8≈2981 界。
- **结论**：隐私噪声是管线中最便宜环节，主要成本为公开披露强度（ρ）；机制支持复合预算查询，且在百节点规模测试中验证了支持独立性与灵敏度界。

## 相关工作脉络
1. **图反事实解释**：GNNExplainer、CF‑GNNExplainer、RCExplainer、COMBINEX 等方法假设完全访问干净图，未处理隐私发布；本文将其搜索目标作为打分 oracle 接入私有选择层，兼容上述方法。
2. **图学习差分隐私**：DP‑SGD、Opacus、本地隐私 GNN、节点级 DP‑GNN（DPAR）等聚焦模型训练或图发布，未研究在私有产物上计算解释的后续发布隐私；本文补全该链条，并与模型级 DP 正交可组合。
3. **解释隐私与反事实公平**：GDPR 解释权推动反事实成为法律概念；表数据上的 DP 反事实生成（Privately trained prototypes、DP retrieval、diverse counterfactuals under DP training）未处理图结构泄漏；本文首次针对图结构提供纯 ε 保证。
4. **攻击与审计**：LinkTeller 等影响分析攻击可从模型行为恢复私有边；解释发布放大模型反转攻击（Zhao et al.）。本文的似然比审计沿用相同协议，量化对比启发式与所提机制的实际泄露。
5. **位置诊断定位**：指出图级 DP 与解释级 DP 的放置差距是效用全部损失（同操作空间下图级 CSR=0.000），而非常数因子；本文选择解释级基于构造的认证路径。

## 局限性与未来方向
1. **候选宇宙固定**：解释搜索受限于公共先验提供的候选集，可能遗漏非公开结构中的更优干预；数据依赖型候选会破坏支持独立性。
2. **公共先验依赖**：性能随 ρ 单调变化，高质量先验图可显著提升效用，但实际场景中先验可能过时或稀疏。
3. **特征隐私未完全覆盖**：主要保证针对边邻接；特征维度隐私作为独立会计问题留待未来工作。
4. **支持大小与计算开销**：候选数 |C_v| 可达数万个，exact enumeration 在百节点规模可行，但在更大图或更广两跳扩展下需近似采样。
5. **未来方向**：集成模型 Lipschitz 约束以降低预算；扩展至动态图、图级任务（motif ground truth）；支持特征条目 DP 或阈值“无干预”发布；探索两跳公共先验与特征‑kNN 候选的其他公开模式。

## 研究启发与可借鉴点
1. **基于构造的认证范式**：将候选宇宙固定为数据无关集合，利用 no‑op 语义维持支持一致性，从而绕过优化器灵敏度分析的困难；该思路可迁移至其他需要发布离散选择的隐私任务（如序列标注、推荐列表）。
2. **有效性门控效用设计**：通过软‑硬门控（flip 才赋予正向奖励，否则为 0）既保证解释实用性，又维持全局灵敏度上界；可借鉴于需要“条件奖励”的隐私选择场景。
3. **隐私‑成本价格表**：将公开披露强度（ρ）作为可单调购买的效用提升维度，使数据所有者能在预算外预计算成本；该理念可用于隐私预算分配决策支持工具。
4. **审计验证补充理论**：使用最优似然比攻击在真实相邻对上评估实际泄露，提供比理论界更精细的经验证据；可作为差分隐私机制发布的标准验证流程。
5. **团队结合机会**：若团队关注动态图或时序解释，可将 PRICKF 的固定候选框架扩展至时间切片；或将“公共先验快照”替换为跨模态对齐的辅助图，提升候选覆盖。

## 关键术语表
- **反事实解释（Counterfactual Explanation）**：使模型预测翻转的最小输入干预（边删除/特征遮蔽）。
- **差分隐私（Differential Privacy）**：保证任意相邻数据集的输出分布相似度受 ε 控制，隐藏单个记录的影响。
- **纯 ε‑DP（Pure ε‑DP）**：δ=0 的差分隐私，不存在放松概率，适用于 worst‑case 保证。
- **指数机制（Exponential Mechanism）**：按 exp(ε·u/2Δu) 概率采样输出，用于在效用函数下保持隐私的选择。
- **全局灵敏度（Global Sensitivity）**：效用函数在相邻数据集上的最大变化量，决定噪声尺度。
- **有效性门控（Validity‑gated）**：仅对真正满足翻转条件的干预赋予正向效用，否则效用为 0。
- **虚假翻转（Spurious Flip）**：在隐私噪声图上翻转但真实图上不翻转的干预。
- **预测污染（Prediction Pollution）**：隐私噪声导致模型对低边际节点的预测发生改变。
