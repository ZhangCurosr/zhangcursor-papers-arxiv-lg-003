# 论文速读：SEEING-IS-NOT-ADDRESSING-AUDITING-LINGUISTIC-ACCESS-TO-FROZE

## 一句话总结
论文揭示了视觉-语言模型中"视觉可区分性"与"语言可及性"之间的系统性差距，并提出一种基于目标-其余对比的匹配视觉接地方法，在冻结表示上无需微调即可显著改善细粒度视觉属性的文本检索性能。

## 研究问题与动机
- 视觉表征往往保留了比语言概念化更精细的区分信息，但在冻结的视觉-语言模型中，某些图像几何层面可区分的属性却难以通过原生文本查询有效访问。
- 现有检索失败常被归因于模型缺乏对应视觉结构，但本文证明问题可能在于语言接口未能充分激活图像中已存在的区分性信息。
- 全局对齐方法（如线性变换）虽能提升整体检索性能，但会留下残留的值级访问差距，需要区分度特定的干预来进一步缩小。
- 细粒度视觉-语言对齐的评估缺乏对"视觉可区分性"与"语言可及性"的系统性分离诊断。

## 核心贡献（创新点）
1. **提出匹配视觉接地（Matched Visual Grounding）框架**：通过为目标值构建"目标-平均其余"视觉对比方向，将其作为校准向量对齐到原生文本查询，本质区别在于仅调整查询方向而非引入新参数或缓存。
2. **建立视觉可区分性与语言可及性的分离评估协议**：在同一冻结图像几何上独立测量两种能力，首次系统化量化二者差距并验证其非重合性。
3. **提供方向特异性与视觉证据依赖的严谨控制实验**：通过原型吸引、错配方向、提示模板、词汇替换、视觉信号衰减等多重对照，证明增益来自匹配的靶-余对比而非泛化吸引力或词表变化。
4. **验证跨模型、跨分布与组合检索的泛化性**：在7个VLM骨干网络、三种保持-out协议（上下文保持、语义组合保持、24次划分）下均取得一致增益，并扩展到自然图像数据集。

## 方法详解
- **因子视觉对比构造**：对因子值集合$\mathcal{V}$中的值$v$，用校准集$C_v$计算目标原型$\mu_v^I = \text{norm}(\frac{1}{|C_v|}\sum_{x\in C_v}\text{norm}(I(x)))$与平均其余原型$\bar{\mu}_{-v}^I = \frac{1}{|\mathcal{V}|-1}\sum_{u\neq v}\mu_u^I$，得对比方向$d_v^I = \frac{\mu_v^I - \bar{\mu}_{-v}^I}{\|\mu_v^I - \bar{\mu}_{-v}^I\|}$。
- **匹配接地查询**：$q_v'(\alpha) = \text{norm}(q_v + \alpha d_v^I)$，其中$\alpha \geq 0$控制接地强度，在验证集选择。
- **几何保证（Proposition 1）**：接地后相似度边距$M_v(q_v'(\alpha)) = \|\Delta_v^I\|\frac{c+\alpha}{\sqrt{1+\alpha^2+2\alpha c}}$单调不减于原始边距$M_v(q_v)$，当初始边距为负时$\alpha^* = -c$可使其归零转正。
- **评估协议**：FactorAtlas包含23,040张图像（8形状×12色调×10图案×24干扰变体），4个上下文校准、2个验证、6个测试；所有编码器冻结，仅调整文本查询方向。

## 实验与结果
- **数据集**：FactorAtlas（合成，23,040图像）、DTD（纹理）、Fashionpedia（服装图案/长度）、COCO-Facet（材质）、UT-Zappos（鞋类材质）。
- **基线**：原生文本检索、原型吸引接地、错配方向、全秩线性全局对齐（共享/因子级）、Tip-Adapter缓存。
- **主要结果（SigLIP2 Base，上下文保持）**：图案mAP从0.635→0.878（+24.3%），色调从0.678→0.854（+17.6%），形状从0.702→0.813（+11.1%）；21个骨干-因子组合全部提升。
- **最强结果**：七骨干宏观mAP在图案上达0.862（+29.5绝对值），组合检索R@1从0.357→0.711（+99.7%相对提升）。
- **自然图像迁移**：COCO-Facet材质mAP从0.624→0.860；FactorAtlas方向直接复用至Fashionpedia提升mAP从0.583→0.719。

## 相关工作脉络
- **CLIP/SigLIP等VLM对齐工作**：关注整体跨模态对应，本文聚焦值级细粒度访问差距的显式诊断与干预。
- **LABCLIP（Koishigarina et al., 2026）**：学习共享文本变换改善属性-对象对应，本文证明全局对齐后仍存在残留差距且可被值特定接地进一步缩小。
- **Winoground/VL-CheckList等组合推理基准**：指出VLM在细粒度属性绑定上的不足，本文从"视觉可区分性 vs 语言可及性"分离视角提供新解释。
- **Tip-Adapter支持自适应（Zhang et al., 2021）**：利用校准样本缓存提升检索，本文方法在同等校准数据下获得更高mAP且无需推理时缓存。
- **视觉表征组合性研究（Berasi et al., 2025; Sonthalia et al., 2026）**：证明图像嵌入保留有序结构，本文将其应用于显式构建值级对比方向。

## 局限性与未来方向
- 几何保证仅针对校准集的目标-平均其余边距局部成立，不保证跨域泛化或组合检索单调改进。
- 全局对齐实验仅测试全秩线性映射一种家族，其他非线性或结构化对齐策略未评估。
- 匹配视觉接地依赖标注校准图像估计方向，在零标签场景下的扩展未讨论。
- 单值干预的累积效应在多值复合查询（如同时指定形状+色调+图案）中未被系统分析。
- 自然图像实验局限于特定领域（纹理/服装/材质），未验证 generality 到其他视觉属性类别。

## 研究启发与可借鉴点
- **接口解耦诊断思路**：将"模型是否学到区分信息"与"文本接口能否访问"分离评估，为VLM黑盒分析提供可操作的审计框架。
- **无参数方向调整范式**：通过向量加法而非权重更新实现查询修正，适用于任何冻结VLM的即插即用增强。
- **控制实验设计**：原型吸引、错配方向、信号衰减、词汇替换四重对照完整排除替代解释，可作为后续方法的评测模板。
- **跨域方向复用潜力**：FactorAtlas学到的图案对比方向可直接迁移至Fashionpedia，提示合成-自然域间存在共享视觉结构。
- **验证引导的选择性接地**：利用Bootstrap置信区间识别需干预的值，避免对已有效查询的过度修正，适用于资源受限场景。

## 关键术语表
**视觉可区分性（Visual Discriminability）**：冻结图像几何中某视觉属性值与其余值可被可靠区分的程度，由图像原型查询衡量。
**语言可及性（Linguistic Addressability）**：原生文本查询检索到对应视觉属性图像的有效性，反映语言接口对视觉结构的访问能力。
**匹配视觉接地（Matched Visual Grounding）**：将目标-其余视觉对比方向对齐到原生文本查询的干预方法，无需训练即可改善检索。
**目标-平均其余对比（Target-vs-Average-Rest Contrast）**：从校准集构建的值特定方向，表征目标值与因子内其余所有值的视觉差异。
**FactorAtlas**：由SNU团队构建的程序化渲染测试集，包含8形状×12色调×10图案×24干扰变体共23,040张图像。
**精确组合检索（Exact Compositional Retrieval）**：查询同时指定多个因子值，正确图像必须在所有维度上精确匹配。
**全局对齐（Global Alignment）**：学习跨所有值的统一线性变换改善跨模态对应，与本文值特定方法形成对比。
**支撑大小缩放（Support-Size Scaling）**：研究不同数量校准图像对方向估计质量与检索增益的影响。

## 可复现要素
- **数据集**：FactorAtlas为作者构建的合成数据集，详见附录B；自然图像数据集为公开数据（DTD、Fashionpedia、COCO-Facet、UT-Zappos）。
- **代码/权重**：论文未提供代码开源声明，使用公开模型权重（openai/clip-vit-base-patch16、google/siglip2-*.pytorch）。
