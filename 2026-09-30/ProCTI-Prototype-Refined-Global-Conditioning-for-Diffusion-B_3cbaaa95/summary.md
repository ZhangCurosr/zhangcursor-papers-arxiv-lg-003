# 论文速读：ProCTI-Prototype-Refined-Global-Conditioning-for-Diffusion-B

## 一句话总结
提出 ProCTI 框架，通过可学习的全局原型库检索数据集级先验，并与局部上下文融合，增强扩散模型时间序列插补性能，尤其在局部观测稀疏或噪声大时显著提升精度。

## 研究问题与动机
1. **现有扩散插补方法过度依赖局部上下文**：如 CSDI、MTSCI 等方法仅用当前或相邻窗口的观测值进行反向扩散条件化，当局部信息缺失或噪声干扰时，重建不确定性高。
2. **全局数据集结构隐式编码**：传统方法将全局模式隐含在模型参数中，缺乏显式利用跨样本的周期性、趋势等数据集级特征。
3. **局部条件与全局条件的信息互补性未经验证**：理论层面尚未明确全局条件何时能严格降低插补误差，缺乏对两者作用机制的清晰界定。

## 核心贡献（创新点）
1. **提出原型条件扩散框架 ProCTI**：设计可学习原型库，通过交叉注意力为每个输入窗口检索实例相关的属性级全局上下文，与局部信号融合后指导反向扩散过程，实现更准确的插补。
2. **建立局部‑全局条件化的理论框架**：引入潜在‑ regime 数据模型，从条件熵、得分函数分解和最小均方误差三个角度证明全局条件能严格降低插补误差，并给出其生效的等价条件。
3. **在五个真实数据集上系统评估**：ProCTI 在随机缺失设置下全面优于九个基线（包括扩散模型、RNN、Transformer 等），MAE 较最强扩散基线 FGTI 提升约 3%–30%；在属性缺失场景下，部分数据集仍保持最优或次优。
4. **揭示全局条件的适用边界**：理论分析与特征相关性实验表明，当缺失变量与观测变量存在强交叉特征冗余时（Y ⊥ Z | O），简单回归方法更具竞争力，全局条件增益有限；反之，在 regimes 结构丰富的数据上 ProCTI 优势显著。

## 方法详解
1. **问题设定**：多元时间序列窗口 x ∈ ℝ^(L×K)，应用人工 keep‑mask m ∈ {0,1}^(L×K) 表示观测位置，训练目标为通过扩散去噪重建缺失值。
2. **Token 构建**：每个时间‑属性位置构造二维 token z = [x, m]，经线性投影映射至 D 维嵌入空间。
3. **窗口级查询向量**：对所有时间‑属性嵌入求平均，得到实例特定的查询 q_b ∈ ℝ^D，捕获窗口内的观测值与缺失模式。
4. **原型库与交叉注意力**：维护可学习原型库 P = {p_m}_{m=1}^M（p_m ∈ ℝ^D），通过多头交叉注意力从 q_b 检索全局上下文 c_b，再经投影 W_r 得到属性级 regime 向量 r_b ∈ ℝ^K。
5. **频率感知扩散建模**：借鉴 FGTI，将窗口频域分解为高频分量 h^hf（细粒度变化）和主频分量 h^dom（周期/长期趋势）。将 regime 向量 r_b 以可学习标量 α 加到主频分支：h^dom+r = h^dom + α r_b，与高频分量拼接构成最终条件 h。
6. **反向扩散过程**：扩散网络 ε_θ(x_t, t | h) 预测噪声，训练损失为噪声预测的均方误差。推理时，保留原始观测值，仅对缺失位置执行 T 步去噪。
7. **理论支撑**：
   - **引理1**：若全局变量 Z 携带关于缺失值 Y 的额外信息（I(Y;Z|O)>0），则条件熵 H(Y|O,Z) < H(Y|O)。
   - **命题1**：混合条件 h=(O,Z) 下的得分函数可分解为局部得分与 regime 引导项之和，类似 classifier guidance。
   - **命题2**：加入 Z 后最优去噪器的 MMSE 严格减小（或不变），即 E[‖X₀−μ*(X_t,O,Z)‖²] ≤ E[‖X₀−μ*(X_t,O)‖²]。
   - **命题3**：在潜在‑regime 模型下，I(Y;Z|O)>0 ⇔ Y ⊥ Z|O（条件独立不成立） ⇔ 加入 Z 能降低最优预测误差。

## 实验与结果
- **数据集**：Gait（步态）、PhysioNet（临床重症）、Weather（气象）、Beijing（空气质量）、Stock（股价），共五个多元时间序列基准。
- **基线**：BRITS、CSDI、SCINet、TIDER、MTSCI、Diffusion‑TS、iTransformer、FGTI、PaD‑TS，共九个对比方法。
- **评估指标**：MAE、RMSE（越低越好），另含 CRPS、PI90 Coverage、PI90 Width 等概率评估。
- **缺失设置**：随机 Markov 掩码，缺失率 r∈{0.1,0.3,0.5,0.7}；属性缺失（Drop 1/2）全掩某个/某两个属性。
- **核心结果**：
  - **随机缺失**：ProCTI 在全部五个数据集的平均 MAE 上均排名第一，较次优基线 FGTI 的 MAE 降低约 3%–30%（最大提升见于 PhysioNet 和 Stock）。
  - **属性缺失**：Gait、PhysioNet、Beijing 上 ProCTI 多数场景最优；Weather、Stock 上 BRITS 更优，归因于强特征冗余（符合命题3的理论预测）。
  - **概率评估**（PhysioNet、Beijing）：ProCTI 获得最佳或次优 CRPS，PI90 Coverage 接近 90%，在准确性、校准与锐度间取得最佳平衡。
- **消融实验**：完整 ProCTI（含原型库、交叉注意力、可学习 α、注入主频分支）在所有数据集上表现最佳；冻结原型库或使用不可学习 α 均导致性能下降；仅注入高频分支或同时注入双分支效果较差。
- **超参数敏感性**：原型库大小 32 时综合性能最优；α=0.1 在多数数据集上最好。

## 相关工作脉络
1. **扩散时间序列插补**：CSDI（条件得分扩散）、MTSCI（一致性扩散）、FGTI（频域感知扩散）均采用局部观测作为反向过程条件；ProCTI 在此基础上显式引入全局原型检索，弥补局部信息不足。
2. **时空扩散插补**：PriSTI 从地理传感器网络提取粗糙全局先验，但局限于空间相关结构；ProCTI 面向一般多元时间序列，学习数据集级周期/趋势 regimes。
3. **非扩散插补模型**：BRITS（双向 RNN 回归）、TIDER（矩阵分解）、SAITS（自注意力）依赖局部或跨特征统计；ProCTI 在扩散框架内融合全局先验，理论保证更优。
4. **生成式时间序列扩散模型**：Diffusion‑TS、PaD‑TS 侧重无条件生成或人口统计保留；ProCTI 专注于条件插补任务，并建立局部‑全局条件的理论分解。
5. **原型学习在时序中的应用**：ProtoAD（异常检测）、PRIME（医疗插补）、TimeDP/K‑ProtoDiff（生成）使用原型作解释、检索或域提示；ProCTI 将原型作为全局 regime 近似器，通过注意力动态注入反向扩散条件。

## 局限性与未来方向
1. **全局条件增益有条件**：当缺失变量可由观测变量线性/强相关恢复时（Y ⊥ Z|O），原型检索收益有限，此时简单模型可能更优。
2. **原型库可解释性不足**：实验显示 32 个原型被广泛使用，缺乏直观的 regime 语义解释，难以直接洞察学到的全局模式。
3. **非平稳 regimes 假设**：当前原型库假设数据集存在稳定且可复现的全局模式，若数据分布随时间漂移（non‑stationary regimes），性能可能下降。
4. **计算开销**：相比部分基线，ProCTI 的 GPU 显存占用较高（与 FGTI 相当），在资源受限场景可能成为约束。
5. **未来方向**：原型库可解释性分析、支持非平稳 regimes 的动态更新机制、扩展至更长的跨实体泛化（如不同传感器站、不同患者群体）。

## 研究启发与可借鉴点
1. **全局先验的显式检索机制**：将数据集级结构组织为可学习的原型库，并通过注意力动态检索，为其他生成/补全任务（如图像修复、视频插帧）提供了新的条件化思路。
2. **局部‑全局条件的理论分解**：通过条件熵、得分分解、MMSE 分析阐明两类条件的互补性，可为设计混合条件模型提供严谨的评估标准。
3. **频域分解与 regime 向量融合**：借鉴 FGTI 的频率感知框架，将全局 regime 信号仅注入主频分支（保留高频细节），是一种有效的信号隔离策略。
4. **适用边界的实证验证**：结合特征相关性热力图与理论命题，明确全局条件有效的前提（非强冗余），为方法选择提供决策依据。
5. **跨实体泛化设置**：采用用户/患者/站点划分的实体不相交划分，避免信息泄漏，更贴近真实部署场景，值得在时序建模任务中推广。

## 关键术语表
**ProCTI**：Prototype‑Refined Global Conditioning for Time series Imputation 的缩写，本文提出的基于扩散的全局原型条件插补框架。
**Prototype bank**：可学习的原型集合，用于近似数据集中的重复性全局时序模式（regimes）。
**Cross‑attention**：多头交叉注意力机制，让输入窗口查询向量从原型库中检索相关的全局上下文。
**Regime vector**：实例特定的属性级向量 r_b，由原型检索得到，反映该窗口所处的全局运行状态。
**Local conditioning**：仅由当前窗口的观测值（及缺失模式）派生的条件信号 h_loc。
**Global conditioning**：由数据集级结构（原型库）和当前观测共同决定的条件信号 h_glob。
**Hybrid conditioning**：局部与全局条件信号的融合 h = ψ(h_loc, h_glob)。
**Latent‑regime data model**：假设每个窗口关联一个未观测的离散 regime 变量 Z，条件 (O,Y)|Z 服从某分布，用于形式化分析全局条件的增益边界。
