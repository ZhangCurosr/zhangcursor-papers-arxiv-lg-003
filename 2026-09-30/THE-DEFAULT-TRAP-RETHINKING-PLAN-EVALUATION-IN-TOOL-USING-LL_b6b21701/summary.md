# 论文速读：THE DEFAULT TRAP: RETHINKING PLAN EVALUATION IN TOOL-USING LLM AGENTS

## 一句话总结
本文提出了配对优先级框架来重新审视工具使用LLM agent中计划评估的问题，揭示了"默认陷阱"现象——当计划优先级与默认行为一致时，移除整个计划可能显示微小影响，但这并不能反映模型对优先级变化的真实响应能力。研究发现模型在优先级切换时具有强控制力，但局部行为响应与任务成功率之间的关系复杂。

## 研究问题与动机
- **核心问题**：现有方法通过移除整个计划来评估计划对agent行为的影响，但这种评估方式存在"默认陷阱"风险——当计划优先级与模型默认行为一致时，移除计划的影响很小，研究者可能错误地得出"模型对优先级不敏感"的结论。
- **优先级控制与移除效果的本质区别**：优先级切换(priority switching)测量的是改变优先级时动作选择的变化；整体计划移除(whole-plan removal)测量的是有无计划之间的差异。前者不能由后者唯一确定。
- **默认行为的呈现依赖性**：无计划状态下的默认行为可能受到信息呈现顺序的影响，这使得单一方向的移除对比具有误导性。
- **局部控制与任务成功的脱节**：即使模型能强响应优先级指令，这种局部控制力并不必然转化为更高的任务成功率或更优的资源使用。

## 核心贡献（创新点）
1. **配对优先级框架**：在具有两个有用读取状态的地方，构建共享无计划参考的配对计划对比协议，建立了连接不同行为对比的会计恒等式，使得优先级切换效应和移除效应的差异可被精确量化。
2. **揭示"默认陷阱"现象**：通过3,200个决策窗口的实验，证明两个executor模型在优先级切换时表现出强控制力（D_A=67-99个百分点），但移除效应差异显著（R_A=6-24个百分点），打破了用单一移除对比推断优先级响应能力的假设。
3. **呈现顺序干预实验**：在2,160个决策窗口中，反转账户列表顺序使默认目标选择变化63.3-98.3个百分点，而优先级切换效应保持在96.7-100.0个百分点，证明默认行为高度依赖呈现方式而优先级控制稳健。
4. **联合评估协议**：首次在相同的1,080个完整任务episode中同时测量局部选择、任务成功率和资源消耗，发现成功率变化范围在-19.4到+8.3个百分点之间，所有Retail和Airline区间包含零值，表明局部响应与任务效用不完全对应。

## 方法详解
- **配对计划设计**：对于每个任务，选择具有两个有用信息目标A和B的状态，构建两个计划P_A和P_B，它们共享大部分指导文本，仅在连续的优先级跨度上 differ（如"A先于B"vs"B先于A"）。
- **五条件执行协议**：每种文本条件定义三个输入条件：P_A、P_B和共享的无计划条件∅。每个计划执行两次（重复执行），无计划执行一次，共5次独立执行。
- **会计恒等式**：定义了优先级切换效应D_A = p_A(P_A) - p_A(P_B)，移除效应R_A = p_A(P_A) - p_A(∅)，以及默认到B的对比G_A = p_A(∅) - p_A(P_B)，满足D_A = R_A + G_A。
- **九类结果记录**：端点Y(z)记录为A读取、B读取、OTHER（其他读取）、BOTH（两者都读）、ERROR（工具/参数错误）、YIELD（无工具调用响应）、WRITE（未改变状态或超出批准读取集的行动）、BUDGET（耗尽10次模型响应）。
- **统计估计**：对Retail和Airline使用客户聚类bootstrap重采样（10,000次），报告95%置信区间；AgentDojo结果描述四个固定应用世界。
- **列表顺序干预**：固定语义ID、计划和业务状态，仅反转账户记录列表顺序，产生40×2×3×3×3=2,160个决策窗口。
- **完整任务评估**：使用 Retail（15任务）、Airline（13任务）、AgentDojo（12任务），共1,080个episode，60次executor响应和16次模拟用户响应的预算限制。

## 实验与结果
- **数据集**：Retail（96任务，44客户）、Airline（28任务，20客户）、AgentDojo（36任务，4个固定世界：travel、Slack、workspace、banking），来自τ-bench、τ²-Bench和AgentDojo基准。
- **执行模型**：gpt-5.6-luna (Luna)、gpt-5.4-mini (Mini)、gemini-3.8-flash (Gemini)，使用medium reasoning effort，4,096或8,192 token输出上限，每次响应最多一个工具调用，最多10次响应。
- **主要结果**：
  - **优先级控制强**：所有六个领域/模型组的D_A在67.36-99.11个百分点之间（表1），证明模型对优先级指令响应强烈。
  - **移除效应不对称**：R_A在5.73-24.11之间，远小于D_A；R_B普遍大于R_A。
  - **默认陷阱明显**：以Retail/Luna为例，p_A(P_A)=90.89%，p_A(∅)=84.90%，p_A(P_B)=0.26%，D_A=90.63但R_A=5.99，G_A=84.64。
  - **呈现顺序效应**：反转列表顺序使默认A选择下降63.3-98.3个百分点（图2），但优先级控制在两种顺序下保持100.0或96.7个百分点。
  - **成功率变化有限**：完整任务评估中，计划vs无计划的成功率差异在-19.4到+8.3个百分点之间，所有Retail/Airline客户区间包含零（表2、图3）。
  - **资源消耗增加**：Airline/Gemini在有计划时token消耗增加47.5%-52.6%，但调用次数差异区间包含零。

## 相关工作脉络
1. **计划与执行研究**：ReAct（Yao et al., 2023）、Plan-and-Solve（Wang et al., 2023）、ReWOO（Xu et al., 2023）等分离或交织推理与工具使用；本文聚焦于已生成计划的输入响应性测量。
2. **计划合规性研究**：Liu et al. (2026) 研究计划移除、阶段编辑、重排序等；本文关注更窄的干预——配对优先级对比与共享无计划参考。
3. **可控归因方法**：Ning et al. (2026) 使用四种匹配条件分解二次传递增益；本文的会计恒等式扩展了这一思路，连接不同计划-行动对比。
4. **呈现与选择偏差**：Position bias研究（Lu et al., 2022; Liu et al., 2024; Blankenstein et al., 2026）关注提示顺序和工具选择偏好；本文通过交叉账户顺序与计划优先级，直接测试默认行为的呈现依赖性。
5. **Agent评估基准**：PlanBench（Valmeekam et al., 2023）、WebArena（Zhou et al., 2024）、AgentBoard（Ma et al., 2024）；本文连接局部控制与任务成功，使用τ-bench和AgentDojo。

## 局限性与未来方向
- **局部控制与任务成功的因果链未明确**：虽然发现强优先级控制，但未能证明这种控制如何传递到最终任务成功率，中间决策环节的影响机制尚不明确。
- **AgentDojo仅限于四个固定应用世界**：结果推广性受限，缺乏更广泛的动态环境验证。
- **计划结构贡献未隔离**：组件研究表明单句优先级即可产生强控制，但完整计划结构中额外文本的具体贡献难以区分（是长度、语义还是脚手架效应）。
- **多智能体场景未涉及**：论文主要关注单agent执行，未扩展到多agent系统中的计划传递与协调。
- **评估窗口限于初始读取**：full-task评估中的D_A仅在第一次端点测量，未覆盖后续决策的优先级响应。

## 研究启发与可借鉴点
1. **配对干预协议的可迁移性**：引入会计恒等式D_A = R_A + G_A的框架可应用于其他干预评估场景，帮助区分不同因果路径的贡献，建议在其他agent研究中也采用联合报告优先级响应、默认行为和任务结果。
2. **呈现顺序作为混淆变量**：列表顺序干预实验设计值得借鉴，可用于检测其他评估中潜在的呈现偏差，建议在agent评测中标准化信息呈现顺序或报告其对结果的影响。
3. **多维度评估指标的联合报告**：将局部选择概率、任务成功率、资源消耗在同一实验中联合测量，有助于发现"高响应低收益"等现象，避免单一指标误导，建议在后续研究中采用类似的综合评估框架。
4. **重复执行与bootstrap估计**：使用5次执行（重复2次+无计划1次）和10,000次客户聚类bootstrap的方法提高了估计稳定性，适用于小规模但需要精确估计的agent实验。
5. **保留所有端点类别的完整性分析**：不仅关注A/B选择，还保留OTHER、BOTH、ERROR等类别，提供了更全面的视角，建议同行研究也避免仅报告二元结果的简化分析。

## 关键术语表
**默认陷阱(Default Trap)**：当计划的优先级与模型默认行为一致时，移除整个计划显示微小影响，从而错误推断模型对优先级变化不敏感的风险。
**优先级控制(Priority Control/Directional Control)**：通过切换计划中的优先级指令所导致的目标选择概率变化，测量模型对给定优先级的响应能力。
**移除效应(Removal Effect)**：比较有计划与无计划条件下指定端点的概率变化，反映整个计划的存在与否对行为的影响。
**会计恒等式(Accounting Identity)**：D_A = R_A + G_A，连接优先级切换效应、移除效应和默认到替代计划的对比，约束不同计划-行动对比的报告方式。
**决策窗口(Decision Window)**：从执行开始到测量的目标读取或记录的停止事件的区间，用于局部行为分析。
**覆盖率(Coverage)**：选择恰好一个指定目标（A或B）的概率C(z) = p_A(z) + p_B(z)，反映目标特异性。
**呈现顺序干预(Presentation Order Intervention)**：固定语义目标身份和业务状态，仅反转信息列表的显示顺序，测试默认行为对呈现的敏感性。
**β-bench / τ²-Bench**：用于评估对话型agent的真实域交互基准，包含Retail和Airline等客户服务的模拟环境。
