# 论文速读：THE DEFAULT TRAP: RETHINKING PLAN EVALUATION IN TOOL-USING LLM AGENTS

## 一句话总结
论文提出配对优先级框架，揭示工具使用LLM Agent评估中的"默认陷阱"：当计划优先级与默认行为一致时，移除计划可能显示微小变化，但这被错误解读为Agent对替代优先级不敏感；实际上优先级切换可强效引导选择，而移除效果取决于呈现顺序决定的默认基线。

## 研究问题与动机
- **默认陷阱问题**：现有研究常仅测量"移除整个计划"对Agent行为的影响，但小移除效果可能被误读为"Agent对替代优先级响应弱"，而实际上优先级切换可能产生大幅影响
- **参考基线的呈现依赖性**：无计划时的默认行为本身受信息呈现顺序影响，导致不同研究使用不同参考基线时无法直接比较
- **缺乏系统的双向测量方法**：现有工作缺少将方向控制（优先级切换）与移除效果（计划有无）联合报告的标准协议
- **局部控制与任务完成的脱节**：即使模型对优先级强烈响应，实际任务成功率变化可能很小或不确定，需要联合评估

## 核心贡献（创新点）
1. **配对优先级框架**：通过比较两个不同优先级的计划与共享的无计划参考，建立双向测量协议，本质区别在于同时捕捉优先级切换和移除两种不同干预的效应
2. **会计恒等式**：推导 $D_A = R_A + G_A$，将优先级切换效果分解为移除效果和默认到对比计划的差异，本质区别在于提供了可验证的分解关系而非简单对比
3. **列表顺序干预实验**：通过反转账户记录顺序固定语义目标，证明默认行为随呈现顺序大幅偏移（63.3–98.3个百分点），而优先级控制保持稳定
4. **联合评估协议**：首次在同一任务序列中同时测量局部选择控制、任务成功率和资源消耗，揭示强局部响应与小成功率变化共存的发现
5. **组件控制研究**：比较完整计划与单优先级句子，证明单句即可产生强控制，额外文本效果因组而异

## 方法详解
**配对优先级设计**：
- 每个任务包含两个可用信息目标A和B，执行顺序不影响业务状态
- 计划 $P_A$ 和 $P_B$ 共享引导内容，仅改变一个连续优先级段
- 每个文本条件定义三个输入状态：$P_A$、$P_B$、无计划 $\emptyset$
- 每计划执行两次，无计划执行一次，共5次独立执行

**关键度量与恒等式**：
$$D_A = p_A(P_A) - p_A(P_B), \quad R_A = p_A(P_A) - p_A(\emptyset)$$
$$D_A = R_A + G_A, \quad G_A = p_A(\emptyset) - p_A(P_B)$$
其中 $D_A$ 为方向控制（优先级切换效应），$R_A$ 为移除对比（计划减无计划），$G_A$ 为默认到B计划的对比

**覆盖校正**：
$$D_A = R_A + R_B + p_O(P_B) - p_O(\emptyset)$$
$p_O$ 为其他结果类别概率，$C(z) = p_A(z) + p_A(z)$ 为分支覆盖率

**实验设计**：
- 配对优先级研究：160个任务，3,200个决策窗口
- 列表顺序干预：40个任务，2,160个窗口，3个执行器
- 全任务评估：40个任务，1,080个 episode
- 组件控制研究：60个状态，3,240个窗口

**统计方法**：客户聚类bootstrap，10,000次重采样，报告95%区间

## 实验与结果
**数据集与基线**：
- **Retail**（96任务，44客户）+ **Airline**（28任务，20客户）：来自 τ²-Bench，使用gpt-5.6-luna(Luna)、gpt-5.4-mini(Mini)、gemini-3.8-flash(Gemini)
- **AgentDojo**（36任务，4固定世界）：旅行、Slack、工作区邮件、文档日历、银行

**主要结果**：
| 领域/模型 | $D_A$ (方向控制) | $R_A$ (移除效果) | $N_A$ (重复分歧) |
|-----------|------------------|------------------|------------------|
| Retail/Luna | 90.63 | 5.99 | 4.69% |
| Retail/Mini | 76.82 | 5.73 | 13.02% |
| Airline/Luna | 99.11 | 9.82 | 1.79% |
| Airline/Mini | 92.86 | 24.11 | 8.93% |
| AgentDojo/Luna | 67.36 | 18.75 | 4.17% |
| AgentDojo/Mini | 68.75 | 20.83 | 5.56% |

**最强结果**：Airline/Luna 方向控制达99.11个百分点，几乎完美优先级遵循；列表顺序干预中，逆转账户列表使默认A选择下降63.3–98.3个百分点（所有6个组严格为正），而方向控制在两种顺序下保持96.7–100.0个百分点

**成功率变化**：全任务评估中，计划vs无计划的成功率差异跨度为−19.4至+8.3个百分点，Retail/Airline所有客户区间包含零，AgentDojo表现不稳定

## 相关工作脉络
- **ReAct/Plan-and-Solve**： interleaving推理与工具调用，本文聚焦于计划如何改变行动选择的测量而非生成计划
- **Plan compliance研究**（Liu et al., 2026）：研究计划移除、阶段编辑、重新排序等，本文聚焦于配对优先级的双向对比
- **Reasoning perturbation**（Lanham et al., 2023）：测量输出敏感性，本文扩展至工具选择的行为控制测量
- **Position bias研究**：文献记录位置影响选择，本文通过列表顺序干预直接操控呈现以分离默认与优先级效应
- **Agent evaluation**：PlanBench/WebArena/AgentBoard评估规划与交互，本文提供计划影响的因果测量协议

## 局限性与未来方向
- **任务选择偏差**：仅选择具有两个可互换读取状态的任务，可能不适用于串行依赖场景
- **AgentDojo有限描述**：AgentDojo结果基于4个固定世界，难以推广到动态环境
- **计划可见性**：计划在整个执行过程中可见，未测试计划被驱逐后的保留效果
- **单优先级句子的边界**：组件研究显示单句可产生强控制，但完整计划结构的具体贡献未明确分离
- **多智能体扩展**：结论基于单Agent设置，未测试多Agent协调场景

## 研究启发与可借鉴点
1. **会计恒等式思维**：将观测效应分解为多个可解释分量（$D_A = R_A + G_A$），为评估研究提供因果分解框架
2. **呈现顺序作为实验变量**：通过操控信息顺序固定语义目标，分离呈现效应与内容效应，可迁移至任何涉及列表/顺序的评估
3. **双向对比设计**：同时测量"计划A vs 计划B"和"计划A vs 无计划"，避免单一对比的误导性结论
4. **重复执行与 bootstrap**：每条件多次独立执行+客户聚类重采样，提高估计可靠性并量化不确定性
5. **联合评估指标**：同时报告局部控制、任务成功率和资源消耗，揭示行为响应与实际价值之间的脱节

## 关键术语表
**Default trap（默认陷阱）**：当计划优先级与默认行为一致时，移除计划产生小变化，被错误解读为Agent对替代优先级响应弱
**Paired-priority framework（配对优先级框架）**：比较两个优先级不同的计划与共享无计划参考的测量协议
**Priority control（优先级控制）**：改变计划优先级导致的行动选择概率变化，即 $D_A = p_A(P_A) - p_A(P_B)$
**Removal contrast（移除对比）**：计划存在与不存在时的概率差异，即 $R_A = p_A(P_A) - p_A(\emptyset)$
**List-order intervention（列表顺序干预）**：反转账户记录顺序而固定语义目标，测试默认行为的呈现依赖性
**Coverage（覆盖率）**：选择指定目标A或B的概率之和，$C(z) = p_A(z) + p_B(z)$
**Decision window（决策窗口）**：从输入到第一次测量读取或停止事件的执行片段
