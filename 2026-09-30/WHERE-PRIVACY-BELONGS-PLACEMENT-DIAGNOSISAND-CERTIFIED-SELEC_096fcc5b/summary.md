# 论文速读：WHERE PRIVACY BELONGS: PLACEMENT DIAGNOSIS AND CERTIFIED SELECTION FOR PRIVATE COUNTER-FACTUAL EXPLANATIONS ON GRAPHS

## 一句话总结
本文诊断了图神经网络（GNN）反事实解释中隐私保护的"放置困境"——无论先在图上加噪再解释（导致虚假翻转），还是先解释再加噪发布（无法认证完整释放），现有方案均失败；提出 PRIVCFS 方法，通过固定数据无关候选宇宙 + 有效性门控 + 指数机制，首次实现对完整反事实解释发布的纯 ε-DP 认证保证。

## 研究问题与动机
1. **GNN 反事实解释的隐私悖论**：要生成反事实解释必须读取目标节点邻域结构（敏感），但发布的解释本身（删除了哪些边、掩码了哪些特征）又会泄露该结构，形成两难。
2. **图级放置的致命缺陷**：先在邻接矩阵上加 DP 噪声再解释，会污染预测目标——在需要回应的边缘节点（low-margin nodes）上，噪声恰好翻转预测，导致"虚假翻转"（spurious flips），即对加噪图有效但对真图无效的解释。
3. **解释级放置的认证缺口**：在干净图上解释、仅对发布结果加噪的标准启发式方案，其宣称的 per-entry 预算（ε≈7.2）并不认证完整释放物；实测全释放预算高达 573–753（Cora）/ 256（CiteSeer），最坏情况下被删除边的条目 AUC=1.0（完全泄露）。
4. **缺乏可认证的图反事实解释机制**：现有隐私保护工作聚焦于模型训练或图发布，无人研究"在私有物之上计算解释"的认证问题；解释级 DP 需要满足全局敏感性有界且支持独立，而优化器输出不具备此性质。

## 核心贡献（创新点）
1. **图解释隐私的放置诊断框架**：形式化定义图级 DP vs 解释级 DP 两条路径，识别预测污染与虚假翻转为图级放置的两类失败模式，并证明启发式输出扰动在其声称预算下不可认证（附录 A 重审数据支撑）。
2. **PRIVCFS：构造可认证的隐私选择器**：用"从固定数据无关候选宇宙中选择"替代"通过优化器解释后扰动输出"，边候选来自公共先验图、特征候选来自公共模式，利用 no-op 语义保证邻域图共享同一输出支撑，通过指数机制实现完整释放物的纯 ε-DP。
3. **全局敏感性可直接由效用裁剪界定**：有效性门控 + 截断效用设计使得全局敏感性 Δu≤1，无需像优化器基线那样做灵敏度分析，且该界由公开裁剪范围直接给出。
4. **隐私-效用前沿作为可购买价格表**：在 ε=8 时采样释放保留 83–97% 的支持受限非隐私最优值，隐私噪声是管线中最便宜环节，主导成本是公共披露强度的单调可测量代价。
5. **最强可行性审计实证强化理论保证**：最优似然比边推断攻击在认证释放上平均 AUC=0.50、最坏对 0.59，远低于启发式基线的最坏条目 AUC=1.0；方法可迁移至 15K 节点图且保持 0.96 有效释放率。

## 方法详解
**威胁模型与问题设定**：给定属性图 G=(V, E, X) 与预训练冻结的 GNN 分类器 f，对目标节点 v 的反事实解释为干预集 S=(S_E, S_F)，其中 S_E⊆E 为删除的边、S_F⊆[F] 为掩码的特征维度，使得反事实图 G' = G⊖S 的预测翻转；威胁模型为边级别 pure ε-DP（δ=0），邻域图为恰好相差一条无向边的图对。

**3.3 数据无关候选支撑**：候选宇宙 C_v 由两部分构成：
- 边候选 U_v^E = {(v,u) : u ∈ N_pub(v)}，截断至前 k_E=12 对，来自公共先验图快照 G_pub（固定、独立于当前私有边集）；关键设计：删除不存在的边是 no-op（G⊖(u,w)=G），因此邻域图共享相同输出支撑。
- 特征候选 U_v^F 为 frozen backbone 的一阶影响排名 top-k_F 非零维度，按 |x_{v,d}|·||W_{:,d}^{(1)}||_2 排序，特征掩码在边邻域模型下灵敏度为零。
Lemma 1 证明：给定固定公共上下文，相邻图对具有完全相同的候选宇宙 C_v，支撑与数据无关。

**3.4 有效性门控效用与全局敏感性**：候选 S 的效用定义为：
- u(G,S) = w_c（空干预）/ w_f + w_c·γ(s) + w_p·plaus(S_E)（有效翻转）/ 0（其他），其中 s=|S_E|+|S_F|，γ(s)=1−s/k_max，plaus(S_E)=|S_E∩E|/|S_E| 奖励真正存在的边。
- Lemma 2 证明全局敏感性 Δu≤w_f+w_c+w_p=1：翻转指示器是二元的、大小项数据无关、plaus 只随一条差异边变化且变化量≤1，因此凸组合的界由公开裁剪范围直接给出，无需优化器灵敏度分析。

**3.5 指数机制与保证**：释放机制对固定支撑 C_v 应用指数机制：
P(M(G)=S) = exp(ε·u(G,S)/(2Δu)) / Σ_{S'∈C_v} exp(ε·u(G,S')/(2Δu))
- Theorem 1（纯 DP）：M 对 replace-one 边邻域满足纯 ε-DP（δ=0），认证的是完整释放物 S，而非逐坐标。
- Corollary 1（可组合性）：k 次自适应查询消耗 kε 预算。
- Theorem 2（效用保证）：以概率≥1−β，采样结果的效用不低于 OPT − (2Δu/ε)(ln|C_v|+ln(1/β))。
 backbone 为两层 GCN，候选评估在二跳诱导子图上精确执行（与全图前向 bit-identical）。

## 实验与结果
**数据集**：Cora（2,708 节点）、CiteSeer（3,327 节点）为主基准，ogbn-arxiv-core（15,000 节点，160,944 边，40 类）用于规模迁移测试；backbone 为两层 GCN（hidden=32），Cora test acc=0.809，CiteSeer test acc=0.682。

**评估指标**：valid-CF（真实翻转率）、targeted success（翻转向亚军类别）、intervention size、empty-output rate、utility regret、release collision、spurious-flip/prediction-pollution rates。

**主要结果（Table 1 & 2）**：
- 在一般人群（16 公共采样目标）ε=8 时：Cora ρ=0.5 的 valid rate=0.139（保留 starCF 84%），CiteSeer ρ=0.5 为 0.139（保留 95%）；边际人群（10 最低 margin 节点）ε=8 时：Cora ρ=0.7 达 0.614（保留 97%），CiteSeer ρ=0.7 达 0.534（保留 94%）。
- 隐私噪声是最便宜阶段：边际人群上 privacy price≈−0.02，公共先验是主导购买（−0.40），支撑限制次之（−0.07/−0.17）。
- 预算-有效曲线符合理论预期：边际 Cora ρ=0.7 下 utility regret 从 ε=0.5 的 0.368 降至 ε=8 的 0.164。

**机制对比（Table 3）**：
- 认证列是决定性维度：PrivCF-out（启发式）声称 ε=7.2 但实际全释放预算 573–753，不可认证；已认证的只有 PrivCF-SGD、PRIVCFS 及 per-edge randomized response。
- 同操作空间下图级 DP 的 valid rate=0.000（预测污染率 60–92%，虚假翻转 23–37%），而解释级 PRIVCFS 在相等支撑下保持 0.485/0.349（Cora/CiteSeer，ε=8, ρ=0.5）。
- 纯 ε-DP vs (ε,δ)-DP：PRIVCFS 提供纯保证，PrivCF-SGD 为 (ε,δ)。

**审计（Sec 4.5）**：
- 实测最大灵敏度 |Δu|=0.96≤1.0，最大释放比值 35.3，比 e^8≈2981 低两个数量级。
- 91–96% 相邻对产生完全相同的效用向量（piecewise constant），最优似然比攻击平均 AUC=0.50、最坏对 0.59，远低于启发式基线最坏条目 AUC=1.0。
- 迁移至 15K 节点：ε=8 下 valid rate=0.963±0.026（边界协议），collision 降至 0.02–0.03%。

**最强结果**：在 ogbn-arxiv-core 边界人群上，ε=8、ρ=0.5 的 certified arm 达到 valid rate 0.963（接近天花板 1.000），AUC 审计最坏值仅 0.59。

## 相关工作脉络
1. **图反事实解释基线**：CF-GNNExplainer（连续松弛边删除）、RCExplainer（分布偏移鲁棒）、GCFExplainer（全局解释）、COMBINEX（特征+结构统一目标）——均假设完全访问干净图， naïvely 上游加隐私会破坏它们精心设计的边缘节点解释。
2. **图学习中的 DP**：DP-SGD（Abadi et al., 2016）+ Opacus 是标准训练隐私方案；局部私有 GNN（Sajadmanesh & Gatica-Perez, 2021）与节点级私有训练（Daigavane et al., 2022; Zhang et al., 2024）保护模型或图发布，但未研究"在私有物上解释"的认证问题。
3. **解释隐私与反事实公平**：表格式数据的 DP 反事实工作（Yang et al., 2022; Nomeir et al., 2024; Vo et al., 2023; Harder et al., 2020）不涉及图结构泄露渠道；解释输出泄露研究（Zhao et al., 2021）与边推断攻击（Wu et al., 2022）量化了图泄露风险。
4. **经典私有选择机制**：McSherry & Talwar（2007）的指数机制是本文的理论基石，本文将其适配至图反事实解释场景，通过 no-op 语义 + 有效性门控满足支撑独立与全局敏感性有界两个关键条件。
5. **启发式输出扰动的认证缺口**：附录 A 的重审揭示 per-entry 假设下的 ε≈7.2 实际对应全释放预算 573–753，≈8–9% 相邻对存在优化器盆地跳跃（ basin jumps），局部 Lipschitz 正则无法弥补，本文据此定位与已有工作的本质差异。
6. **因果评估与反事实学习综述**：Cai et al.（2025）的概率必要充分性评估、Guo et al.（2025）的反事实学习综述为本工作提供方法论背景，但均未涉及隐私认证维度。

## 局限性与未来方向
1. **支撑限制的成本**：可用反事实解释的质量受限于固定候选宇宙的大小与公共先验质量；当前 k_E=12、k_F=12 的配置在一般人群上 starCF 仅 0.15–0.31，限制了绝对有效率的提升。
2. **公共先验的披露决策**：方法要求数据所有者披露公共快照 G_pub（强度 ρ），这本身是一次公开披露，需由数据所有者在用户同意下决策，论文未讨论快照发布本身的隐私成本。
3. **特征维度的 DP 未覆盖**：当前保证仅针对边邻域，特征矩阵 X 的条目级保护被留为未来工作（论文明确声明）。
4. **模型训练的额外泄露通道**：若 backbone 在私有边集上训练，模型发布构成独立泄露通道，本文定理条件于公共固定 f，未处理此场景。
5. **候选枚举的计算复杂度**：虽在二跳诱导子图上精确评估，但支持大小随度数增长，论文在附录 F 指出需有界度数条件才能保证每查询成本与节点数 N 无关。
6. **软效用 vs 门控效用**：软变体（部分credit for margin reduction, Δu=0.8）实验表现相近，但论文未系统比较两者在极端 margin 分布下的行为差异。

## 研究启发与可借鉴点
1. **"构造可认证"而非"优化后扰动"的设计哲学**：通过将候选宇宙固定为数据无关集合、利用 no-op 语义保证支撑独立，直接规避了优化器输出的敏感性分析难题——这一思路可迁移至其他结构化输出（如树、序列）的私有发布场景。
2. **全局敏感性可由公开裁剪范围直接界定**：有效性门控 + 截断效用的设计使 Δu≤1 不依赖优化器灵敏度分析，为其他需要 DP 保证的选择/排序任务提供了可复用的效用设计模板。
3. **隐私-效用前沿作为可购买价格表的部署视角**：将成本分解为支撑限制、公共先验、隐私噪声三个阶段，并量化各阶段的边际代价，为数据所有者的隐私预算分配提供了可操作的决策框架。
4. **审计驱动的理论强化**：用最优似然比攻击对认证释放进行实证审计，与理论保证形成互补，这种"理论+最强可行审计"的双重验证策略值得在隐私机制论文中推广。
5. **公共信息选择 vs 私有 margin 路由的区分**：论文明确指出"谁被解释"应基于公共信息（无隐私成本），而基于 margin 的门控会泄露私有信息——这一部署设计原则对面向高风险决策的解释服务具有直接指导价值。

## 关键术语表
**Counterfactual Explanation（反事实解释）**：回答"对输入做最小何种改变会使预测翻转？"的可 recourse 解释范式，是图神经网络解释的黄金标准。
**Spurious Flip（虚假翻转）**：在加噪图上被识别为有效翻转、但在真图上无效的干预，源于图级 DP 对边缘节点预测目标的污染。
**Prediction Pollution（预测污染）**：DP 噪声恰好改变低 margin 节点的预测，导致解释器优化错误目标。
**Exponential Mechanism（指数机制）**：McSherry & Talwar（2007）提出的 DP 选择原语，以概率 ∝ exp(ε·u/2Δu) 从候选集采样，保证全局敏感性有界时的纯 ε-DP。
**No-op Semantics（空操作语义）**：删除不存在的边等于不做任何操作，保证不同邻域图共享相同候选宇宙与输出支撑。
**Support Independence（支撑独立性）**：候选宇宙 C_v 仅依赖公共上下文（快照、特征、backbone、目标），与私有边集无关，是应用指数机制的前提条件。
**Global Sensitivity Bound（全局敏感性界）**：效用函数在相邻图对上的最大变化量 Δu，本文通过效用裁剪直接得到 Δu≤1，无需优化器灵敏度分析。
**Likelihood-Ratio Audit（似然比审计）**：用最优攻击者对发布分布计算 AUC，本文以此实证验证理论 DP 保证的实际强度。
