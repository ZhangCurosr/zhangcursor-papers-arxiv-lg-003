# 论文速读：VSTRESS-CORRELATION-AWARE-AUDITING-ANDADAPTIVE-BUDGET-ALLOCA

## 一句话总结
本文提出 VSTRESS 可审计重放合约与 VSTRESS-CA 相关性感知分配策略，通过估计验证器间的条件边际信息量，在固定调用预算下实现自适应通道选择与停止决策，从而在质量控制、覆盖率与成本之间取得帕累托改进，并提升下游强化学习推理（RLVR）性能。

## 研究问题与动机
1. **重复调用验证器的价值边界不清**：多次调用仅在额外视角包含独立信息时才有效；若错误相关，额外调用仅增加成本而不提供新证据。
2. **现有方法缺乏相关性感知**：多数投票、随机分配等策略未显式建模验证器间的依赖结构，可能在高相关场景下浪费预算或降低质量。
3. **审计边界缺失**：现有工作未将验证器选择、停止决策与事后 oracle 评分分离，难以保证在线决策不受泄漏标签影响。
4. **成本‑质量‑覆盖率权衡难以量化**：固定预算下需在广度（覆盖更多项）与冗余（深度调用）间权衡，但缺少基于条件信息的自适应分配机制。

## 核心贡献（创新点）
1. **提出可审计的二进制反馈合约（VSTRESS）**：在线聚合器仅接收污染视图并冻结账本后，才加入清洁 oracle 评分，防止事后偏差。
2. **定义条件边际可判别性（D(j|S)=I(Y;V_j|V_S)）**：从密封校准集估计未查询验证器对已观测通道的增量信息价值，而非依赖边际准确率。
3. **设计 VSTRESS-CA 自适应分配策略**：基于条件信息、不确定性折扣与成本归一化，实现通道选择、选择性停止与依赖偏移回退。
4. **机制‑到‑学习的全链路验证**：通过固定预算控制、重复验证器重放与下游 RLVR 任务，证明相关性感知分配在质量‑覆盖率‑成本前沿上的优势。

## 方法详解
1. **任务定义与信息边界**：对每个样本 i，清洁二值 oracle $y_i$ 在线聚合时不可见；系统仅接收 5 个污染视图 $v_{i,1:5}$（来自声明的污染家族）。决策账本冻结后，离线才连接 oracle 计算指标。
2. **四阶段框架**：
   - **校准**：在密封集上估计各通道可靠性、失败率、成本与条件依赖性。
   - **在线获取**：VSTRESS-CA 基于当前已查询集合 $S_t$ 选择下一个通道 $j_t^*$。
   - **决策冻结**：聚合器在加入 oracle 前冻结预测、abstention 状态与已获取通道集。
   - **事后评分**：在 Held‑out 验证器轨迹与 RLVR 任务上计算质量‑覆盖率‑成本向量。
3. **污染与聚合**：对称污染率 $\rho$ 下，多数投票错误概率为 $\sum_{j=3}^5 \binom{5}{j}\rho^j(1-\rho)^{5-j}$；固定 abstention 规则要求 $a = \max(z,5-z)/5 \ge 0.8$ 才接受决策。
4. **相关性感知分配**：
   - 条件边际可判别性：$D(j|S) = I(Y;V_j|V_S)$，从校准行估计。
   - 效用函数：$U(j|S) = \frac{[\hat{D}(j|S) - \beta \hat{\sigma}_{j,S}]_+}{\hat{c}_j + \epsilon}$，其中 $\hat{\sigma}$ 为 bootstrap 标准误，$\hat{c}_j$ 为校准成本。
   - 选择 $j_t^* = \arg\max_{j\notin S_t} U(j|S_t)$。
5. **停止与依赖偏移回退**：
   - 若 $\max(\hat{p}_t,1-\hat{p}_t) \ge \tau$ 则接受预测。
   - 否则继续查询仅当 $|S_t| < B$ 且 $\max_{j\notin S_t} U(j|S_t) > \gamma$；否则 abstain。
   - 部署窗口使用 Jensen‑Shannon 统计量 $S_{\text{shift}}$ 检测分布偏移；当 $S_{\text{shift}} > \delta$ 时禁用通道偏好，回退到精确停止策略。
6. **训练与推理合约**：在线路径每视图记录二值投票、实现标识、延迟与成本；账本线性扩展 $O(k)$。离线评分按 manifest 键排序后 $O(n)$ 连接 oracle。

## 实验与结果
- **数据集**：512 条有序记录，GSM8K 载荷提供不变标识；7 个确定性污染种子重放。
- **评估基线**：固定多数投票（majority‑5）、随机分配、边际准确率贪婪选择、忽略条件依赖的边际信息策略。
- **主要结果**：
  - **固定预算比较**（表 2）：VSTRESS-CA 以 3.4216 次调用/item 达到平衡准确率 0.6538、选择性准确率 0.6892、RLVR 分数 0.6417，优于广度（0.6048）与冗余（0.6375）。
  - **污染强度边界**（表 3）：对称污染 35% 时 majority‑5 提升 BA 0.1161（0.6578→0.7739）；65% 时损失 0.1226 分。
  - **依赖诊断**（表 1）：跨家族通道误差重叠最低（0.3187），条件边际增益最高（0.0913）。
  - **下游 RLVR**（表 4、6）：VSTRESS-CA 在 matched candidate cache 下任务得分 0.6417，较单调用基线提升 +0.0290。
- **最强结果**：VSTRESS-CA 在相同候选池与预算下取得最高 BA 与 RLVR 分数，证明相关性感知分配的价值。

## 相关工作脉络
1. **Reward‑model 与 verifier 评估**（Lambert et al., 2024）：关注 held‑out 质量与失败模式，但未提供统一的可审计边界与条件信息量化。
2. **RLVR 研究**（Lightman et al., 2024）：使用可验证奖励训练推理系统，但未解决重复调用中的相关错误与预算分配。
3. **选择性预测与拒绝选项**（Geifman & El‑Yaniv, 2019）：形式化 abstention，但缺乏基于条件互信息的通道选择机制。
4. **相关错误与验证器鲁棒性**（Kim et al., 2025; Chen et al., 2025）：指出验证器错误的相关性，但未将其转化为在线分配信号。
5. **定位差异**：VSTRESS 将相关性从事后警告变为可审计的分配决策，并通过固定预算控制、依赖偏移检测与下游 RLVR 验证形成完整链条。

## 局限性与未来方向
1. **校准样本效率**：条件信息估计在通道池较大时噪声增大，需更多校准样本。
2. **因果独立未保证**：低测量依赖不意味着因果独立，共享训练数据、模板或基础设施可能隐藏共同失败原因。
3. **依赖偏移检测局限**：仅监测表决频率、分歧与失败率，潜伏性偏移可能未被捕获。
4. **任务与池规模受限**：当前为二元决策任务与有界验证器池，扩展至多类别与大规模池需结构化估计器。
5. **未来方向**：动态依赖建模、在线校准更新、多类别扩展、更大规模真实部署验证。

## 研究启发与可借鉴点
1. **条件边际可判别性作为选择指标**：可迁移至模型路由、工具调用、多代理协同等场景，替代基于边际准确率或模型身份的启发式选择。
2. **可审计合约设计**：“在线冻结‑事后评分”模式适用于任何需要防止标签泄漏的评估协议，提升可复现性与公信力。
3. **成本归一化与不确定性折扣**：效用函数 $U(j|S)$ 的设计可推广至资源分配、实验设计、主动学习等预算敏感决策问题。
4. **依赖偏移回退机制**：Jensen‑Shannon 统计量检测分布漂移并自动降级策略，可为在线学习系统提供鲁棒性保障。
5. **质量‑覆盖率‑成本联合前沿**：将三项指标共同报告而非单一准确率，为算法比较提供更全面的决策依据。

## 关键术语表
- **VSTRESS**：可审计二进制反馈重放合约，在线聚合器冻结账本后才连接清洁 oracle 评分。
- **VSTRESS-CA**：相关性感知分配策略，基于条件边际信息、成本归一化与不确定性折扣进行通道选择与停止决策。
- **条件边际可判别性（D(j|S)）**：未查询验证器 j 在已观测集合 S 下对标签 Y 的增量互信息 $I(Y;V_j|V_S)$。
- **分离 oracle**：清洁标签与在线决策过程隔离，仅在校准后离线使用，防止事后偏差。
- **依赖偏移**：部署期间验证器输出的联合分布与校准分布发生偏离，由 Jensen‑Shannon 统计量检测。
- **选择性准确率**：仅对聚合器接受的项计算的准确率，反映高置信度子集的精度。
- **平衡准确率（BA）**：正负类召回率的平均值，用于类别不平衡场景。
- **广度 vs 冗余**：广度指用固定预算覆盖更多样本（每样本少调用）；冗余指对少数样本多次调用以提升质量。
