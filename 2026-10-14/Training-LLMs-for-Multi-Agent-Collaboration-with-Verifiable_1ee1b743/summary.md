# 论文速读：Training-LLMs-for-Multi-Agent-Collaboration-with-Verifiable

## 一句话总结
本文提出 CoSIR，通过在简易可验证的评分表环境中进行自博弈强化学习后训练，利用基于贝叶斯团队 surprisal 减少量的细粒度奖励（分享、请求、使用信息）引导 LLM 学会分布式协作行为，并在 7 个未见自然语言任务上实现跨模型的最优泛化，同时保持基础能力不变。

## 研究问题与动机
1. **最终结果反馈过于粗粒度**：多智能体协作的最终任务得分无法区分单条消息对团队决策的真实贡献，难以直接用于训练协作行为。
2. **现有后训练目标未显式建模信息价值**：主流指令微调与多轮任务训练聚焦于执行与遵循，未奖励“共享关键证据”或“请求缺失信息”这类协作核心动作。
3. **开放任务中信息价值难以验证**：在自然语言复杂任务里，事实分布、缺失来源及消息贡献度通常不可观测，导致无法自动计算通信奖励。
4. **LLM 团队存在系统性协作失效**：即便团队整体掌握足够信息，个体仍可能隐瞒发现、不澄清疑问、忽略队友输入或盲目跟从多数派，导致团队表现劣于单个智能体。

## 核心贡献（创新点）
1. **可计算的信息价值评估器**：设计贝叶斯评估器，以团队 surprisal 的比特减少量精确衡量每条分享陈述和请求的协作价值，替代粗粒度的结果奖励。
2. **细粒度信用分配机制**：将消息整体信息价值通过 Shapley 边际分配至各评分陈述，并配套正确性验证、捏造惩罚与通信成本，实现 token 级精确奖励。
3. **保留通用能力的后训练框架**：在自博弈 PPO 训练中引入参考模型 KL 惩罚（k₂ 估计）与通用提示模仿损失，确保协作微调不损害数学推理、常识与指令跟随能力。
4. **跨任务协作行为迁移验证**：在 3 个 LLM 骨干与 7 个未见自然语言任务上验证，CoSIR 取得最高聚合得分，并证明学到的共享/请求/整合行为可泛化至自由形式答案生成。

## 方法详解
1. **分布式评分表任务**：每轮生成 k 个选项、m 个属性的表格 V∈{-1,0,+1}^(k×m)，最优选项 y⋆ 为属性总分最高者。n 个 Agent 初始仅获得部分单元格简报 B_i，需通过自然语言轮流交流（可含多条评分陈述和 1 条请求），最后各自私有输出选项选择与计算总分。
2. **贝叶斯评估器与团队 Surprisal**：基于均匀先验与动态规划精确计算后验 P(y|K_i)。定义团队 surprisal Φ(K) = -Σᵢ log₂ P̄(y⋆|K_i)，其中 P̄ 下界截断为 10⁻⁴。信息价值 ΔΦ 即接收新陈述前后 Φ 的减少量（单位：比特）。
3. **分享奖励**：消息价值 I_share(M) = ΔΦ(M)。支持性陈述（源于初始简报或已接收报告）按移除边际或 Shapley 值分配；每条陈述扣除 0.01 通信成本，捏造陈述额外惩罚 0.04。仅依赖当前信息的正确猜测无正奖励。
4. **请求奖励**：评估假设请求被诚实回答时的潜在 ΔΦ，乘以持有者剩余轮次出场概率 p_next 与已接收折扣 δ_c，上限 2 比特。请求需在合理目标处发出，否则记为无效并惩罚 0.10。
5. **私有答案奖励**：r_i^answer = P̄(ŷ_i|K_i) + (1/k)Σ_o 1[ŝ_io = s_io^K]，分别奖励选项选择的概率合理性（基于当前可用信息而非真相标签）与总分计算的正确性。
6. **自博弈 PPO 训练**：每轮 60 局游戏，16 个策略候选并发采样。陈述信用直接绑定 token，行动/选择/总分优势在候选组内中心化。早期通过演示样本注入高质量请求模板辅助探索。优化器 AdamW8bit，clip bounds [0.8, 1.28]，梯度范数限制 1.0，学习率 1e-5（前两轮）→ 2e-5（第三轮）。

## 实验与结果
1. **实验设置**：骨干模型 Qwen3-8B、Qwen3-4B、Gemma-3-4B-it。基线包括 Base（初始权重）、ToM、TalkHier（推理时增强）、Outcome-RL（仅奖励最终团队结果）。评测 7 个未见任务：HiddenBench、SILO-BENCH、SplitQA（自建，HotpotQA 桥接问答）、MathChat、BenchForm、Einstein Puzzles、Collaboration Tax。通用能力评测 GSM8K、MMLU、IFEval。
2. **主要结果**：CoSIR 在所有模型上 SUM 得分最高。Qwen3-8B 达 384.44（ΔSUM = +31.85），Qwen3-4B 达 357.87（+24.70），Gemma-3-4B-it 达 235.94（+27.92）。较 Outcome-RL 分别提升约 20.7、22.9、24.9 分；较 ToM/TalkHier 提升 19.8~24.9 分。7 个任务中 CoSIR 在大多数单项上领先或持平最佳。
3. **行为分析**：训练后私有事实披露率显著提升（如 Qwen3-8B 在 HiddenBench 从 68.5%→74.3%，SplitQA 从 52.9%→58.2%）；响应队友、列出原始数据、首条消息即披露证据的比例均上升。MAST 失败分析显示“忽略队友输入”（26.3%→22.8%）、“未经澄清直接推进”（36.4%→32.0%）、“未完整验证”（51.3%→45.9%）下降，团队协作失败率整体下降。
4. **能力保留**：GSM8K、MMLU、IFEval 得分变化仅 ±0.6~0.8 个百分点，证明协作后训练未造成能力坍塌。

## 相关工作脉络
1. **推理时协作增强（ToM, TalkHier）**：在现有模型上添加思维链描述或层级修订流程，不改模型参数；CoSIR 直接更新模型策略，通过 RL 内化协作行为。
2. **协作后训练（MA-PoRL, MAGRPO）**：以最终答案对错或团队结果作为奖励；CoSIR 将奖励信号前置到单条信息陈述与请求，实现更细粒度的信用分配。
3. **合成环境迁移（SPIRAL, MARS）**：在无零和/合作游戏中训练通用推理或博弈策略；本文同样利用简单环境，但目标专为“分布式信息下的共享/请求/整合”设计，并验证向开放 NLP 任务的迁移。
4. **信息不对称下的 SFT 训练（Peng et al., 2025）**：用监督学习训练通信轨迹，推理时配合验证器；CoSIR 摒弃 SFT 与外部验证器，完全依赖环境内置的贝叶斯可微评估器进行端到端 RL。
5. **多智能体失败分类（MAST, Cemri et al., 2025）**：提供失败 taxonomy 框架；本文首次将其用于量化协作 RL 训练前后具体失败类型的变化，揭示奖励设计对特定失败模式的针对性改善。

## 局限性与未来方向
1. **环境与任务覆盖有限**：仅验证 3 个骨干与 7 个任务，部分推理时方法在特定组合上仍更强，未覆盖长程、多模态或真实世界场景。
2. **未能消除所有协作失败**：重复步骤、部分信息隐瞒等 MAST 类别改善不明显，说明当前奖励对“结构性冗余沟通”约束不足。
3. **依赖玩具环境的可验证性**：团队 surprisal 奖励建立在完整状态已知且可精确后验的前提上；扩展至开放任务需解决状态不可观测时的信息价值近似评估问题。
4. **未来方向**：探索基于语言模型自身不确定性或外部工具验证的信息价值代理信号；结合检索增强或工具调用，将训练范式迁移至开放域多智能体协作；设计更鲁棒的信用分配以抑制无效重复通信。

## 研究启发与可借鉴点
1. **Surprisal 作为协作信用分配信号**：用概率后验变化（而非结果成败）量化单条消息价值，为多智能体 RL 的 credit assignment 提供了一条可解释、可微、免人工标注的新路径，可迁移至代码协同、科学假设生成等需隐式分工的场景。
2. **保留通用能力的双正则化策略**：参考模型 KL 惩罚（k₂ 估计）+ 通用提示 imitation loss 的组合，在强后训练任务中有效防止能力退化，值得在其他领域 RLHF/GRPO 流程中复用。
3. **自博弈候选组中心化优势设计**：同一对话历史下多候选并行评分并中心化，既保证比较公平又稳定策略梯度，比全局轨迹优势方差更小，适合通信型多步任务。
4. **自建 Bridge QA 基准 SplitQA**：将 HotpotQA 桥接问答按段落分配给不同 Agent，以 exact-match 投票机制评估自由形式答案生成，为衡量“分布式证据整合”提供了可直接复用的评测模板。

## 关键术语表
**Team Surprisal**：团队对正确选项的“意外量”，定义为各智能体对正确选项后验概率负对数之和，用于度量信息交换带来的认知不确定性下降。
**CoSIR**：Collaboration via Surprisal-based Information Rewards，本文提出的协作后训练方法，通过信息 surprisal 减少量驱动共享、请求与使用行为。
**Information Record (K_i)**：智能体 i 的完整信息状态，由初始简报 B_i 与已接收评分陈述 R_i 拼接而成，作为贝叶斯评估器的输入。
**Shapley Allocation**：将一条消息的整体信息价值按各陈述的边际贡献平均分配至 token 的博弈论方法，用于细粒度信用分配。
**Outcome-RL**：与 CoSIR 相同的自博弈训练框架，但仅使用最终团队结果作为奖励，用于对比验证细粒度信息奖励的有效性。
**MAST**：Multi-Agent System Failure Taxonomy，系统化的多智能体对话失败分类框架，本文用于量化训练前后各类协作失效的变化。
**Self-play RL**：同一模型参数同时扮演团队中所有角色进行交互博弈，通过持续收集对手/队友同质化轨迹实现策略迭代。

- **代码/权重**：论文未提及代码仓库或模型权重开源链接。
- **关键超参**：采样温度 1.2，最大生成长度 1,024 tokens；每状态 16 策略候选 / 8 答案候选；每轮 60 局游戏；PPO clip [0.8, 1.28]，双裁剪边界 3；梯度范数 1.0；参考 KL 系数 0.1；通用提示模仿系数 0.1；优化器 AdamW8bit；学习率 1e-5（R1-R2）→ 2e-5（R3），共 3 轮；硬件 2× NVIDIA H100 + 4× Intel Gaudi 2，每轮约 5 小时。
