# 论文速读：Towards-Continual-Learning-Mitigating-Forgetting-With-Subspa

## 一句话总结
本文提出了**子空间调优（Subspace Tuning, SST）**方法，通过将优化器产生的权重更新投影到预训练权重的低能量奇异子空间中，有效缓解大语言模型在新任务微调过程中的灾难性遗忘，同时保持较强的目标任务学习能力。SST 是一种优化器无关、可与多种微调配方（如 SFT、SDFT）自由组合的通用方法。

## 研究问题与动机
1. **灾难性遗忘阻碍 LLM 持续学习**：大语言模型通过微调获取新技能，但传统监督微调（SFT）会破坏预训练阶段习得的通用能力（如指令遵循、编码、推理），导致灾难性遗忘。
2. **现有方法不足以根本解决问题**：自蒸馏（SDFT）和强化学习等方法通过数据层面间接控制更新方向，在长推理轨迹或复杂任务上仍存在显著遗忘；后修复方法（如 KL 修复）仅能部分恢复能力。
3. **更新方向是关键但被忽视**：近年研究发现，预训练权重的**主奇异方向**与模型核心功能紧密相关，而强化学习的更新集中在非主方向，因此较少遗忘。SST 直接对此进行显式约束。
4. **现有正交微调方法的局限**：如 Sculpting 和 OPLoRA 等通过因式分解低秩适配器实现子空间约束，但仅在初始化时构建谱分解，无法动态适应，且对状态优化器（如 Adam）的保护存在泄漏。

## 核心贡献（创新点）
1. **提出优化器无关的子空间投影机制**：SST 对最终优化的权重更新进行双侧投影而非对原始梯度投影，确保即使使用 Adam 等状态优化器也能完全消除对主奇异方向的更新，与 Sculpting 仅投影梯度形成本质区别。
2. **引入基刷新（Basis Refresh）机制**：SST 支持每 K 步重新计算受保护子空间的 SVD，以当前的权重为锚点重新对齐保护方向，在严格保护和持续适应能力之间提供可调节的控制手柄。
3. **证明 SST 与多种微调配方正交可组合**：SST 不仅适用于标准 SFT，还能与自蒸馏（SDFT）、Muon 优化器等结合，在所有组合下均显著提升保留能力而不牺牲目标任务性能。
4. **揭示遗忘的本质是权重更新的空间位置**：通过控制玩具实验和系统对比，证明灾难性遗忘并非学习的必然代价，而是取决于更新在权重重力场中的"落点"，为持续学习提供了新的理论视角。

## 方法详解
**核心投影公式（Eq. 3）**：
对每个受约束的权重矩阵 $W$（如 attention 的 q/k/v/o 和 MLP 的 gate/up/down），计算其 SVD 分解，取前 $k = \lfloor r \cdot \min(d_{out}, d_{in}) \rfloor$ 个主奇异向量构成保护子空间。对优化器产生的最终更新 $\Delta W$，应用双侧投影：
$$\Pi(\Delta W) = (I - U_k U_k^\top) \Delta W (I - V_k V_k^\top)$$
即只保留"自由-自由"（free-free）块，丢弃涉及任何保护方向的三个交叉块。

**为何必须投影优化器更新而非梯度**：
对状态优化器（如 Adam），其对梯度进行逐坐标的预条件缩放，该操作与投影算子不交换。投影梯度后，Adam 的非对角缩放会使部分更新重新渗入保护子空间（实验显示 69% 泄漏）；只有投影最终的应用更新才能精确限定。

**基刷新机制（Refresh）**：
默认情况下 $U_k, V_k$ 从预训练权重固定计算。对于较长训练或连续微调，当前权重的奇异向量可能旋转出初始基。SST 每 K 步（如 R10=每10步、R100=每100步）将 $W_{ref}$ 更新为当前权重并重新计算 SVD，为新方向的适应打开空间，但代价是逐步偏离原始预训练基。

**算法流程（Algorithm 1）**：
1. 初始化 $W_{ref}$ 为预训练权重，计算 $U_k, V_k$ 及互补投影算子 $Q_U, Q_V$。
2. 对每个优化步骤：计算完整梯度 → Adam 更新一阶/二阶矩 → 产生临时更新 $\tilde{W}_{t+1}$ → 计算 $\Delta W = \tilde{W}_{t+1} - W_t$ → 应用 $\Pi(\Delta W)$ 替换原始更新。
3. 每隔 K 步，刷新 $W_{ref}$ 并重新计算 SVD。
4. Embedding 和 LayerNorm 等参数不受约束。

## 实验与结果
**模型与数据集**：以 Qwen3-8B 为主，辅以 Qwen2.5-7B-Instruct、Olmo-3-7B-Think，在 Science、Finance (FinQA)、Pathology、Medicine 四个领域的 CoT 推理数据上进行微调。

**评估指标**：
- 目标任务精度（ID）：各领域测试集准确率
- 先验能力保留：GPQA-Diamond、MMLU-Pro、GSM8K、HumanEval、IFEval 五项基准的平均分
- 策略漂移：在 WikiText-2 上的 KL 散度

**关键结果**：
- **Qwen3-8B（SST 无刷新 vs SFT）**：在 Science 上 ID 从 77.6 提升至 80.1，但 LM avg 仅下降 1.0 分（vs SFT 下降 25.5 分）；FinQA 上 ID 73.0 vs 72.3，LM avg 反而上升 1.3 分（vs SFT 下降 57.3 分）
- **Scaling 模型尺寸**：从 1.7B 到 14B，SFT 遗忘 30-40 分，SST 从 8B 起遗忘降至约 1 分以内（Table 2, Table 3）
- **Scaling 数据量**：SFT 随数据增加遗忘单调恶化，SST 保持平稳且目标精度持续提升（Figure 3）
- **策略漂移**：SST 产生的 KL 漂移比 SFT 少 2–4 倍（Figure 7）
- **连续微调**：在两阶段（A→B）和三阶段（FinQA→Pathology→Science）实验中，SST 实现累积学习；SFT 每新训练一个阶段，先前技能下降 18-28 分
- **刷新机制**：R10 比无刷新在高目标任务精度上显著改善（FinQA ID 从 73.0 到 75.3），但保留能力略有下降（约 3-5 分）
- **与其他子空间方法对比**：SST 无刷新在四领域平均 LM avg 仅降 1.4 分，而 Sculpting 降 26.1 分、OPLoRA 降 17.9 分（Table 5）

## 相关工作脉络
1. **经典持续学习方法（A-GEM、GiUL)**：基于过去任务数据或梯度约束更新方向，需要任务边界和重放数据，SST 无需这些数据但依赖预训练权重谱。
2. **数据层面的遗忘缓解（SDFT, RLVR）**：SDFT 通过自蒸馏生成近似 on-policy 的监督信号间接限制遗忘；RLVR 通过强化学习使更新远离主方向。SST 从更新几何层面直接约束，与这些数据方法正交可组合。
3. **Sculpting [34]**：冻结每个权重的顶部奇异向量并在 Adam 步骤前投影梯度，但仅去除"保护-保护"块而遗漏交叉块，且对梯度投影导致 Adam 下仍有 69% 泄漏。
4. **OPLoRA [54]**：冻结权重并训练低秩适配器 BA，通过固定投影器将更新限定在自由子空间。其实验仅保护 16-128 个方向（远少于 SST 的 99%），且无法刷新基。
5. **PiSSA / MiLoRA / CorDA**：参数高效微调方法中，PiSSA 在初始化时用主奇异值初始化 LoRA 但随后训练全部参数；MiLoRA 通过固定低秩因式分解适配次要奇异分量，但无法刷新。SST 直接投影稠密更新且支持动态刷新。
6. **KL 正则化（反向 KL penalty）**：直接惩罚策略漂移，实验证明弱正则化无效、强正则化抑制学习，无法复现 SST 的学习-保留权衡（Table 6, Figure 16）。

## 局限性与未来方向
1. **最优学习率需重新调优**：SST 改变了可行更新几何，其最优学习率不一定等于无约束 SFT，尚未建立完全调优的学习-保留帕累托前沿。
2. **百亿级以上参数模型的扩展未验证**：实验最大到 32B，需验证 SST 在数百亿参数规模下的表现。
3. **长任务序列下的累积误差**：三阶段实验展示了改进但仍存在小幅遗忘，更长的连续微调链（>5 阶段）的表现待探索。
4. **刷新策略为固定间隔**：当前每 K 步固定刷新，未利用每批次更新信息动态调整保护基，效率有优化空间。
5. **对非思考型指令模型的适用性有限**：Table 1 显示在 r=0.99 时自由子空间太小无法容纳任务（Science 域需用 r=0.90），说明保护率需要根据模型大小和任务复杂度动态调整。

## 研究启发与可借鉴点
1. **更新几何视角分析遗忘**：将灾难性遗忘归因于"更新在权重空间中的落点"而非单纯的数据分布偏移，为理解遗忘提供了新的理论框架，可迁移到任何微调场景的遗忘诊断。
2. **投影优化器更新而非梯度的技术决策**：通过严格的控制实验（Figure 4）证明了对 Adam 等状态优化器必须投影最终更新而非原始梯度，这一方法论对设计其他正交约束方法有参考价值。
3. **刷新机制作为调节学习-保留权衡的手柄**：R10/R100/无刷新构成连续的"保护强度-适应自由度"光谱，可作为实际部署中根据下游任务动态调整保守/激进程度的实用工具。
4. **模型合并的干扰分析框架**：附录 B.1 展示了独立训练的 SST 专家合并时干扰显著小于 SFT 专家，揭示了子空间约束对模型集成的正面效应，值得在多任务 LoRA 合并研究中进一步探索。
5. **保持基分布接近性的间接获益**：SST 不仅提升量化指标，还保留了响应长度、推理深度等定性行为（Figure 8），提示在持续学习评估中应纳入分布级指标而非仅依赖任务准确率。

## 关键术语表
**SST (Subspace Tuning)**：一种通过双侧正交投影将权重更新限定在非主奇异子空间内的微调方法，用于缓解灾难性遗忘。
**灾难性遗忘 (Catastrophic Forgetting)**：模型在学习新任务时显著丢失已有能力的现象，是持续学习的核心障碍。
**主奇异方向 (Principal Singular Directions)**：预训练权重矩阵中对应最大奇异值的左右奇异向量，与模型核心功能紧密相关。
**基刷新 (Basis Refresh)**：SST 中每 K 步重新以当前权重为锚点计算 SVD 以更新保护子空间的机制。
**SDFT (Self-Distillation Fine-Tuning)**：一种 on-policy 微调方法，通过在模型自身分布内重写监督信号来减少遗忘。
**LM avg**：五项通用基准（GPQA、MMLU-Pro、GSM8K、HumanEval、IFEval）的平均得分，作为先验能力的综合指标。
**策略漂移 (Policy Drift)**：微调后模型分布与预训练基分布之间的 KL 散度，衡量行为的偏离程度。
**自由-自由块 (Free-Free Block)**：权重更新中同时不在输出和输入保护子空间中的分量，是 SST 唯一允许的更新部分。
