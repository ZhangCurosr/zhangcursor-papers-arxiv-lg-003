# Sharp Stationary Gaussian Approximation for Constant-Stepsize SGD

Junghoon Seo

PIT IN Corp., South Korea

## Abstract

We prove a sharp Gaussian approximation for the invariant law of constant-stepsize SGD with bounded additive noise generated by an exogenous uniformly ergodic Markov chain. For a smooth, strongly convex objective with a Lipschitz Hessian and nondegenerate long-run noise covariance, the centered iterate normalized by the square root of the stepsize is $O ( { \sqrt { \alpha } } ) .$ close in 1-Wasserstein distance to its limiting Gaussian. The proof combines blockwise Gaussian comparison with long-run contraction. A four-state example gives a matching lower bound although the one-time noise marginal is symmetric and every nonzero-lag autocovariance vanishes. In this example, an adjacent third-order mixed moment produces the leading correction.

## 1. Introduction

Constant-stepsize stochastic gradient descent (SGD) is naturally studied through its invariant distribution when the deterministic drift is stable and the gradient noise persists (Pflug, 1986; Dieuleveut et al., 2020; Chen et al., 2022). We consider

$$
X _ { k + 1 } = X _ { k } - \alpha \nabla f ( X _ { k } ) + \alpha \xi ( Z _ { k } ) , \qquad k \geq 0 ,\tag{1}
$$

where $f : \mathbb { R } ^ { d }  \mathbb { R }$ is smooth and strongly convex, $\left( Z _ { k } \right)$ is an exogenous Markov chain with invariant distribution $\pi ,$ and $\xi : Z \to \mathbb { R } ^ { d }$ is centered under $\pi$ . Exogeneity means that the transition kernel of $\left( Z _ { k } \right)$ is independent of the iterate. At stationarity, $X _ { k }$ and $Z _ { k }$ are generally dependent because the iterate contains the accumulated efect of earlier Markov states.

Let $x _ { \star }$ be the unique minimizer of f and set $H = \nabla ^ { 2 } f ( x _ { \star } )$ . The scale $\sqrt { \alpha }$ is suggested by a simple variance calculation. Over $O ( \alpha ^ { - 1 } )$ efective steps, the recursion accumulates noise increments of size α, so their total standard deviation is of order ${ \sqrt { \alpha ^ { - 1 } } } \alpha = { \sqrt { \alpha } }$ For a stationary chain, temporal dependence changes the covariance through the long-run covariance

$$
\Sigma _ { M } = \mathbb { E } [ \xi ( Z _ { 0 } ) \xi ( Z _ { 0 } ) ^ { \top } ] + \sum _ { \ell \ge 1 } \mathbb { E } \Big [ \xi ( Z _ { 0 } ) \xi ( Z _ { \ell } ) ^ { \top } + \xi ( Z _ { \ell } ) \xi ( Z _ { 0 } ) ^ { \top } \Big ] .\tag{2}
$$

Under the assumptions below, this series converges absolutely. The Gaussian benchmark is $\gamma = \mathcal { N } ( 0 , \Sigma )$ , where

$$
H \Sigma + \Sigma H = \Sigma _ { M } .\tag{3}
$$

This is the covariance equation for the Ornstein–Uhlenbeck approximation obtained by linearizing the drift at x (Pflug, 1986; Chen et al., 2022).

Main contribution. Wang et al. (2026) give an ${ \cal O } ( \sqrt { \alpha } \log ( 1 / \alpha ) )$ upper bound for the $W _ { 1 }$ distance between the $\alpha ^ { - 1 \bar { / } 2 }$ -scaled centered stationary law and its Gaussian limit. We improve this to $O ( \sqrt { \alpha } )$ (Theorem 1) and give a four-state example attaining the matching lower bound (Theorem 2).

Proof architecture. The proof separates a finite-block Gaussian approximation from longrun contractivity. One block contains $n = \lceil T / \alpha \rceil$ updates, so its deterministic contraction factor is approximately $e ^ { - m T }$ . Within a block, we linearize the drift and use a Poisson equation to decompose the Markovian noise into a martingale diference and a coboundary. The propagated Gaussian initial condition smooths Lipschitz test functions, which permits a second-order Lindeberg expansion. A second Poisson equation telescopes the state-dependent conditional covariance. A coalescent coupling and strong convexity then transfer the block estimate to the invariant law.

Related work. Stationary and difusion descriptions of constant-stepsize stochastic approximation appear in Pflug (1986); Mandt et al. (2017); Dieuleveut et al. (2020), and general stationary weak limits are developed by Chen et al. (2022). Poisson-equation methods for Markovian stochastic approximation are classical (Benveniste et al., 2012; Kushner and Yin, 2003; Fort, 2015). Quantitative analyses use concentration, Lyapunov methods, coupling, and linear stochastic-approximation techniques (Thoppe and Borkar, 2019; Chen et al., 2024; Mou et al., 2024; Durmus et al., 2025). Stationary bias and prelimit coupling under Markovian noise are studied in Huo et al. (2026, 2024); Allmeier and Gast (2024); Merad and Ga¨ıfas (2025); Zhang et al. (2026). Dependent-data and finite-horizon Gaussian approximations provide complementary benchmarks (Zhang and Xie, 2026a; Wei et al., 2025; Haque et al., 2026; Kong and Srikant, 2026). Appendix $\mathrm { A }$ discusses connections with recent Gaussian approximation results Zhang and Xie (2026a); Haque et al. (2026); Zhang and Xie (2026b,c).

Fix $d \geq 1$ . Vector norms and $\langle \cdot , \cdot \rangle$ are Euclidean, matrix inequalities use the Loewner order, and $\operatorname { L i p } ( h )$ denotes the Lipschitz constant of h. For a bounded function g taking values in a normed space, let $\| g \| _ { \infty } = \operatorname* { s u p } _ { z } \| g ( z ) \|$ , where the pointwise norm is understood from context and is displayed explicitly for matrices when needed. ## 3. Block approximation and stationary transfer

Define the scaled iterate and its deterministic update map by

$$
Y _ { k } = \frac { X _ { k } - x _ { \star } } { \sqrt { \alpha } } ,
$$

$$
\mathcal T _ { \boldsymbol \alpha } ( \boldsymbol y ) = \boldsymbol y - \sqrt { \alpha } \nabla f ( \boldsymbol x _ { \star } + \sqrt { \alpha } \boldsymbol y ) ,\tag{14}
$$

$$
Y _ { k + 1 } = \mathcal { T } _ { \alpha } ( Y _ { k } ) + \sqrt { \alpha } \xi ( Z _ { k } ) .\tag{15}
$$

For $\alpha \leq L ^ { - 1 }$ , the mean-value theorem and (5) give

$$
\Vert T _ { \alpha } ( y ) - T _ { \alpha } ( y ^ { \prime } ) \Vert \leq ( 1 - m \alpha ) \Vert y - y ^ { \prime } \Vert .\tag{16}
$$

Thus one step has a contraction gap of order α. Taking $n = \lceil T / \alpha \rceil$ steps turns this into a fixed contraction factor of order $e ^ { - m T }$

Let $P _ { \alpha }$ be the transition kernel of $( Y _ { k } , Z _ { k } )$ , also use $P _ { \alpha }$ for its Markov operator on functions, write $\lambda P _ { \alpha } ^ { n }$ for the law after n steps from λ, and let $\nu = \gamma \otimes \pi$ . The next propositions isolate the block approximation and joint stability. Appendix B gives a proof guide, followed by the formal arguments in Appendices D and E.

Proposition 3 (One-block Gaussian approximation) For every fixed $T > 0$ , there are $C _ { T } < \infty$ and $\alpha _ { T } > 0$ such that, if $( Y _ { 0 } , Z _ { 0 } ) \sim \gamma \otimes \pi$ and $n = \lceil T / \alpha \rceil$ , then

$$
W _ { 1 } ( { \mathcal { L } } ( Y _ { n } ) , \gamma ) \leq C _ { T } { \sqrt { \alpha } } , \qquad 0 < \alpha \leq \alpha _ { T } .\tag{17}
$$

For $\kappa > 0$ , equip $\mathbb { R } ^ { d } \times Z$ with the cost

$$
d _ { \alpha , \kappa } ( ( y , z ) , ( y ^ { \prime } , z ^ { \prime } ) ) = \| y - y ^ { \prime } \| + \kappa \sqrt { \alpha } \mathbf { 1 } _ { \{ z \neq z ^ { \prime } \} } .\tag{18}
$$

For product-space laws λ and λ<sup>′</sup> with finite first Y-moments, $W _ { d _ { \alpha , \kappa } } ( \lambda , \lambda ^ { \prime } )$ is the supremum of $| \textstyle { \int h \mathrm { d } \lambda - \int h \mathrm { d } \lambda ^ { \prime } } |$ over measurable functions $h : \mathbb { R } ^ { d } \times Z  \mathbb { R }$ satisfying $| h ( y , z ) - h ( y ^ { \prime } , z ^ { \prime } ) | \leq$ $d _ { \alpha , \kappa } ( ( y , z ) , ( y ^ { \prime } , z ^ { \prime } ) ) ,$ ). Every coupling upper-bounds this distance by its expected cost. The factor $\sqrt { \alpha }$ matches the size of one noise increment in (15).

Proposition 4 (One-block contraction of the joint process) There are $T > 0 , 0 <$ $\kappa < \infty , q \in ( 0 , 1 )$ , and $\alpha _ { c } > 0$ such that, with $n = \lceil T / \alpha \rceil$

$$
W _ { d _ { \alpha , \kappa } } ( \lambda P _ { \alpha } ^ { n } , \lambda ^ { \prime } P _ { \alpha } ^ { n } ) \leq q W _ { d _ { \alpha , \kappa } } ( \lambda , \lambda ^ { \prime } )\tag{19}
$$

for all probability measures with finite first Y -moments and every $0 < \alpha \le \alpha _ { c }$

The one-block approximation uses two Poisson equations. We state them here because they identify the two places where serial dependence enters the proof.

Lemma 5 (Noise and covariance correctors) Let $\mathcal { F } _ { k } = \sigma ( Z _ { 0 } , \ldots , Z _ { k } )$ and define

$$
V = \sum _ { j \geq 0 } P ^ { j } \xi ,\tag{20}
$$

$$
D _ { k + 1 } = V ( Z _ { k + 1 } ) - P V ( Z _ { k } ) ,\tag{21}
$$

$$
\begin{array} { r } { \mathcal { C } ( z ) = P ( V V ^ { \top } ) ( z ) - ( P V ) ( z ) ( P V ) ( z ) ^ { \top } , } \end{array}\tag{22}
$$

$$
W = \sum _ { j \geq 0 } P ^ { j } ( { \mathcal { C } } - \Sigma _ { M } ) .\tag{23}
$$

Both series converge uniformly, with nuclear-norm convergence for W. Moreover, $V - P V =$ $\xi , \left( D _ { k + 1 } \right)$ is a bounded martingale diference sequence, and

$$
\mathbb { E } [ D _ { k + 1 } D _ { k + 1 } ^ { \top } \mid \mathcal { F } _ { k } ] = \mathcal { C } ( Z _ { k } ) , \qquad \int \mathcal { C } \mathrm { d } \pi = \Sigma _ { M } .\tag{24}
$$

The exact identities

$$

$$

will be used for summation by parts and covariance telescoping.

The first corrector turns the Markov sum into a martingale sum plus a bounded coboundary remainder. The second turns predictable covariance fluctuations into an exact telescoping sum. ## 4. Proof of Theorem 1

Fix the block duration from Proposition 4, let $n = \lceil T / \alpha \rceil$ , and start from $( Y _ { 0 } , Z _ { 0 } ) \sim \gamma \otimes \pi$ We follow the comparison path and record the order of each error.

Step 1: linearize the drift. Set $A = I _ { d }$ − αH. This matrix is symmetric. Let

$$
\bar { Y } _ { k + 1 } = A \bar { Y } _ { k } + \sqrt { \alpha } \xi ( Z _ { k } ) , \qquad \bar { Y } _ { 0 } = Y _ { 0 } .
$$

The Lipschitz Hessian condition and Taylor’s formula give

$$
\| T _ { \alpha } ( y ) - A y \| \leq \frac { M } { 2 } \alpha ^ { 3 / 2 } \| y \| ^ { 2 } .\tag{26}
$$

Stationarity of the Markov chain and absolute summability of $\left( \Gamma _ { \ell } \right)$ imply

$$
\operatorname* { s u p } _ { 0 \leq k \leq n } \mathbb { E } \| \bar { Y } _ { k } \| ^ { 2 } \leq \mathrm { t r } ( \Sigma ) + ( T + 1 ) C _ { \Gamma } .
$$

Coupling $Y _ { k }$ and $\bar { Y } _ { k }$ with the same Markov path, then iterating (16) and (26), yields

$$
\mathbb { E } \Vert Y _ { n } - { \bar { Y } } _ { n } \Vert \leq C _ { T } { \sqrt { \alpha } } .\tag{27}
$$

Step 2: reduce the Markov sum to a martingale sum. For $r = 1 , \ldots , n$ , write $B _ { r } = \sqrt { \alpha } A ^ { n - r }$ . Substituting the first identity in (25) into the explicit linear recursion and applying weighted summation by parts gives

$$
\bar { Y } _ { n } = A ^ { n } Y _ { 0 } + \sum _ { r = 1 } ^ { n } B _ { r } D _ { r } + R _ { V , n } ,\tag{28}
$$

where

$$
R _ { V , n } = { \sqrt { \alpha } } \left[ A ^ { n - 1 } V ( Z _ { 0 } ) - V ( Z _ { n } ) + \alpha \sum _ { j = 1 } ^ { n - 1 } A ^ { n - 1 - j } H V ( Z _ { j } ) \right] .
$$

The first two terms are endpoints, and the sum records the variation of the matrix weights. Since V is bounded, $\| A ^ { j } \| _ { \mathrm { o p } } \leq 1$ , and $\alpha n \leq T + 1$ ，

$$
\| R _ { V , n } \| \leq C _ { T } \sqrt { \alpha } .\tag{29}
$$

Step 3: replace the martingale increments by Gaussian increments. Let $N _ { r }$ <sup>iid</sup>∼ $\mathcal { N } ( 0 , \Sigma _ { M } )$ be independent of $( Y _ { 0 } , ( Z _ { k } ) )$ ). After restricting $\alpha \leq ( 2 L ) ^ { - 1 } , \mathrm { C o v } ( A ^ { n } Y _ { 0 } ) \succeq c _ { T } I _ { d }$ for some $c _ { T } > 0$ independent of α. Hence the function $\psi ( u ) = \mathbb { E } [ h ( A ^ { n } Y _ { 0 } + u ) ]$ has a bounded and Lipschitz Hessian for every 1-Lipschitz h.

For the rth replacement, let $\begin{array} { r } { U _ { r } = \sum _ { 1 \leq i < r } B _ { i } D _ { i } + \sum _ { r < i < n } B _ { i } N _ { i } } \end{array}$ . Conditional centering cancels the linear terms, while the Taylor remainders total $O ( n \alpha ^ { 3 / 2 } ) = O ( { \sqrt { \alpha } } )$ . With $K _ { r } = B _ { r } ^ { \top } \nabla ^ { 2 } \psi ( U _ { r } ) B _ { r }$ , the second Poisson equation gives

$$
\begin{array} { r } { \displaystyle \sum _ { r = 1 } ^ { n } \mathbb { E } \langle K _ { r } , \mathcal { C } ( Z _ { r - 1 } ) - \Sigma _ { M } \rangle _ { \mathrm { F } } = \mathbb { E } \langle K _ { 1 } , W ( Z _ { 0 } ) \rangle _ { \mathrm { F } } - \mathbb { E } \langle K _ { n } , W ( Z _ { n } ) \rangle _ { \mathrm { F } } } \\ { + \displaystyle \sum _ { r = 1 } ^ { n - 1 } \mathbb { E } \langle K _ { r + 1 } - K _ { r } , W ( Z _ { r } ) \rangle _ { \mathrm { F } } . } \end{array}
$$

The boundary terms are $O ( \alpha )$ , while $\mathbb { E } \| K _ { r + 1 } - K _ { r } \| _ { \mathrm { o p } } = O ( \alpha ^ { 3 / 2 } + \alpha ^ { 2 } )$ . Thus the variation sum is $O ( \sqrt { \alpha } )$ , and

$$
W _ { 1 } \left( { \mathcal { L } } \left( A ^ { n } Y _ { 0 } + \sum _ { r = 1 } ^ { n } B _ { r } D _ { r } \right) , { \mathcal { L } } \left( A ^ { n } Y _ { 0 } + \sum _ { r = 1 } ^ { n } B _ { r } N _ { r } \right) \right) \leq C _ { T } { \sqrt { \alpha } } .\tag{30}
$$

Step 4: identify the target covariance. The Gaussian vector in (30) has covariance $\begin{array} { r } { \Sigma _ { \alpha , n } = A ^ { n } \Sigma A ^ { n } + \alpha \sum _ { j = 0 } ^ { n - 1 } A ^ { j } \Sigma _ { M } A ^ { j } } \end{array}$ . The identities $\Sigma _ { M } = H \Sigma + \Sigma H$ and $A = I _ { d } - \alpha H$ give

$$
\Sigma _ { \alpha , n } - \Sigma = \alpha ^ { 2 } \sum _ { j = 0 } ^ { n - 1 } A ^ { j } H \Sigma H A ^ { j } , \qquad \| \Sigma _ { \alpha , n } - \Sigma \| _ { F } \leq C _ { T } \alpha .\tag{31}
$$

Appendix F converts this covariance error into an $O ( \alpha )$ Wasserstein error. Equations (27), (29), and (30) then prove Proposition 3.

Step 5: contract the joint process and transfer to stationarity. Uniform ergodicity gives a coupling with coalescence time τ satisfying $\mathbb { P } ( \tau > k ) \le C _ { \mathrm { c p l } } \rho _ { \mathrm { c p l } } ^ { k }$ . Under this coupling, strong convexity contracts the iterate distance by 1 − mα after the Markov paths meet, while bounded noise adds at most $2 b \sqrt { \alpha }$ before meeting. Choosing T and κ therefore makes the n-step joint kernel contract by a fixed factor $q < 1$ . Appendix E constructs its unique invariant law $\varpi _ { \alpha }$ and proves $( 1 - q ) W _ { d _ { \alpha , \kappa } } ( \varpi _ { \alpha } , \nu ) \leq ( C _ { T } + 2 \kappa ) \sqrt { \alpha }$ . Projection gives (11), and undoing the scaling gives (12).

## Appendix A. Connections with recent Gaussian approximation results

The CLT for time-varying observables in Zhang and Xie (2026a, Theorem 3) ofers an alternative to our direct Gaussian comparison for the linearized block. Fix $T > 0$ , let $n = \lceil T / \alpha \rceil$ , and set $A = I _ { d } - \alpha H$ . The noise contribution to this block is

$$
\begin{array} { c l c r } { { } } & { { } } & { { S _ { \alpha , n } = \displaystyle \sqrt { \alpha } \sum _ { k = 0 } ^ { n - 1 } A ^ { n - 1 - k } \xi ( Z _ { k } ) = \frac { 1 } { \sqrt { n } } \sum _ { k = 0 } ^ { n - 1 } h _ { \alpha , k } ( Z _ { k } ) , } } \\ { { } } & { { } } & { { { } } } \\ { { } } & { { } } & { { h _ { \alpha , k } ( z ) = \sqrt { n \alpha } A ^ { n - 1 - k } \xi ( z ) . } } \end{array}
$$

For $0 < \alpha \leq \operatorname* { m i n } \{ 1 , L ^ { - 1 } \}$ , these centered observables satisfy $\begin{array} { r } { \operatorname* { s u p } _ { 0 \leq k < n } \| h _ { \alpha , k } \| _ { \infty } \leq \sqrt { T + 1 } b } \end{array}$ Under stationarity, geometric covariance decay gives

$$
\operatorname { C o v } ( S _ { \alpha , n } ) = \alpha \sum _ { j = 0 } ^ { n - 1 } A ^ { j } \Sigma _ { M } A ^ { j } + O ( \alpha ) \longrightarrow \int _ { 0 } ^ { T } e ^ { - t H } \Sigma _ { M } e ^ { - t H } \mathrm { d } t \succ 0 \quad \mathrm { a s ~ } \alpha \downarrow 0 ,
$$

where the error is measured in operator norm. For the fixed chain and horizon, these bounds make the CLT constants uniform for suficiently small α, yielding an $O ( n ^ { - 1 / 2 } ) = O ( { \sqrt { \alpha } } )$ Wasserstein-1 comparison with ${ \mathcal { N } } ( 0 , \mathrm { C o v } ( S _ { \alpha , n } ) )$ . The Gaussian comparator for $A ^ { n } Y _ { 0 } + S _ { \alpha , n } ,$ with $Y _ { 0 } \sim \gamma$ independent of the chain, has covariance $\Sigma + O ( \alpha )$ and is O(α)-close to γ in Wasserstein-1 distance. The nonlinear comparison and joint contraction then yield our stationary bound. Our proof establishes the block comparison directly by Poisson–Lindeberg interpolation.

Haque et al. (2026, Proposition 4.5) obtain a finite-time lower bound for linear stochastic approximation from a nonzero third moment of an i.i.d. noise projection. Our matching stationary lower bound instead isolates temporal dependence: the noise marginal is symmetric and all nonzero-lag autocovariances vanish, yet $\mathbb { E } [ \xi ( Z _ { 0 } ) \xi ( Z _ { 1 } ) ^ { 2 } ] = - 9 / 4$ produces the leading order- $\cdot \sqrt { \alpha }$ correction.

Concurrent work by Zhang and Xie (2026b,c) develops sharp Gaussian bounds for martingale sums from uniformly ergodic Markov chains and for contractive stochastic approximation with multiplicative Markov noise. Under local quadratic linearization, their stationary result gives the optimal $O ( { \sqrt { \alpha } } )$ rate in Wasserstein-2 distance for this broader class of recursions. By H¨older’s inequality, $W _ { 1 } ( \mu , \nu ) \leq W _ { 2 } ( \mu , \nu )$ for the same pair of laws, so their stationary result also implies the $O ( \sqrt { \alpha } )$ rate in Wasserstein-1 distance. For SGD with bounded additive Markov noise, our direct Wasserstein-1 proof uses a Gaussian initial condition for smoothing and Poisson correctors for the noise and covariance fluctuations. The four-state example above gives a matching $\Omega ( { \sqrt { \alpha } } )$ lower bound driven by higher-order temporal dependence, even with zero stationary mean bias and vanishing nonzero-lag noise autocovariances.

## Appendix B. Reader’s guide to the upper-bound proof

This section gives a calculation-level roadmap for the upper bound. It explains the block length, the two Poisson equations, the Lindeberg interpolation, and the transfer from one block to stationarity. The formal estimates appear in Appendices C–F.

## B.1. Block length and the linear reference recursion

After centering and scaling, the update is

$$
Y _ { k + 1 } = { \mathcal { T } } _ { \alpha } ( Y _ { k } ) + { \sqrt { \alpha } } \xi ( Z _ { k } ) .
$$

For two points $y , y ^ { \prime }$ , the fundamental theorem of calculus gives

$$
\mathcal T _ { \alpha } ( \boldsymbol y ) - \mathcal T _ { \alpha } ( \boldsymbol y ^ { \prime } ) = \left[ I _ { d } - \alpha \int _ { 0 } ^ { 1 } \nabla ^ { 2 } f \big ( \boldsymbol x _ { \star } + \sqrt { \alpha } ( \boldsymbol y ^ { \prime } + t ( \boldsymbol y - \boldsymbol y ^ { \prime } ) ) \big ) \mathrm d t \right] ( \boldsymbol y - \boldsymbol y ^ { \prime } ) .
$$

The averaged Hessian in brackets has eigenvalues in $[ m , L ]$ . When $\alpha \leq L ^ { - 1 }$ , the bracketed matrix therefore has operator norm at most $1 - m \alpha$ . This proves the one-step contraction in (16).

Linearizing the drift at $x _ { \star }$ gives

$$
A = I _ { d } - \alpha H , \bar { Y } _ { k + 1 } = A \bar { Y } _ { k } + \sqrt { \alpha } \xi ( Z _ { k } ) .
$$

The eigenvalues of A lie in $[ 0 , 1 - m \alpha ]$ , so

$$
\| A ^ { j } \| _ { \mathrm { o p } } \leq ( 1 - m \alpha ) ^ { j } \leq e ^ { - m \alpha j } .
$$

One update has only an order-α contraction gap. A block of $n = \lceil T / \alpha \rceil$ updates satisfies

$$
\| A ^ { n } \| _ { \mathrm { o p } } \leq e ^ { - m \alpha n } \leq e ^ { - m T } ,
$$

which is a fixed contraction factor once $T$ is fixed.

Iterating the linear recursion gives

$$
\bar { Y } _ { n } = A ^ { n } Y _ { 0 } + \sqrt { \alpha } \sum _ { k = 0 } ^ { n - 1 } A ^ { n - 1 - k } \xi ( Z _ { k } ) .
$$

After restricting $\alpha \leq ( 2 L ) ^ { - 1 }$ , the first term remains a nondegenerate Gaussian vector over a fixed block when $Y _ { 0 } \sim \gamma$ . The second term is a matrix-weighted additive functional of the Markov chain.

## B.2. The first Poisson equation removes the conditional mean

For a centered observable,

$$
P ^ { j } \xi ( z ) = \mathbb { E } [ \xi ( Z _ { j } ) \mid Z _ { 0 } = z ] .
$$

Uniform ergodicity makes this conditional mean decay geometrically. Hence

$$
V = \sum _ { j \geq 0 } P ^ { j } \xi
$$

converges uniformly and satisfies $V - P V = \xi$ . Define

$$
D _ { k + 1 } = V ( Z _ { k + 1 } ) - P V ( Z _ { k } ) .
$$

The Markov property yields $\mathbb { E } [ D _ { k + 1 } \mid { \mathcal { F } } _ { k } ] = 0$ , and the Poisson equation gives

$$
\xi ( Z _ { k } ) = D _ { k + 1 } + V ( Z _ { k } ) - V ( Z _ { k + 1 } ) .
$$

Thus the additive functional is a martingale sum plus a coboundary.

For the weights

$$
B _ { r } = { \sqrt { \alpha } } A ^ { n - r } ,
$$

write $V _ { r } = V ( Z _ { r } )$ . Expanding the weighted coboundary sum and collecting the coeficient of each interior $V _ { r }$ gives

$$
\sum _ { r = 1 } ^ { n } B _ { r } ( V _ { r - 1 } - V _ { r } ) = B _ { 1 } V _ { 0 } - B _ { n } V _ { n } + \sum _ { r = 1 } ^ { n - 1 } ( B _ { r + 1 } - B _ { r } ) V _ { r } .
$$

This is the discrete summation-by-parts identity used in the proof. The endpoint weights have operator norm at most $\sqrt { \alpha }$ , while

$$
B _ { r + 1 } - B _ { r } = \alpha ^ { 3 / 2 } A ^ { n - r - 1 } H .
$$

The variation of one weight is therefore $O ( \alpha ^ { 3 / 2 } )$ . There are $O ( \alpha ^ { - 1 } )$ weights in a block, so boundedness of $V$ makes the entire coboundary correction $O ( \sqrt { \alpha } )$

## B.3. Gaussian smoothing and Lindeberg interpolation

After the first Poisson equation, the leading variable is

$$
A ^ { n } Y _ { 0 } + \sum _ { r = 1 } ^ { n } B _ { r } D _ { r } .
$$

Let $N _ { r }$ be independent $\mathcal { N } ( 0 , \Sigma _ { M } )$ vectors. The Lindeberg interpolation replaces $B _ { r } D _ { r }$ by $B _ { r } N _ { r }$ one index at a time.

The propagated initial condition provides the smoothing needed for a second-order Taylor expansion. Under the restriction $\alpha \leq ( 2 L ) ^ { - 1 }$ , its covariance is $A ^ { n } \Sigma A ^ { n }$ , which is bounded below by $c _ { T } I _ { d }$ for a constant $c _ { T } > 0$ independent of α. For a 1-Lipschitz test function $h ,$ define

$$
\psi ( u ) = \mathbb { E } [ h ( A ^ { n } Y _ { 0 } + u ) ] .
$$

Gaussian convolution gives a bounded Hessian and a Lipschitz Hessian for $\psi$

At position $r ,$ set

$$
U _ { r } = \sum _ { i < r } B _ { i } D _ { i } + \sum _ { i > r } B _ { i } N _ { i } , \qquad \mathcal { G } _ { r } = \mathcal { F } _ { r - 1 } \vee \sigma ( N _ { i } : i > r ) .
$$

Then $U _ { r }$ is $\mathcal { G } _ { r }$ -measurable. The future Gaussian variables are independent of the Markov chain, so

$$
\mathbb { E } [ D _ { r } \ | \ \mathcal { G } _ { r } ] = 0 , \qquad \mathbb { E } [ D _ { r } D _ { r } ^ { \top } \ | \ \mathcal { G } _ { r } ] = \mathcal { C } ( Z _ { r - 1 } ) .
$$

The Gaussian candidate $N _ { r }$ is conditionally centered with covariance $\Sigma _ { M }$ . The linear terms in the two Taylor expansions cancel after conditioning. Since $\| B _ { r } \| _ { \mathrm { o p } } \leq \sqrt { \alpha }$ , each cubic remainder is ${ \cal O } ( \alpha ^ { 3 / 2 } )$ . Summing over $n = O ( \alpha ^ { - 1 } )$ positions gives an $O ( \sqrt { \alpha } )$ contribution.

## B.4. The second Poisson equation removes covariance fluctuations

The quadratic Taylor term contains

$$
\mathscr { C } ( Z _ { r - 1 } ) = \mathbb { E } [ D _ { r } D _ { r } ^ { \top } \mid \mathcal { F } _ { r - 1 } ] .
$$

The first Poisson equation is constructed so that

$$
\int \mathcal { C } \mathrm { d } \pi = \Sigma _ { M } .
$$

Hence ${ \mathcal { C } } - \Sigma _ { M }$ is centered under π. Uniform ergodicity gives the bounded matrix corrector

$$
W = \sum _ { j \geq 0 } P ^ { j } ( \mathcal C - \Sigma _ { M } ) , \qquad W - P W = \mathcal C - \Sigma _ { M } .
$$

Let

$$
K _ { r } = B _ { r } ^ { \top } \nabla ^ { 2 } \psi ( U _ { r } ) B _ { r } .
$$

Because $K _ { r }$ is $\mathcal { G } _ { r }$ -measurable, the Markov property gives

$$
\begin{array} { r } { \mathbb { E } \langle K _ { r } , P W ( Z _ { r - 1 } ) \rangle _ { \mathrm { F } } = \mathbb { E } \langle K _ { r } , W ( Z _ { r } ) \rangle _ { \mathrm { F } } . } \end{array}
$$

Therefore

$$
\begin{array} { r l } {  { \sum _ { r = 1 } ^ { n } \mathbb { E } \langle K _ { r } , \mathcal { C } ( Z _ { r - 1 } ) - \Sigma _ { M } \rangle _ { \mathrm { F } } } } \\ & { = \sum _ { r = 1 } ^ { n } \mathbb { E } \langle K _ { r } , W ( Z _ { r - 1 } ) \rangle _ { \mathrm { F } } - \sum _ { r = 1 } ^ { n } \mathbb { E } \langle K _ { r } , W ( Z _ { r } ) \rangle _ { \mathrm { F } } } \\ & { = \mathbb { E } \langle K _ { 1 } , W ( Z _ { 0 } ) \rangle _ { \mathrm { F } } - \mathbb { E } \langle K _ { n } , W ( Z _ { n } ) \rangle _ { \mathrm { F } } + \sum _ { r = 1 } ^ { n - 1 } \mathbb { E } \langle K _ { r + 1 } - K _ { r } , W ( Z _ { r } ) \rangle _ { \mathrm { F } } . } \end{array}
$$

The second equality follows by shifting the index in the second sum. This is the stochastic summation-by-parts step.

The bounded Hessian gives $\| K _ { r } \| _ { \mathrm { o p } } = O ( \alpha )$ , so the two boundary terms are $O ( \alpha )$ . To control the variation, write $J _ { r } = \nabla ^ { 2 } \psi ( U _ { r } )$ and decompose

$$
\begin{array} { r l } & { K _ { r + 1 } - K _ { r } = ( B _ { r + 1 } - B _ { r } ) ^ { \top } J _ { r + 1 } B _ { r + 1 } + B _ { r } ^ { \top } ( J _ { r + 1 } - J _ { r } ) B _ { r + 1 } } \\ & { \qquad + B _ { r } ^ { \top } J _ { r } ( B _ { r + 1 } - B _ { r } ) . } \end{array}
$$

The first and third terms are $O ( \alpha ^ { 2 } )$ . The middle term is ${ \cal O } ( \alpha ^ { 3 / 2 } )$ in expectation because the Hessian is Lipschitz and

$$
\mathbb { E } \| U _ { r + 1 } - U _ { r } \| = O ( { \sqrt { \alpha } } ) .
$$

Summing $O ( \alpha ^ { - 1 } )$ variation terms gives $O ( \sqrt { \alpha } )$

## B.5. Target covariance and transfer to stationarity

After all replacements, the comparison variable is Gaussian with covariance

$$
\Sigma _ { \alpha , n } = A ^ { n } \Sigma A ^ { n } + \alpha \sum _ { j = 0 } ^ { n - 1 } A ^ { j } \Sigma _ { M } A ^ { j } .
$$

The continuous Lyapunov equation and $A = I _ { d } - \alpha H$ give the one-step identity

$$
A \Sigma A + \alpha \Sigma _ { M } = \Sigma + \alpha ^ { 2 } H \Sigma H .
$$

Multiplying by $A ^ { j }$ on the left and right and summing over $j$ makes the left-hand side telescope. Hence

$$
\Sigma _ { \alpha , n } - \Sigma = \alpha ^ { 2 } \sum _ { j = 0 } ^ { n - 1 } A ^ { j } H \Sigma H A ^ { j } .
$$

Since $n = O ( \alpha ^ { - 1 } )$ , the covariance error is $O ( \alpha )$

Let $\varpi _ { \alpha }$ be the invariant law of the joint scaled process and let $\nu = \gamma \otimes \pi$ . The block coupling gives a fixed contraction factor $q < 1$ in the joint transportation distance. The $Z _ { - }$ marginal of both $\nu P _ { \alpha } ^ { n }$ and $\nu$ is π. For an admissible joint test, replacing the state coordinate by a fixed state changes each expectation by at most $\kappa \sqrt { \alpha }$ . Proposition 3 therefore implies

$$
W _ { d _ { \alpha , \kappa } } ( \nu P _ { \alpha } ^ { n } , \nu ) \leq W _ { 1 } ( \mathcal L ( Y _ { n } ) , \gamma ) + 2 \kappa \sqrt { \alpha } = O ( \sqrt { \alpha } ) .

Invariance and the triangle inequality now give

Because $1 - q$ is a fixed positive number, rearranging preserves the $O ( \sqrt { \alpha } )$ order.

## Appendix C. Consequences of uniform ergodicity

This appendix develops the Markov-chain estimates used throughout the proof. For a centered function $^ { g , }$ the quantity $P ^ { k } g ( z )$ is the conditional mean of $g ( Z _ { k } )$ when the chain starts from z. Uniform ergodicity makes this conditional mean decay geometrically. That estimate yields three consequences: a coalescent coupling with a geometric tail, absolute summability of the stationary covariance sequence, and bounded solutions of the two Poisson equations in Lemma 5. For a bounded function g taking values in a finite-dimensional normed space, recall the supremum-norm convention from Section 2 and write

$$
\pi g = \int g ( z ) \pi ( \mathrm { d } z ) .
$$

Lemma 6 (Uniform decay of centered observables) Let $g : Z \to E$ be bounded and measurable, where E is a finite-dimensional normed space, and suppose $\pi g = 0$ . Under (6),

$$
\operatorname* { s u p } _ { z \in \mathsf { Z } } \| P ^ { k } g ( z ) \| \leq 2 C _ { Z } \rho ^ { k } \| g \| _ { \infty } , \qquad k \geq 0 .\tag{32}
$$

Proof Fix $z \in { \mathbb { Z } }$ . The centering condition $\pi g = 0$ gives

$$
P ^ { k } g ( z ) = \int g ( u ) [ P ^ { k } ( z , \mathrm { d } u ) - \pi ( \mathrm { d } u ) ] .
$$

Let $E ^ { * }$ be the dual space of $E ,$ with dual norm denoted by $\| \cdot \| _ { E ^ { * } }$ . The dual representation of the norm yields

$$
\| P ^ { k } g ( z ) \| = \operatorname* { s u p } _ { \stackrel { \ell \in E ^ { * } } { \| \ell \| _ { E ^ { * } } \leq 1 } } \left| \int \ell ( g ( u ) ) [ P ^ { k } ( z , \mathrm { d } u ) - \pi ( \mathrm { d } u ) ] \right| .
$$

For every functional in this supremum, $| \ell ( g ( u ) ) | \leq \| g \| _ { \infty }$ . With the total-variation convention fixed above, integration against a bounded scalar function satisfies

$$
\left| \int q \mathrm { d } ( \mu - \nu ) \right| \leq 2 \| q \| _ { \infty } \| \mu - \nu \| _ { \mathrm { T V } } .
$$

Consequently,

$$
\begin{array} { r } { \| P ^ { k } g ( z ) \| \leq 2 \| g \| _ { \infty } \| P ^ { k } ( z , \cdot ) - \pi \| _ { \mathrm { T V } } . } \end{array}
$$

Equation (6) now gives the stated bound uniformly in z.

Lemma 7 (Geometric coalescent coupling from uniform ergodicity) Under (6), there exist constants $C _ { \mathrm { c p l } } < \infty$ and $\rho _ { \mathrm { c p l } } \in ( 0 , 1 )$ , depending only on $C _ { Z }$ and $\rho ,$ and a coupling kernel measurable in the initial pair $( z , z ^ { \prime } ) \in Z ^ { 2 }$ . Under this kernel, the two P-chains have coalescence time

$$
\tau = \operatorname* { i n f } \left\{ k \geq 0 : Z _ { j } = Z _ { j } ^ { \prime } \ f o r \ e v e r y \ j \geq k \right\}
$$

satisfying

$$
\begin{array} { r } { \mathbb { P } _ { z , z ^ { \prime } } ( \tau > k ) \le C _ { \mathrm { c p l } } \rho _ { \mathrm { c p l } } ^ { k } \mathbf { 1 } _ { \{ z \neq z ^ { \prime } \} } , \qquad k \ge 0 . } \end{array}\tag{33}
$$

Here $\mathbb { P } _ { z , z ^ { \prime } }$ denotes probability under the coupling kernel started from $( z , z ^ { \prime } )$ . The kernel can be chosen Markovian at the boundaries of fixed-length blocks, which is the structure used in the joint contraction argument.

Proof The construction uses the r-step skeleton of the chain. Choose an integer $r \geq 1$ such that

$$
2 C _ { Z } \rho ^ { r } \leq \frac { 1 } { 2 } .
$$

For any two initial states $z , z ^ { \prime } \in Z$ , the triangle inequality and uniform ergodicity imply

$$
\begin{array} { r l } & { \| P ^ { r } ( z , \cdot ) - P ^ { r } ( z ^ { \prime } , \cdot ) \| _ { \mathrm { T V } } \leq \| P ^ { r } ( z , \cdot ) - \pi \| _ { \mathrm { T V } } + \| P ^ { r } ( z ^ { \prime } , \cdot ) - \pi \| _ { \mathrm { T V } } } \\ & { \qquad \leq 2 C _ { Z } \rho ^ { r } \leq \displaystyle \frac { 1 } { 2 } . } \end{array}
$$

Thus the two r-step transition laws overlap uniformly. At each block boundary, use a maximal coupling for the two endpoints at the next boundary. Their conditional disagreement probability is at most $1 / 2$ . On a Polish space, the maximal coupling can be selected measurably in the initial pair (Grifeath, 1975; Douc et al., 2018; Meyn and Tweedie, 2012).

Apply this endpoint coupling successively at times $0 , r , 2 r , \ldots$ . The iterate recursion also uses the intermediate states inside each block. To retain the correct path law, sample those states from the regular conditional law of a Markov path given its initial and terminal states. Such bridge laws exist on a Polish space (Faden, 1985). Once the two endpoints agree at a block boundary, use the same transitions in both coordinates thereafter. The two paths then remain equal.

If $z = z ^ { \prime } ,$ , this synchronous construction starts at time zero. $\operatorname { I f } z \neq z ^ { \prime }$ , every block before coalescence has conditional meeting probability at least $1 / 2$ . Therefore

$$
\begin{array} { r } { \mathbb { P } _ { z , z ^ { \prime } } ( \tau > j r ) \le 2 ^ { - j } , \qquad j \ge 0 . } \end{array}
$$

For an arbitrary integer $k \geq 0$ , the event $\{ \tau > k \}$ is contained in the event that the chains have not coalesced by the preceding block boundary. Hence

$$
\begin{array} { r } { \mathbb { P } _ { z , z ^ { \prime } } \big ( \tau > k \big ) \le 2 ^ { - \lfloor k / r \rfloor } \le 2 \big ( 2 ^ { - 1 / r } \big ) ^ { k } . } \end{array}
$$

This proves (33) with $C _ { \mathrm { c p l } } = 2$ and $\rho _ { \mathrm { c p l } } = 2 ^ { - 1 / r }$

Lemma 8 (Absolute covariance summability) Let $\Gamma _ { \ell }$ be the stationary covariance matrices defined in (8). Under (6)–(7),

\| \Gamma \ell \| _ { * } \leq 2 b ^ { 2 } C _ { Z } \rho ^ { \ell } , \qquad \ell \geq 1 .\tag{34}
$$

$$

$$

For a rank-one matrix $u v ^ { \top }$ , the nuclear norm is $\| u \| \| v \|$ . Lemma 6, applied to the centered function $\xi ,$ therefore gives

$$
\begin{array} { r } { \| \Gamma _ { \ell } \| _ { * } \leq \mathbb { E } _ { \pi } \Big [ \| \xi ( Z _ { 0 } ) \| \| P ^ { \ell } \xi ( Z _ { 0 } ) \| \Big ] } \\ { \leq b \cdot 2 C _ { Z } \rho ^ { \ell } b = 2 b ^ { 2 } C _ { Z } \rho ^ { \ell } . } \end{array}

The term $\Gamma _ { 0 }$ is finite because $\xi$ is bounded. Since $\Gamma _ { - \ell } = \Gamma _ { \ell } ^ { \top }$ and the nuclear norm is invariant under transposition, the same geometric estimate holds for negative lags. Summing over $\ell \in \mathbb { Z }$ proves (9).

## Appendix D. Proof of the one-block Gaussian approximation

This appendix proves Proposition 3. Fix $T > 0$ , restrict to $0 \textless \alpha \leq 1$ , let $n = \lceil T / \alpha \rceil$ 9 and assume $( Y _ { 0 } , Z _ { 0 } ) \sim \gamma \otimes \pi$ . ## D.1. Linearization and finite-block moment bounds

Set

$$

$$
{ \mathcal { T } } _ { \alpha } ( y ) - A y = - { \sqrt { \alpha } } { \big [ } \nabla f ( x _ { \star } + { \sqrt { \alpha } } y ) - H { \sqrt { \alpha } } y { \big ] } .

The integral Taylor formula gives

$$
\nabla f ( x _ { \star } + { \sqrt { \alpha } } y ) - H { \sqrt { \alpha } } y = \int _ { 0 } ^ { 1 } \left[ \nabla ^ { 2 } f ( x _ { \star } + t { \sqrt { \alpha } } y ) - H \right] { \sqrt { \alpha } } y \ \mathrm { d } t .

$$

$$

The linear recursion has the explicit representation

$$

For $\alpha \leq L ^ { - 1 }$ , the symmetric matrix A has spectrum in [0, 1], so $\| A ^ { j } \| _ { \mathrm { o p } } \leq 1$ The next calculation shows that the weighted Markov sum has a second moment bounded uniformly over a fixed block. Using (8), stationarity gives

Stationarity expresses all cross terms through the lag covariances $\Gamma _ { j - i }$ , whose absolute summability controls their total contribution. The first term is at most $\operatorname { t r } ( \Sigma )$ . For the second term, cyclicity of the trace and operator–nuclear norm duality give

For each $i ,$ the sum over $j$ is bounded by $C _ { \Gamma }$ . Therefore

where we used $\alpha n \leq T + 1$

Construct $Y _ { k }$ and $Y _ { k }$ with the same initial condition and the same Markov path. Add and subtract $\mathcal { T } _ { \alpha } ( \bar { Y } _ { k } )$ , use the contraction (16), and apply (40) at $\bar { Y } _ { k }$

$$

Iteration from $Y _ { 0 } = \bar { Y _ { 0 } }$ gives

\begin{array} { r l } {  { \mathbb { E } \| Y _ { n } - \bar { Y } _ { n } \| \leq \frac { M } { 2 } \alpha ^ { 3 / 2 } \sum _ { k = 0 } ^ { n - 1 } ( 1 - m \alpha ) ^ { n - 1 - k } \mathbb { E } \| \bar { Y } _ { k } \| ^ { 2 } } } \\ & { \leq \frac { M C _ { \mathrm { m o m } } ( T ) } { 2 m } \sqrt { \alpha } . } \end{array}\tag{43}

## D.2. Weighted martingale–coboundary decomposition

Insert (25) into the explicit solution of the linear recursion. With the reindexing $r = i + 1$ ， define

$$

$$
\begin{array} { r l r } {  { \sum _ { r = 1 } ^ { n } B _ { r } \bigl [ V ( Z _ { r - 1 } ) - V ( Z _ { r } ) \bigr ] } } \\ & { } & { = \displaystyle B _ { 1 } V ( Z _ { 0 } ) - B _ { n } V ( Z _ { n } ) + \sum _ { r = 1 } ^ { n - 1 } ( B _ { r + 1 } - B _ { r } ) V ( Z _ { r } ) . } \end{array}\tag{45}

\begin{array} { r } { \mathbb { P } _ { z , z ^ { \prime } } ( \tau > k ) \le C _ { \mathrm { c p l } } \rho _ { \mathrm { c p l } } ^ { k } \mathbf { 1 } _ { \{ z \neq z ^ { \prime } \} } . } \end{array}

$$

Consequently,

$$

Next choose

and restrict α so that $C _ { \mathrm { c p l } } \rho _ { \mathrm { c p l } } ^ { \lceil T / \alpha \rceil } \leq 1 / 4$ . The initial iterate discrepancy is then multiplied by at most $1 / 4$ . ## E.2. Construction and uniqueness of the invariant law

Fix $0 < \alpha \leq L ^ { - 1 }$ . Because $\textsf { Z }$ is Polish and $\pi$ is invariant, a stationary P-chain with marginal $\pi$ has a two-sided realization $( Z _ { k } ) _ { k \in \mathbb { Z } }$ . Since $\mathcal { T } _ { \alpha } ( 0 ) = 0$ , the contraction bound gives

$$
\begin{array} { r } { \| \mathcal { T } _ { \alpha } ( y ) + \sqrt { \alpha } \xi ( z ) \| \le ( 1 - m \alpha ) \| y \| + b \sqrt { \alpha } . } \end{array}\tag{69}
$$

For each $N \geq 1$ , initialize the scaled recursion at time −N from zero and denote its value at time zero by $Y _ { 0 } ^ { ( N ) }$ . Iterating (69) shows that every such trajectory stays in the deterministic ball of radius $b / ( m \sqrt { \alpha } )$

If $N ^ { \prime } > N$ , the two trajectories use the same noise path from time $- N$ onward. At time $- N$ , the trajectory started there equals zero, while the older trajectory lies in the absorbing ball. Their distance at that time is at most $b / ( m \sqrt { \alpha } )$ . Contractivity over the next $N$ updates gives

$$
\| Y _ { 0 } ^ { ( N ^ { \prime } ) } - Y _ { 0 } ^ { ( N ) } \| \leq \frac { b } { m \sqrt { \alpha } } ( 1 - m \alpha ) ^ { N } .
$$

The right-hand side tends to zero, so $( Y _ { 0 } ^ { ( N ) } )$ is almost surely Cauchy. Let $Y _ { 0 }$ denote its limit.   
This limit is measurable with respect to the infinite past of the noise chain.

Apply the same pullback construction after shifting the time origin. This defines $Y _ { k }$ for every $k \in \mathbb { Z }$ , and the shift invariance of the two-sided noise chain makes $( Y _ { k } , Z _ { k } ) _ { k \in \mathbb { Z } }$ stationary. Passing to the limit in the recursion shows that it satisfies (15) (Diaconis and Freedman, 1999; Gupta and Haskell, 2021). Hence $\varpi _ { \alpha } : = \mathcal { L } ( Y _ { 0 } , Z _ { 0 } )$ is invariant for $P _ { \alpha }$ and has Z-marginal π.

The pullback law just constructed is supported in the deterministic ball

$$
\| Y \| \leq { \frac { b } { m { \sqrt { \alpha } } } } \qquad \mathrm { a l m o s t ~ s u r e l y } .\tag{70}
$$

Indeed, the finite pullback trajectories stay in this ball by (69), and the ball is closed, so their almost-sure limit has the same bound.

Now restrict further to $\alpha \leq \alpha _ { c }$ , where $\alpha _ { c }$ is supplied by Proposition 4. Every invariant law has a finite first Y -moment. Indeed, iterating (69) gives

$$
\| Y _ { k } \| \leq ( 1 - m \alpha ) ^ { k } \| Y _ { 0 } \| + { \frac { b } { m { \sqrt { \alpha } } } } .\tag{71}
$$

If the law of $Y _ { 0 }$ is invariant, then $Y _ { k }$ has the same law as $Y _ { 0 }$ . For every $\varepsilon > 0$ , the preceding pathwise bound gives

$$
\begin{array} { r l r } {  { \mathbb { P } \bigg ( \| Y _ { 0 } \| > \frac { b } { m \sqrt { \alpha } } + \varepsilon \bigg ) = \mathbb { P } \bigg ( \| Y _ { k } \| > \frac { b } { m \sqrt { \alpha } } + \varepsilon \bigg ) } } \\ & { } & { \leq \mathbb { P } \bigg ( \| Y _ { 0 } \| > \varepsilon ( 1 - m \alpha ) ^ { - k } \bigg ) . } \end{array}
$$

The threshold on the right tends to infinity, so the probability tends to zero. Thus every invariant law is supported in the same deterministic ball as (70). Its Z-marginal is π because uniform ergodicity makes $\pi$ the unique invariant law of $P$

Let $\mu _ { 1 }$ and $\mu _ { 2 }$ be two invariant laws of the joint recursion. Both have finite first Y -moments, so Proposition 4 applies:

$$
W _ { d _ { \alpha , \kappa } } ( \mu _ { 1 } , \mu _ { 2 } ) = W _ { d _ { \alpha , \kappa } } ( \mu _ { 1 } P _ { \alpha } ^ { n } , \mu _ { 2 } P _ { \alpha } ^ { n } ) \leq q W _ { d _ { \alpha , \kappa } } ( \mu _ { 1 } , \mu _ { 2 } ) .
$$

The dual class contains suitably rescaled products of bounded Lipschitz functions of $y$ and bounded measurable functions of $z ,$ so it determines the joint law. Hence $q < 1$ forces $\mu _ { 1 } = \mu _ { 2 }$ , and the pullback law $\varpi _ { \alpha }$ is the unique invariant law of the scaled recursion.

## E.3. Transfer of the block estimate to stationarity

Recall $\nu = \gamma \otimes \pi$ . Let h be an admissible joint test and fix an arbitrary $z _ { 0 } \in \mathbb { Z }$ . The function $y \mapsto h ( y , z _ { 0 } )$ is 1-Lipschitz. Moreover,

$$
| h ( y , z ) - h ( y , z _ { 0 } ) | \leq \kappa \sqrt { \alpha } \qquad \mathrm { f o r ~ e v e r y ~ } y , z .
$$

Both $\nu P _ { \alpha } ^ { n }$ and $\nu$ have Z-marginal π. Replacing $h ( y , z )$ by $h ( y , z _ { 0 } )$ in each of the two expectations therefore costs at most $\kappa \sqrt { \alpha }$ . Proposition 3 now gives

$$
W _ { d _ { \alpha , \kappa } } ( \nu P _ { \alpha } ^ { n } , \nu ) \leq ( C _ { T } + 2 \kappa ) \sqrt { \alpha } .\tag{72}
$$

Set $w _ { \alpha } = W _ { d _ { \alpha , \kappa } } ( \varpi _ { \alpha } , \nu )$ . Invariance of $\varpi _ { \alpha }$ , the triangle inequality, and Proposition 4 yield

$$
\begin{array} { r l } & { w _ { \alpha } = W _ { d _ { \alpha , \kappa } } ( \varpi _ { \alpha } P _ { \alpha } ^ { n } , \nu ) } \\ & { \qquad \le W _ { d _ { \alpha , \kappa } } ( \varpi _ { \alpha } P _ { \alpha } ^ { n } , \nu P _ { \alpha } ^ { n } ) + W _ { d _ { \alpha , \kappa } } ( \nu P _ { \alpha } ^ { n } , \nu ) } \\ & { \qquad \le q w _ { \alpha } + ( C _ { T } + 2 \kappa ) \sqrt { \alpha } . } \end{array}
$$

Therefore

$$

Projection onto the first coordinate can only decrease Wasserstein distance. Hence the Y-marginal of $\varpi _ { \alpha }$ is within $C \sqrt { \alpha }$ of $\gamma$ . The pushforward of $\varpi _ { \alpha }$ under $( y , z ) \mapsto ( x _ { \star } + \sqrt { \alpha } y , z )$ is the unique invariant probability measure $\Pi _ { \alpha }$ of the original recursion. Scaling the iterate distance by $\sqrt { \alpha }$ also gives the unscaled $O ( \alpha )$ bound. Taking $\alpha ,$ <sub>⋆</sub> to be the minimum of the finitely many positive thresholds introduced above completes the proof of Theorem 1.

## Appendix G. Matching lower bound from temporal dependence

This appendix proves Theorem 2. The calculation has four steps. We first verify that the finite-state noise has a symmetric marginal distribution and zero autocovariance at every nonzero lag. We then identify the third-order temporal moment that remains and compute the exact second and third moments of the stationary weighted series. Kantorovich– Rubinstein duality requires a Lipschitz test function, whereas $x \mapsto x ^ { 3 }$ is not Lipschitz. We therefore evaluate the bounded 1-Lipschitz test function sin x through an explicit two-state characteristic-function recursion.

## G.1. Markov model and third-order temporal dependence

Take $f ( x ) = x ^ { 2 } / 2$ . Then $x _ { \star } = 0 , H = 1$ , and the objective assumptions in (5) hold with $m = L = 1$ and $M = 0$ . Let $( \eta _ { k } ) _ { k \in \mathbb { Z } }$ be independent Rademacher random variables, so

$$
\mathbb { P } ( \eta _ { k } = 1 ) = \mathbb { P } ( \eta _ { k } = - 1 ) = \frac { 1 } { 2 } .\tag{80}
$$

Define

$$
Z _ { k } = ( \eta _ { k - 1 } , \eta _ { k } ) , \qquad \xi ( Z _ { k } ) = { \frac { \eta _ { k } ( 3 - \eta _ { k - 1 } ) } { 2 } } .\tag{81}
$$

The four possible noise values are displayed by

$$
\begin{array} { c c } { { \displaystyle \frac { \mid \eta _ { k } = 1 } { \eta _ { k - 1 } = 1 } \frac { \mid \eta _ { k } = 1 } { 1 } } } & { { \mathrm { ~ - 1 ~ } } } \\ { { \eta _ { k - 1 } = - 1 \mid \mathrm { ~  ~ 2 ~ } } } & { { \mathrm { ~ - 2 ~ } } } \end{array}
$$

The state space is $\{ - 1 , 1 \} ^ { 2 }$ . From a state $( a , b )$ , the chain moves to $( b , c )$ , where c is a fresh Rademacher variable. Thus

$$
P ( ( a , b ) , \{ ( b , c ) \} ) = \frac { 1 } { 2 } , \qquad c \in \{ - 1 , 1 \} .
$$

Its invariant probability measure π is uniform on the four states. After two transitions, both coordinates are fresh and independent of the initial state, which gives

$$
P ^ { 2 } ( z , \cdot ) = \pi \qquad \mathrm { f o r ~ e v e r y ~ } z .\tag{82}
$$

Equation (82) verifies (6), for example with $C _ { Z } = 1$ and $\rho = 1 / 2$ . The observable satisfies (7) with $b = 2$

The four equally likely values of $\xi ( Z _ { 0 } )$ are −2, −1, 1, 2. Hence the marginal distribution is symmetric and

$$
\mathbb { E } \xi ( Z _ { 0 } ) = 0 , \qquad \mathbb { E } \xi ( Z _ { 0 } ) ^ { 2 } = \frac { 5 } { 2 } , \qquad \mathbb { E } \xi ( Z _ { 0 } ) ^ { 3 } = 0 .\tag{83}
$$

For every $\ell \geq 1$ , the variable $\xi ( Z _ { \ell } )$ contains the fresh factor $\eta _ { \ell }$ to the first power. Conditional on all earlier innovations, this factor has mean zero. Therefore

$$
\mathbb { E } [ \xi ( Z _ { 0 } ) \xi ( Z _ { \ell } ) ] = 0 , \qquad \ell \ge 1 .\tag{84}
$$

Stationarity gives the same conclusion at negative lags. The long-run covariance is therefore

$$
\Sigma _ { M } = \mathbb { E } \xi ( Z _ { 0 } ) ^ { 2 } = \frac { 5 } { 2 } .\tag{85}
$$

Since $H = 1$ , the Lyapunov equation $2 \Sigma = \Sigma _ { M }$ gives $\Sigma = 5 / 4$

At second order, this process agrees with independent draws having the same marginal distribution because every nonzero-lag covariance vanishes. Third-order moments separate the two models. Direct conditioning gives

$$
\begin{array} { r l r } {  { \mathbb { E } [ \xi ( Z _ { 0 } ) \xi ( Z _ { 1 } ) ^ { 2 } ] = \mathbb { E } [ \frac { \eta _ { 0 } ( 3 - \eta _ { - 1 } ) } { 2 } \frac { ( 3 - \eta _ { 0 } ) ^ { 2 } } { 4 } ] } } \\ & { } & { = \frac { 1 } { 8 } \mathbb { E } [ 3 - \eta _ { - 1 } ] \mathbb { E } [ \eta _ { 0 } ( 3 - \eta _ { 0 } ) ^ { 2 } ] = - \frac { 9 } { 4 } . } \end{array}\tag{86}
$$

Here $\mathbb { E } [ 3 - \eta _ { - 1 } ] = 3$ and $\mathbb { E } [ \eta _ { 0 } ( 3 - \eta _ { 0 } ) ^ { 2 } ] = - 6$ . By contrast, for independent centered variables $\widetilde { \xi } _ { 0 }$ and $\xi _ { 1 }$ with this same marginal law,

$$
\mathbb { E } [ \widetilde { \xi } _ { 0 } \widetilde { \xi } _ { 1 } ^ { 2 } ] = \mathbb { E } \widetilde { \xi } _ { 0 } \mathbb { E } \widetilde { \xi } _ { 1 } ^ { 2 } = 0 .
$$

Thus (86) is generated by temporal dependence.

## G.2. Stationary weighted series and exact low-order moments

Fix $\alpha \in ( 0 , 1 )$ and set $r _ { \alpha } = 1 - \alpha$ . The recursion is

## G.5. Interpretation of the lower bound

The quadratic objective $f ( x ) = x ^ { 2 } / 2$ has exactly linear drift, so the nonlinear Taylor remainder from the upper-bound proof is absent. The order- $\sqrt { \alpha }$ discrepancy therefore comes entirely from temporal dependence. Nevertheless, the Markovian and independent models agree in their one-time noise law and second-order structure. Both have the symmetric marginal distribution on $\{ - 2 , - 1 , 1 , 2 \}$ and long-run covariance $\Sigma _ { M } = 5 / 2$ , and every nonzerolag covariance in the Markovian model is zero. Thus both have the limiting Gaussian law $\mathcal { N } ( 0 , 5 / 4 )$

The distinction appears in the adjacent mixed moment

$$
\mathbb { E } [ \xi ( Z _ { 0 } ) \xi ( Z _ { 1 } ) ^ { 2 } ] = - \frac { 9 } { 4 } .
$$

This moment survives the geometric filtering in the stationary recursion and produces an order- $\cdot \sqrt { \alpha }$ third cumulant. The characteristic-function recursion converts that local temporal asymmetry into the following expectation:

$$
\mathbb { E } [ \sin ( Y _ { \alpha } ) ] = \frac { 3 } { 8 } e ^ { - 5 / 8 } \sqrt { \alpha } + O ( \alpha ) .
$$

Independent sampling has the same covariance calculation, while joint sign symmetry makes its sine expectation exactly zero.

The scale can also be read directly from the exact third-moment sum. Each adjacent repeated-index pattern has weight of order $\alpha ^ { 3 / 2 } r _ { \alpha } ^ { 3 j }$ , and the number of efectively contributing indices is of order $\alpha ^ { - 1 }$ . Equivalently,

$$

$$

The two-state recursion transfers this scale from an unbounded third-moment calculation to the bounded sine test function required by Wasserstein duality.

The coeficient $3 e ^ { - 5 / 8 } / 8$ in (106) combines the order- $\sqrt { \alpha }$ imaginary correction $3 / 8$ with the Gaussian damping factor $e ^ { - 5 / 8 }$

The two proofs separate three efects. Strong convexity gives block contraction, Hessian regularity controls nonlinear drift, and the Poisson correctors encode temporal dependence. Under independent sampling, $\mathcal { C } ( \boldsymbol { z } ) = \Sigma _ { M }$ and $W = 0$ . The lower example shows that higher-order dependence can still afect the order- $\cdot \sqrt { \alpha }$ correction. Thus long-run covariance determines the Gaussian limit, while the first correction may also reflect objective curvature and higher-order temporal structure.
