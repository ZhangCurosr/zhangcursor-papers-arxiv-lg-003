# 论文速读：SAGE: SALIENT FACTOR DISCOVERY AND GENERATION WITH VISUAL FOUNDATION REPRESENTATIONS

## 一句话总结
SAGE 是一种对比分析方法，利用冻结的视觉基础表示自编码器（RAE）的高维空间潜在变量，仅凭背景/目标数据集标签将其分解为捕获共有内容的公共因子与捕获目标特定细节的显著因子；该方法能实现高保真图像重建、无监督子类型发现，并能以显著因子为条件生成保留目标属性但变化共有内容的新样本。

## 研究问题与动机
1. **核心问题**：给定两个数据集（如戴眼镜的人脸 vs. 不戴眼镜的人脸），如何在无子类型标签的情况下，自动分离出目标数据集特有的显著因子（如眼镜形状、颜色、位置）与两个数据集共有的内容因子？
2. **现有方法不足**：生成式对比分析模型（如 cVAE、SepVAE）缺乏解码复杂自然图像的能力，重建质量差；对比式对比分析模型（如 SepCLR）能学到语义丰富的表示但缺乏解码器，无法用于生成或直接编辑。
3. **医学等场景的需求**：临床中常只有粗粒度的分组标签（如正常/患病），但疾病特征未知且难以用文字描述；需要一种能从影像差异中客观揭示疾病亚型甚至未发现类型的方法。

## 核心贡献（创新点）
1. **在冻结 RAE 的空间潜在空间中进行对比因子分解**：将冻结的 DINOv3 编码器与 RAEv2 解码器结合，设计可训练的共同/显著编码器将潜在变量 $z$ 分解为 $z_c$ 和 $z_s$，使分解后的因子仍能通过冻结解码器高保真重建。与以往在工作流生成器或紧凑 token 上分解的方法不同，SAGE 直接在完整的空间潜在表示上进行分解。
2. **设计多种互补损失以约束因子分离**：包括不对称重建损失、交换对抗损失、稀疏先验、一致性损失（图像空间与潜空间）以及 Cycle NCE 损失，共同确保显著因子仅携带目标特定内容且保持实例级细节，而非泛化模板或共有内容。
3. **实现无监督子类型发现与标签噪声检测**：在 Digits-ImageNet 和 FFHQ 眼镜数据集上，显著表示能清晰分离十种数字或眼镜类型，甚至揭示出更细粒度的太阳镜风格；在 FFHQ 上发现了一个由错误标注图像组成的聚类，经人工审计验证后修正了 3.64% 的标签。
4. **提出显著条件生成框架**：第二阶段冻结已学习的显著编码器，以显著表示为条件训练扩散 Transformer，能在改变共有内容（如人脸、背景）的同时保持参考图像的显著子类型，显著提升了生成样本的子类型保持率与多样性。

## 方法详解
SAGE 分两阶段：第一阶段学习因子分解，第二阶段进行显著条件生成。

**Stage 1: 显著因子发现**
- **冻结的表示自编码器**：使用冻结的 RAEv2 编码器 $E$（基于 DINOv3-L with multi-layer summation）和冻结的解码器 $D$。输入图像 $x$ 得到空间潜在 $z = E(x) \in \mathbb{R}^{N \times C}$。
- **共同与显著编码器**：可训练的编码器 $E_c$ 和 $E_s$ 生成与 $z$ 同形状的公共因子 $z_c = E_c(z)$ 和显著因子 $z_s = E_s(z)$。解码器接收两者之和 $z_c + z_s$ 重建图像。背景图像中 $z_s^b = 0$。
- **非对称重建损失 $\mathcal{L}_{\text{rec}}$**：对背景图像 $\hat{x}^b = D(z_c^b, 0)$，对目标图像 $\hat{x}^t = D(z_c^t, z_s^t)$。损失包含图像重建项 $\ell(x, \hat{x}) = \|x-\hat{x}\|_2^2 + \text{LPIPS}(x, \hat{x})$ 与潜空间一致性项，防止解码器接受不可靠的因子组合。
- **交换对抗损失 $\mathcal{L}_{\text{swap}}^G$**：交换背景与目标的因子生成假图像 $\hat{x}_{\text{fake}}^b = D(z_c^t, 0)$ 和 $\hat{x}_{\text{fake}}^t = D(z_c^b, z_s^t)$。使用背景/目标判别器区分交换图像与真实重建图像，引导编码器将目标特有内容推入 $z_s$。
- **稀疏先验**：对背景图像应用 $\ell_2^2$ 惩罚迫使 $z_s^b$ 趋近零；对目标图像应用 $\ell_1$ 惩罚鼓励 $z_s^t$ 稀疏，避免共享内容（如人脸）混入显著因子。
- **一致性损失**：
  - **图像空间循环一致性 $\mathcal{L}_{\text{cyc}}$**：将交换图像重新编码并分解，要求恢复原始因子，确保因子可恢复且实例特定。
  - **潜空间交换一致性 $\mathcal{L}_{\text{lsc}}$**：在潜空间直接对因子组合进行重编码，验证加性组合的可分离性，计算更高效。
- **Cycle NCE 损失 $\mathcal{L}_{\text{cNCE}}$**：对循环恢复的因子全局池化并 L2 归一化后，使用 InfoNCE 将同一因子的原始表示与恢复表示作为正对，不同因子的表示作为负对，进一步防止共同内容泄漏到显著因子中。
- **总损失**：$\mathcal{L}_{\text{SAGE}} = \mathcal{L}_{\text{rec}} + \mathcal{L}_{\text{swap}}^G + \mathcal{L}_{\text{BG-sp}} + \mathcal{L}_{\text{TG-sp}} + \mathcal{L}_{\text{cyc}} + \mathcal{L}_{\text{lsc}} + \mathcal{L}_{\text{cNCE}}$。

**Stage 2: 显著条件生成**
- **条件提取**：冻结 Stage 1 的显著编码器，对参考目标图像 $x^t$ 提取显著表示 $z_s^t$，进行通道维度的全局最大池化得到 $c_s = \text{GMP}(z_s^t) \in \mathbb{R}^C$，丢弃空间位置但保留激活信道信息。
- **扩散 Transformer 训练**：使用从 RAEv2 检查点初始化的 DiT，在目标图像上进行流匹配（flow matching）训练。将 $c_s$ 投影为一个 token 与噪声潜在、时间嵌入拼接作为条件。采用无分类器引导（classifier-free guidance）与内部引导（internal guidance）提升采样质量。
- **推理**：从高斯噪声出发，在 $c_s$ 条件下积分生成潜变量，再经冻结解码器重建图像。不同随机噪声变化共有内容，$c_s$ 固定显著子类型。

## 实验与结果
- **数据集**：
  - **Digits-ImageNet**：将 MNIST 数字叠加在 ImageNet 照片上构成目标集，纯 ImageNet 照片为背景集，10 个数字子类。
  - **FFHQ 眼镜数据集**：使用 Azure Face API 自动标注的眼镜属性（阅读眼镜/太阳镜）划分目标/背景，后经人工审计修正 125 个标签。
  - **OCT-Kermany**：正常视网膜扫描为背景，三种疾病（CNV、DME、DRUSEN）扫描为目标的共轭焦平面光学断层扫描图像。
- **评估基线**：cVAE、SepVAE、Double-InfoGAN、SepCLR、DINOv3+SepCLR，以及未分解的 RAEv2 潜在表示。
- **主要结果**：
  - **重建质量**：SAGE 在 Digits-ImageNet 上 rFID 为 1.78，FFHQ 上为 1.65，远低于生成式基线（>120），接近直接解码原始潜变量的 rFID（0.39）。
  - **子类型发现**：在 Digits-ImageNet 上，显著空间的线性探针精度达 0.950，而最佳基线仅 0.281；聚类 ARI/NMI 为 0.337/0.472。在 FFHQ 上探针精度 0.983，ARI/NMI 0.939/0.865（包含审计后标签）。
  - **疾病亚型发现**：在 OCT-Kermany 上，仅用正常/疾病标签，显著空间能将三种疾病分开，线性探针精度 0.960，ARI/NMI 0.415/0.415。
  - **生成效果**：在 Digits-ImageNet 上，显著条件生成的子类型保持准确率从 27.7% 提升至 90.5%，多样性 Vendi 分数从 2.65 提升至 12.50；FFHQ 上子类型保持准确率 96.6%，Vendi 从 2.32 提升至 6.96。
- **最强结果**：FFHQ 眼镜数据集上的子类型发现（探针精度 0.983，ARI/NMI 0.939/0.865）与 Digits-ImageNet 上的条件生成子类型保持率（90.5% vs. 27.7%）。

## 相关工作脉络
1. **对比分析（CA）模型**：cVAE、SepVAE、Double-InfoGAN 等通过从零训练的生成器学习因子，但重建自然图像能力有限；SAGE 利用冻结的预训练 RAE 克服此限制。
2. **对比表示学习方法**：SepCLR 基于 InfoMax 原则学习强显著表示但无解码器；SAGE 在相同冻结编码器上扩展，加入生成与重建目标，实现端到端解码。
3. **表示自编码器与条件生成**：RAEv2 等将冻结预训练编码器与 ViT 解码器结合支持高质量扩散生成；SAGE 在此基础上进一步分解潜在空间，实现子类型条件生成而非完整表示条件生成。
4. **医学图像分析中的应用**：CA 已用于神经影像（如自闭症脑 MRI）与疾病亚型发现；SAGE 将此方法推广至视网膜 OCT，仅用粗粒度标签发现疾病亚型。

## 局限性与未来方向
1. **发现而非完全解耦**：背景/目标标签不能唯一确定相关属性的分配；公共表示仍保留可线性解码的数字信息（探针精度 0.336），即 SAGE 得到的是干净的显著因子，而非将目标信息独占分配。
2. **生物医学图像重建保真度受限**：冻结的 RAEv2 编码器与解码器在自然图像上预训练，导致 OCT 图像重建质量较低（SSIM 0.448 vs. 自然图像 0.571/0.723）；未来可替换为在生物医学图像上预训练的表示自编码器。
3. **泛化能力待验证**：仅在三个数据集（Digits-ImageNet、FFHQ、OCT-Kermany）上验证，方法在其他领域（如遥感、科学图像）的适用性未测试。
4. **计算开销**：第一阶段需要训练额外的编码器与判别器，第二阶段需单独训练扩散模型，整体流程较复杂。

## 研究启发与可借鉴点
1. **冻结预训练表示空间进行对比分解**：利用冻结的 RAE（如 DINOv3 + RAEv2）作为固定语义空间，避免从头训练带来的语义坍塌与重建质量下降，为其他对比分析任务提供可行范式。
2. **多重损失协同约束因子分离**：结合重建、对抗、稀疏性、循环一致性与对比学习（Cycle NCE）多种损失，从不同角度保证显著因子纯净；可迁移至其他解耦表示学习任务。
3. **无监督子类型发现与标签噪声检测**：显著表示的聚类不仅揭示已知子类，还能暴露数据集中的标注错误（如 FFHQ 眼镜标签），为数据清洗提供自动化线索。
4. **条件生成中的细粒度控制**：通过池化显著表示而非完整潜变量作为扩散模型条件，可在保持目标属性（如眼镜类型）的同时自由变化共有内容（人脸、背景），实现了比文本提示更精确的实例级控制。
5. **医学图像分析的潜在应用**：仅需粗粒度分组标签即可发现疾病亚型，为临床中缺乏详细标注的医学影像研究提供了新工具。

## 关键术语表
- **对比分析（Contrastive Analysis, CA）**：仅凭背景/目标数据集标签，将图像变异分解为两组共有因子与目标特有因子的学习范式。
- **表示自编码器（Representation Autoencoder, RAE）**：结合冻结的预训练视觉编码器与可训练解码器的架构，旨在保留丰富语义的同时支持高质量图像生成。
- **显著因子（Salient Factor）**：对比分析中捕获目标数据集特有变异（如眼镜、数字）的表示分量。
- **公共因子（Common Factor）**：捕获背景与目标数据集共享内容（如人脸身份、场景）的表示分量。
- **流匹配（Flow Matching）**：一种扩散模型训练目标，直接学习从噪声到数据的确定性流，而非去噪得分。
- **Vendi 分数**：基于特征矩阵特征值计算的多样性度量，值越高表示样本多样性越好。
- **Cycle NCE**：将 InfoNCE 对比损失应用于循环恢复的表示，迫使不同因子在重编码后仍保持可区分性。
- **rFID / gFID**：分别用于评估重建图像和生成图像与真实图像分布之间的 Fréchet Inception Distance。

## 可复现要素
- **数据集**：
  - Digits-ImageNet：由公开 MNIST 与 ImageNet 合成，公开可用。
  - FFHQ：公开数据集，眼镜属性标注来自 FFHQ Features Dataset（自动标注），本文进行了人工审计。
  - OCT-Kermany：公开视网膜 OCT 数据集。
- **代码与模型**：论文声明将在发表后公开代码、训练好的模型及审计后的 FFHQ 标签。
- **关键超参**：
  - 第一阶段：学习率 $3 \times 10^{-5}$，AdamW（$\beta_1=0.9, \beta_2=0.999$），权重衰减 0.01；FFHQ 训练 200 epoch，Digits-ImageNet 训练 3 epoch，OCT 训练 60 epoch；目标稀疏权重 $\lambda$：FFHQ 0.01，Digits 1.0，OCT 0.01；背景稀疏权重均为 1.0。
  - 第二阶段：学习率 warmup 至 $10^{-4}$ 后余弦衰减至 $2 \times 10^{-5}$；FFHQ 训练 40 epoch，Digits 训练 20 epoch；流匹配时间采样使用 shifted logit-normal，$\tau_{\min}=0.05$；采样步数 50，内部引导尺度 $\omega=1.78$，Classifier-free guidance scale 1.5（Digits）/ 1.0（FFHQ）。
- **硬件**：主要使用 NVIDIA H200 GPU，每卡 batch size 8–32。
