# 论文速读：SHARED-WEIGHTS-SELECTED-COMPUTATIONS-HOW-LOOPED-TRANSFORMERS

## 一句话总结
本文探究 Looped Transformer 中共享权重下的循环计算机制：通过在学习的线性层 J 介入循环边界，证明了相同冻结骨干网络的前一进入隐状态可路由至不同语义转换（一跳/两跳），且该控制通过注意力模式的路由实现。

## 研究问题与动机
1. **核心问题**：Looped Transformer 在多个循环中重复使用同一组参数，但共享权重是否意味着每个循环执行相同的操作？若不同，是什么机制将共享参数路由到不同运算？
2. **现有方法的局限**：先前工作（如 Blayney et al., 2026；Zhang et al., 2026）描述了循环轨迹的现象特征（如固定点、循环轨迹、不同的进展速度），但未能回答进入循环的隐状态是否能因果性地选择下一个计算，以及该选择如何在模型内部实现。
3. **理论缺口**：最终答案监督下的训练目标不约束中间轨迹，导致循环间的计算分配未被明确界定；缺乏对"隐状态→注意力路由→目标选择"这一因果路径的验证。
4. **应用意义**：理解该机制有助于判断何时额外循环可提供有用的计算，以及循环式的推理测试时计算是否可控。

## 核心贡献（创新点）
1. **现象发现**：在图漫步任务中，模型中间解码输出可前进不同步数或保持在已达目标，证明共享权重不意味着"一圈一步"的固定模式。与已有工作相比，本文首次在同一模型内量化了循环间计算速度的可变性。
2. **状态干预控制**：冻结共享 Transformer 层，在循环边界训练一个线性层 J，仅修改进入隐状态即可将同一冻结块路由至不同语义转换（一跳 vs 两跳），实现了高精度目标重定向（一跳从 48.2% → 99.6%，两跳达 98.2%），本质上表明 J 选择的是骨干已学会的计算而非创造新算法。
3. **机制揭示——注意力路由作为因果通道**：通过激活修补（activation patching）证明注意力模式可恢复 J 的转向效果并在一跳/两跳运行间切换预测目标，为"隐状态控制→注意力路由"提供了因果证据。
4. **训练目标决定路由能力**：在十组配对模型中比较最终监督与逐步监督，证明哪个转换可被 J 控制取决于骨干网络在训练中学习了什么计算，为干预设计提供训练策略依据。

## 方法详解
1. **实验框架：图漫步任务**  
   输入为图 G 的排列 $f_G$、起点 s 和深度 d=8，目标是 $f_G^8(s)$。训练两个模型 D8L8 和 D8L6（分别重复两层 Transformer 块 8 次和 6 次），仅对最终答案施加交叉熵监督。

2. **状态转向控制公式**  
   原始循环：$h_{t+1} = F(h_t)$。在循环边界加入线性层 J：$h_{t+1} = F(J(h_t))$，其中 $J(h) = h(D + AB) + b$，含学习对角项、秩 48 的低秩项和偏置，参数约 25,088 个。J 作用在所有 token 上，但不跨位置聚合图信息（该部分需由冻结块 F 执行）。

3. **目标选择实验**  
   从 D8L6 seed 6 的 $h_6$ 出发，训练 $J_{\text{one}}$ 使 $F(J_{\text{one}}(h_6))$ 预测 $f_G(u)$（一跳目标），训练 $J_{\text{two}}$ 使预测 $f_G^2(u)$（两跳目标），在未见图上分别达到 99.6% 和 98.2% 准确率。

4. **注意力修补方法**  
   - 模式-输出分离：$z_{\text{pattern}} = \alpha_1 V_2$（用运行 1 的注意力模式 + 运行 2 的值），$z_{\text{output}} = \alpha_1 V_1$（完全替换）；实验验证模式改变选择的内容而保留接收方的值。
   - 转向-非转向模式互换：$z_{J\to0} = \alpha_J V_0$，验证单向模式补丁可恢复转向效果。
   - 一跳/两跳模式交换：$z_{\text{two→one}} = \alpha_{\text{two}} V_{\text{one}}$，切换预测目标。

5. ** supervision 对比损失函数**  
   $\mathcal{L}_{\text{final}} = \ell_8$，$\mathcal{L}_{\text{stepwise}} = \ell_8 + \frac{1}{7}\sum_{t=1}^{7} \ell_t$，其中 $\ell_t = \text{CE}(R(h_t), f_G^t(s))$。

6. **大模型扩展（Ouro-2.6B）**：在信件传递多跳语言任务和同义反义词消消乐任务上验证上述机制的可迁移性，使用预训练的 16 个选定注意力头进行修补。

## 实验与结果
- **数据集/任务**：合成图漫步（10 节点循环图，512 测试图）、Parity 任务、Ouro-2.6B 信件传递与反义词消消乐、Qwen3-8B 五种数学/日历任务、合成知识图谱关系组合（64 实体×16 关系）。
- **基线**：无 J 的冻结骨干、仅 F、仅 J、停止读出的对比组。
- **核心结果**：
  - 一跳转向：准确率从 48.2%（无 J）提升至 99.6%（有 $J_{\text{one}}$）；两跳达 98.2%（$J_{\text{two}}$）。
  - 模式修补：将转向模式的注意力补丁移入非转向运行，D8L6 一跳准确率从 39.2% 提升至 61.6%；Ouro 达 248/256（96.9%）。
  - 一跳/两跳模式互换：两跳模式移入一跳运行后，两跳答案频率从 0.1% 升至 65.9%；反向从 0.5% 升至 78.5%。
  - 逐步 vs 最终监督配对实验：一跳准确率逐步为 100% vs 最终仅 66.5%；两跳则相反（最终 50.5% vs 逐步 13.2%），五组全部复现该反转。
  - Qwen3-8B 长请求（k=5–8）：J+F 组合在 5 个任务族上平均准确率达 89.69%，而仅 F 为 28.59%。
  - 合成知识图谱：长度 4–16 范围内，J 将准确率从 2.53% 提升至 99.92%；超出训练范围后（长度 17–24）降至 42.87%，长度 25–32 降至 1.65%。
- **最强结果**：Ouro 一对一跳转向达 248/256（96.9%），Qwen3-8B 单任务达 100%（后继/星期/倍增/Fibonacci）。

## 相关工作脉络
1. **Dehghani et al., 2019（Universal Transformer）**：提出循环 Transformer 的共享权重架构，奠定循环计算基础，但本文聚焦于训练后循环内计算的实际分布而非架构表达能力。
2. **Yang et al., 2024；Gatmiry et al., 2024**：证明循环 Transformer 可学会迭代优化算法（如梯度下降），本文在此基础上追问"每个循环具体执行什么计算"及"由什么控制"。
3. **Zhang et al., 2026（当循环成为算法？）**：研究了训练如何选择不同速度的计算前沿，本文与之互补——不仅观察到速度差异，更通过因果干预揭示隐状态如何路由不同转换。
4. **Blayney et al., 2026**：识别层固定点和循环隐轨迹，本文进一步建立隐状态修改→注意力路由→目标选择的因果链。
5. **Singh et al., 2024（Representation Surgery）**：仿射转向理论，本文将其扩展到循环架构的边界，并引入因果机制层面的验证（修补而非黑盒干预）。
6. **Geiping et al., 2025**：循环推理的测试时计算扩展，本文为其机制提供解释基础——循环计算的可控性取决于进入状态的引导。

## 局限性与未来方向
1. **长程组合退化**：控制精度在超过两到三轮后显著下降（八轮后混合序列精确匹配仅约 10%），深层复用仍困难。
2. **监督依赖性强**：转向能力严格受限于骨干网络在训练中学习的计算，无法诱导骨干未曾学过的转换；不同监督策略产生不同的可操控转换集。
3. **合成任务为主**：主要实验在合成图漫步和规则语言任务上进行，虽扩展至 Ouro-2.6B 和 Qwen3-8B，但复杂真实推理任务的机制是否相同尚待验证。
4. **修补范围的局限**：单头修补只能部分恢复转向效果（D8L6 seed 10 单头从 68.3% 提升至 89.4%，全四头可达 93.8%），说明隐状态的其他分量也在起作用，但未完全解析。
5. **长期泛化未验证**：Parity 任务在长度 101–500 改善后，505–1000 反而下降，表明映射的泛化深度有限。

## 研究启发与可借鉴点
1. **线性边界层 J 的训练范式**：冻结骨干+训练轻量线性层干预循环边界的方案（秩 48/128 低秩仿射变换），可作为可控推理测试时计算的通用接口设计参考，参数开销极小（25K–526K）。
2. **注意力模式修补用于因果验证**：将模式补丁与输出补丁分离的比较设计（$\alpha_1 V_2$ vs $\alpha_1 V_1$）可精确定位"选择内容"与"内容本身"的贡献，适用于其他模型的机制解构。
3. **配对监督对比实验设计**：固定初始化和数据、仅改变中间监督目标的配对训练，能干净地隔离监督对可操控计算的影响，可作为消融设计的标准范式。
4. **循环长度外推评估协议**：从 map 训练范围外推至更长循环并报告精确匹配逐轮衰减（图 4、图 9），为"循环计算是否可持续"提供了系统化的评估方法。
5. **与本团队的结合机会**：本工作的"隐状态→注意力路由→目标选择"因果路径可与团队在 latent reasoning / 测试时计算方向结合，探索在更大规模 LLM 上通过状态干预实现可控多步推理的可能性。

## 关键术语表
**Looped Transformer**：在多个循环中重复应用同一组 Transformer 层的递归架构，将前馈深度转化为循环深度。
**State Steering（状态转向）**：通过修改进入循环块的隐状态（如学习线性层 J），在不改变共享权重的情况下路由不同语义转换。
**Activation Patching（激活修补）**：将某次运行的内部激活（注意力模式或输出值）替换为另一次运行的对应值，以测试其因果贡献。
**Pattern Patch vs Output Patch**：前者仅替换注意力权重 $\alpha$（保留接收方的值 $V$），后者替换整个注意力头输出 $z = \alpha V$，二者分离可区分路由与内容。
**Stepwise Supervision（逐步监督）**：在每个循环步骤都对中间目标施加损失，区别于仅对最终答案监督的 final-only 策略。
**Readout**：从模型隐藏状态解码出的当前预测节点/答案，用于观察循环间的任务进展轨迹。
