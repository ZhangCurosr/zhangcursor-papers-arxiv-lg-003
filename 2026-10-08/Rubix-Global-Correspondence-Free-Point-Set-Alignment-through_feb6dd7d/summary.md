# 论文速读：Rubix: Global-Correspondence-Free Point-Set Alignment through Branch-and-Bound in SE(3)

## 一句话总结
Rubix 是一种**全局最优、无对应关系**的点集配准方法，通过在 SE(3) 李群上使用分支定界搜索框架，联合优化旋转、平移与离散匹配，保证收敛到全局最优解而非局部极小值。

## 研究问题与动机
- **非凸优化的局部极小陷阱**：经典 ICP 等方法在点集存在离群点、遮挡或部分重叠时极易陷入局部最优，无法保证全局一致性。
- **对应关系未知**：传统刚性配准假设点对应已知或可迭代求解，但在部分匹配、重叠率不确定场景下对应关系本身即为变量。
- **现有全局方法的计算代价高**：先前基于枚举或采样的全局方法（如 GoICP、Branch&Bound for rigid registration）在高维 SE(3) 空间中搜索空间爆炸，难以同时处理旋转+平移+匹配联合优化。
- **理论完备性与效率的矛盾**：此前工作要么理论保证弱（近似解），要么仅针对纯旋转（S²）或小范围平移，无法在完整 SE(3) 上同时实现理论最优与实用效率。

## 核心贡献（创新点）
1. **SE(3) 上联合重力搜索（Joint Gravity Search）框架**：通过赋权二分图模型结合虚拟节点处理部分匹配，将离散组合优化与连续李群优化统一在同一分支定界框架中。*与已有工作的本质区别*：此前分支定界方法多局限于纯旋转或固定对应关系，本文首次将匹配离散变量嵌入 SE(3) 连续搜索的下界评估。
2. **矩形极值几何简化**：证明全 yaw 圆上独立边下界仅需矩形 box 的极值半径即可闭式求解，将 24 个乘积顶点评估降为仅 3 次 yaw 采样。*与已有工作的本质区别*：突破了此前需枚举大量离散旋转样本才能收紧下界的瓶颈，显著降低每次区域评估的计算量。
3. **部分匹配与未知平移的统一处理**：通过 moment hull（维度 ≤ 17 的充分统计量集合）将平移下的残差表达为凹函数，在 hull 顶点处取极值；无需事先中心化整个点集。*与已有工作的本质区别*：此前方法多假设完全匹配或已知平移，本文在无对应、未知平移条件下仍保持下界 Tightness。
4. **共享最小堆队列与中断安全设计**：所有子搜索共享同一优先队列，支持懒创建与区域未完成不删除的容错机制，保证任意时刻截断均可返回当前最优解及其严格界。*与已有工作的本质区别*：提供工程上的 anytime 能力，适用于实时或预算受限场景，此前方法多为一次性闭式输出。

## 方法详解
- **联合重力搜索（Joint Gravity Search）构造**：采用固定基数 k 的方形赋值表示，实边代价减 $\|e - c_B\|^2$，虚边代价为 0；witness assignment $\tau$ 对应的下界 $\eta_\tau^- = \min_\sigma \sum_i d_{i,\sigma(i)}^-$，其中 $d_{ij}^- = \min_v \{B_{ij}(v) - B_{i,\tau(i)}(v)\}$；Product interpolation 给出 $\eta_\tau^- \leq \min_M h_M(u,e) - h_\tau(u,e)$ 且 $\eta_\tau^- \leq 0$，最终下界 $\min_M \mathcal{E}_M \geq \mathcal{E}_\tau + \eta_\tau^-$。
- **几何简化**：全 yaw 圆上独立边下界只需矩形极值半径 $r_{\min} = \|\max(|c_B|-h_t,0)\|$、$r_{\max} = \| |c_B|+h_t \|$，降阶匹配差在 box 上的最小值可闭式求出，**24 个乘积顶点降至仅 3 次 yaw 评估**。
- **计算复杂度**：单次密集得分 $\mathcal{O}(n^2)$；赋值 $\mathcal{O}(n^3)$；协方差 $\mathcal{O}(n)$；特征值问题常数时间；总复杂度 $\mathcal{O}(N_{\mathrm{query}} n^3 + N_{\mathrm{wit}}^{\mathrm{eval}} n + N_{\mathrm{query}} N_{\mathrm{wit}}^{\mathrm{eval}})$，队列操作 $\mathcal{O}(\log N_{\mathrm{cell}})$，存储 $\mathcal{O}(n^2)$（单查询）或 $\mathcal{O}(N_{\mathrm{query}} n^2)$（批量）。
- **搜索不变量与终止性（Theorem 24）**：不变量 $L = \min\{U, \min_{\Omega \text{ live}} L_\Omega\} \leq E^* \leq U$，空队列时 $L=U$；yaw 弧和 quaternion 坐标不断对半分割使 gap 趋于 0；**无预算时有限终止**，但区域数无上界。
- **部分匹配与平移（Section D.9）**：固定平移时 quaternion 构造仍适用，但需对每个匹配子集单独中心化；未知平移时用充分统计量 $(k, s_{X,M}, s_{Y,M}, S_M, C_M)$ 组成 **moment hull**（维度 ≤ 17），残差对其为仿射函数，$\inf_{R,t}$ 后为凹函数，最小值在有限 hull 顶点处达到。
- **空间搜索算法**：共享 min-heap 队列（Algorithm A.1），根懒创建但 pending anchor 和 32 个 quaternion 根须有有效下界；联合重力搜索（Algorithm A.2）按基数 k 分枝、惩罚模型 $p_k=\lambda(n+m-2k)$，对每枝每 anchor 建根 $\Omega=(k,i,j,[-\pi,\pi],[-r_k,r_k]^3)$，区域评估先用廉价独立边界 $\ell_{\mathrm{edge}}$ 再 on unresolved cell 上用 witness 界，细分全圆分三段 $2\pi/3$ 后 cyclic 二分；完整 SE(3) 四元数搜索（Algorithm A.3）32 个 chart/orthant 根，初始下界 $\max\{0, S-2b_0\}$，最长坐标二分原始 chart box。

## 相关工作脉络
- **GoICP / GoP**：全局刚性配准经典方法，基于分支定界但主要针对纯旋转或完全匹配，未处理未知平移与部分匹配的联合优化。
- **Generalized-ICP / GICP**：基于概率模型的局部迭代方法，依赖良好初值，无全局最优保证。
- **RANSAC 系列配准**：采样验证策略适用于含离群点场景，但为概率近似解，理论最优性无保证。
- **Spectral / Assignment-based 方法**：将匹配松弛为连续优化后舍入，通常只处理固定旋转或纯 2D 场景。
- **四元数旋转搜索（Quat-BB）**：先前工作对 S³ 上的旋转使用四元数 charts 做分支定界，但未扩展至 SE(3) 平移维度。
- **本文定位**：首次在完整 SE(3) 上将旋转（四元数 charts）、平移（moment hull 凹优化）与匹配（联合重力搜索+基数分枝）三者统一在同一分支定界框架内，同时提供全局最优性理论保证与 anytime 工程实现。

## 局限性与未来方向
- **区域数无上界**：虽理论保证有限终止，但不存在多项式区域数上界，极端情况下搜索效率可能下降。
- **高维点集开销**：$\mathcal{O}(n^3)$ 赋值复杂度在大尺度点集（数万级以上）下仍较重，需进一步加速。
- **非刚性形变不支持**：当前框架仅限刚性 SE(3) 变换，未扩展至仿射或非刚性配准。
- **超参 λ 依赖**：惩罚系数 λ 控制基数分枝的松紧，需经验调参，缺乏自适应选择理论。
- **未来方向**：可扩展至非刚性配准、在线/实时版本、与深度学习特征提取器结合以实现端到端全局配准 pipeline。

## 研究启发与可借鉴点
1. **联合重力搜索 + 基数分枝的思路**可迁移至其他含离散匹配的全局优化问题（如结构识别、聚类配准）。
2. **几何简化（极值半径闭式求下界）**的设计范式——将高维枚举降为常数/少量采样评估，适用于任意含旋转对称性的李群优化。
3. **moment hull 处理未知平移**的凹函数技巧，为其他含平移变量的组合-连续混合优化提供了新的下界构造途径。
4. **共享队列 + 中断安全的 anytime 架构**可直接复用于需要实时截断响应的 SLAM、AR 配准等系统。

## 关键术语表
**SE(3)**：三维空间中的刚体变换群，由旋转 SO(3) 和平移 $\mathbb{R}^3$ 半直积构成，是点集配准的标准李群参数化。
**Branch-and-Bound（分支定界）**：通过递归划分离散/连续搜索空间并计算每子区域的下界与上界，剪除不可能含全局最优的子区域。
**Joint Gravity Search（联合重力搜索）**：Rubix 提出的核心下界估计机制，结合二分图匹配与几何约束，为 SE(3) 区域内最优代价提供紧下界。
**Witness Assignment（见证赋值）**：用于构造下界的参考匹配 $\tau$，通过比较不同赋值间的代价差 $d_{ij}^-$ 得到 $\eta_\tau^-$。
**Moment Hull**：由充分统计量 $(k, s_{X,M}, s_{Y,M}, S_M, C_M)$ 构成的低维（≤17）凸包，用于闭式求解未知平移下的残差下界。
**Quaternion Chart**：将 S³ 旋转流形覆盖的 32 个正交 chart 区域，每个 chart 对应一个局部仿射参数化，用于分支定界细分。
**Product Interpolation**：将多维（yaw + box）下界分解为各维度独立下界的乘积插值，用于紧化联合搜索空间的评估。
**Anytime Algorithm**：算法可在任意时刻中断并返回当前最优解及严格界，随运行时间延长下界-上界 gap 单调缩小。
