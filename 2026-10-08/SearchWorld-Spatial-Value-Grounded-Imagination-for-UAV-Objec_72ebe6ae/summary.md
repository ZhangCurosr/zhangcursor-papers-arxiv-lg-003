# 论文速读：SearchWorld: Spatial Value-Grounded Imagination for UAV Object Search via World Models

## 一句话总结
本文提出SearchWorld，一种将显式BEV空间认知记忆与循环状态空间世界模型（RSSM）结合的无人机开放式物体搜索框架；通过解码任务感知空间价值层替代传统标量Critic，并在想象轨迹上池化价值引导移动决策，实现了从反应式探索到前瞻性规划的提升，在UAV-ON基准上以23.8%成功率显著超越现有最强方法。

## 研究问题与动机
1. **核心问题**：无人机在城市环境中进行开放式物体搜索时，需在部分可观测、大尺度区域、密集3D障碍物与开放世界文本指令约束下，自主规划搜索路径并准确停止于目标处。
2. **地图派方法局限**：基于显式地图的代理仅记录历史观测，依赖手工规则或多模态大模型查询对当前视图打分，本质是反应式的，无法预测自身动作对未来状态的影响。
3. **潜在世界模型局限**：隐式潜状态世界模型虽支持想象推演，但空间知识纠缠于扁平向量中；Actor-Critic架构将长程收益压缩为单一标量V(s)，丢失了“何处有价值”的空间定位信息。
4. **动机**：空间记忆与前瞻性推理长期割裂，需将显式物理索引的空间表示与世界模型的想象能力打通，使代理能在地图上做出前瞻决策而非仅对当下观测反应。

## 核心贡献（创新点）
1. **首个面向空载物体搜索的显式空间认知记忆世界模型**：将RSSM与自-centric探索/障碍通道显式绑定，并从潜状态解码任务感知价值层，使搜索状态可直观检查与干预。
2. **认知-动作网络与价值引导想象规划**：用解码的结构化空间价值层替代Actor-Critic的独立标量Critic，通过池化想象动作足迹上的价值分布指导移动决策，同时保持模仿学到的停止行为稳定。
3. **三阶段课程训练策略**：分离世界模型动态学习、专家任务模仿与价值引导精化三个阶段，系统解耦了表征学习、行为先验与策略优化，消融验证了各阶段不可替代的作用。
4. **高推理效率架构设计**：无需每步调用VLM/MLLM或生成视频，仅依赖冻结编码器前向、深度几何反投影、单次RSSM转移与价值头解码，推理速度比主流多模态方法快约一个数量级，契合机载计算约束。

## 方法详解
1. **问题形式化**：将任务建模为POMDP $(S, A, O, P)$，观测$o_t=(I_t, D_t, p_t, \ell)$包含RGB图像、深度图、6-DoF姿态与实例级文本指令；动作空间为基准固定的8个离散原子动作（含stop终止评估）。
2. **显式空间认知记忆（三层BEV网格）**：
   - **探索层**：基于深度与姿态几何构造，累积历史最大折扣可视度 $\mathbf{M}^{\mathrm{expl}}(c)=\max_{\tau\leq t}\left[\left(1-\frac{d_\tau(c)}{\rho}\right)\cos\left(\frac{\pi\Delta\theta_\tau(c)}{\phi}\right)\right]\cdot\mathbb{I}[\cdots]$，记录“已去过哪里”。
   - **障碍层**：前视深度反投影至世界坐标后正交投影至网格，按高度阈值$z_{\mathrm{obs}}$标记不可飞行区域，保障碰撞安全。
   - **价值层**：由世界模型从潜状态解码的任务感知价值场 $\hat{V}_t^{\mathrm{sp}}$，训练时受探索层、障碍层与目标高斯先验联合监督，推理时不接收目标坐标，避免信息泄漏。
3. **任务导向RSSM世界模型**：RGB经冻结DINOv2 ViT与SigLIP视觉塔编码，文本经SigLIP文本塔编码，三者与BEV编码器输出融合为观测嵌入$e_t$；通过GRU更新确定性状态$h_t$，设后验$q_\theta(z_t|h_t,e_t)$与前向$p_\theta(z_t|h_t)$双头预测潜变量；设置RGB解码器、BEV解码器、价值解码器与动作头。想象仅走先验路径：$h_{t+1}=\text{GRU}(z_t,\text{Emb}(a_t),h_t),\ z_{t+1}\sim p_\theta(\cdot|h_{t+1})$，无需像素级视频生成。
4. **认知-动作网络**：认知分支解码空间价值层，价值损失$\mathcal{L}_{\mathrm{value}}$以公式(5)的监督信号回归（目标区高斯先验、已探索区衰减、障碍区置零）；动作分支仅对移动动作$A_{\mathrm{move}}$进行价值引导更新，停止动作概率锁定为Stage-2 BC策略$\pi_{\mathrm{BC}}$，通过KL散度$\mathcal{L}_{\mathrm{action}}=D_{\mathrm{KL}}(\pi^+\|\pi_\theta)$对齐重加权目标策略$\pi^+(a)\propto\pi_{\mathrm{BC}}(a)\exp(Q_V^{(H)}/\tau)$。
