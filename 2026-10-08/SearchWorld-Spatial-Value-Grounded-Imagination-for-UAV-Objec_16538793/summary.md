# 论文速读：SearchWorld: Spatial Value-Grounded Imagination for UAV Object Search via World Models

## 一句话总结
论文提出 SearchWorld，首次将显式空间认知记忆（BEV 网格）与隐式状态空间世界模型结合，用于无人机开放场景目标搜索。通过解码任务感知的空间价值层并指导隐空间想象规划，替代传统标量 Critic，在 UAV-ON 基准上将成功率提升至 23.8%，显著优于现有响应式地图代理与隐式世界模型方法。

## 研究问题与动机
1. **部分可观测性与大范围搜索的矛盾**：城市环境下无人机视场窄、搜索区域大，单一历史观测无法支撑全局决策，需显式记忆记录已探索区域与禁飞区。
2. **现有方法的反应式局限**：基于显式地图的代理（如 APEX、OctMem-Agent）仅对过往观测打分或查询 LLM/MLLM，缺乏对自身动作未来状态的预测能力，探索仍停留在反应式阶段。
3. **隐式世界模型的时空解耦难题**：图像生成型世界模型推理延迟高，无法满足百步级搜索预算；隐空间 RSSM 类模型虽快，但环境知识压缩在平铺潜向量中，无法直接输出“去哪搜索最有价值”的空间先验。
4. **稀疏奖励下 Critic 训练困难**：无人机搜索任务以“到达并停止”为终端奖励，信号极度稀疏，传统 Dreamer 式标量 Critic 难以从噪声中有效自举，导致基于想象的策略优化失效。

## 核心贡献（创新点）
1. **首个面向 aerial object search 的显式空间认知世界模型**：将 BEV 探索层、障碍物层与解码出的任务价值层显式绑定到空间网格，与以往隐式潜态表示的本质区别在于将“我在哪、去过哪、禁飞区在哪、何处值得搜”解耦为可解释的三维通道。
2. **认知-动作网络与价值引导想象**：用从 RSSM 潜态解码的结构化空间价值先验替代 Actor-Critic 中的标量 V(s)，通过池化价值层覆盖动作运动足迹计算效用，本质区别在于不依赖环境返回信号自举，而是由监督目标直接提供空间价值分布。
3. **三阶段课程学习框架**：分阶段完成世界模型动态学习、专家行为模仿与价值引导的移动策略微调；与端到端 BC 或纯 RL 的本质区别在于将表征学习、任务先验与规划优化解耦，避免隐空间漂移与停止行为被覆盖。

## 方法详解
1. **问题建模**：空中目标搜索建模为 POMDP，观测 $o_t=(I_t, D_t, p_t, \ell)$（RGB、深度、6-DoF位姿、实例级文本指令），动作空间为基准固定的 8 个离散原子动作（5平移+2旋转+1停止），episode 上限 150 步。
2. **显式空间认知记忆（BEV 网格）**：维护 256×256、单格 0.4m 的鸟瞰网格，中心对齐搜索区。三层独立来源：
   - **探索层** $M^{\text{expl}}$：累积历史步骤中各格点的折扣可见度，按距离线性衰减与角度余弦加权，实现单调信息积累。
   - **障碍物层** $M^{\text{obs}}$：前视深度反投影至世界坐标后正交投影，垂直高度超阈（>0.5m）即标记禁飞。
   - **价值层**：由世界模型潜态解码，训练期受监督信号约束，推理期无目标坐标输入。
3. **任务导向 RSSM 世界模型**：RGB 经冻结 DINOv2 ViT 与 SigLIP 视觉塔编码，指令经 SigLIP 文本塔编码，BEV 双层经卷积编码器编码，四路线性融合为观测嵌入 $e_t$。动力学遵循标准 RSSM：确定性状态 $h_t=\text{GRU}(z_{t-1},\text{Emb}(a_{t-1}),h_{t-1})$，潜变量分离为先验 $p_\theta(z_t|h_t)$ 与后验 $q_\theta(z_t|h_t,e_t)$。解码头包括 RGB 重建、BEV 重建与空间价值预测。
4. **认知-动作网络**：
   - **认知分支**：$ \hat{V}_t^{\text{sp}} = D_V(h_t,z_t,e_\ell) $，训练标签 $V_t^*=\text{Norm}[(1-M^{\text{obs}})(\lambda_{\text{expl}}(1-M^{\text{expl}})+\lambda_{\text{goal}}G_g)]$，采用鲁棒回归损失。目标位置仅参与标签生成，推理时不泄漏。
   - **动作分支**：初始化自 Stage 2 BC 策略 $\pi_{\text{BC}}$，仅对移动动作施加价值引导，停止概率保持不变以防终止行为被覆盖。
5. **三阶段训练课程**：
   - **Stage 1**：随机动作 rollouts 预训练编码器与 RSSM，联合 RGB/BEV 重建与价值回归，辅以 KL 正则 $\beta_{\text{KL}}=10^{-3}$ 拉近先验与后验。
   - **Stage 2**：专家成功轨迹行为克隆，激活动作头学习搜索-停止策略，编解码器继续训练。
   - **Stage 3**：冻结 RSSM 与价值解码器，从后验状态出发仅用先验路径想象 H 步轨迹；对候选移动动作 $a$，将其运动足迹 $K_{t+1}^a$ 与解码价值层逐格相乘求和得动作效用 $q_V(s_t,a)$，累加为 $Q_V^{(H)}$；目标策略 $\pi^+(a|s_t,e_\ell)\propto\pi_{\text{BC}}(a|s_t,e_\ell)\exp(Q_V^{(H)}/\tau)$，仅对动作头施加 $D_{\text{KL}}(\pi^+\|\pi_\theta)$。

## 实验与结果
- **数据集与设置**：UAV-ON 基准，14 个 photorealistic 场景（10 训练/4 测试，其中 4 场景为 unseen），共约 1.1 万导航任务， episode 上限 150 步。评估指标为 SR、OSR、SPL，按目标尺寸与场景熟悉度分层。
- **主要结果**：SearchWorld 总体 SR 23.80%、OSR 35.52%、SPL 8.03%，较最强发布代理 OctMem-Agent（19.50% SR）提升 4.3 个百分点；在大型目标上 SR 达 35.02%。Seen/Unseen SR 分别为 25.14% / 19.92%，unseen OSR 33.12% 为所有方法最高。
- **推理效率**：单步 0.31s、单 episode 34.5s，比调用多模态语言的基线快一个数量级，仅次 OctMem-Agent（0.58s/步）但 SR 高出 4.3 点。
- **消融结论**：直接 BC（14.33% SR）与 X-Mobility 隐式 RSSM+BC（12.91%）均显著低于本文；Dreamer 式标量 Critic 可恢复到 19.07%，剩余 4.7 点增益归因于显式空间价值 grounding。去除探索层降 5.7 SR，去除障碍物层降 4.0 OSR；跳过任一训练阶段均造成显著性能塌陷（Stage 2 缺失最严重，-12.8 SR）。

## 相关工作脉络
1. **像素级世界模型导航**（PathDreamer、DreamWalker、DreamNav、ANWM）：逐帧生成未来视频供规划，推理延迟高，难以匹配 UAV-ON 的百步级预算；SearchWorld 以单步潜态转移替代视频生成，解决延迟瓶颈。
2. **隐空间 RSSM 导航**（MILE、X-Mobility、NavMorph、WMNav）：世界模型知识隐含在平铺潜向量中，缺乏可读取的空间语义；本文通过 BEV 解码器将隐态显式映射为探索/障碍/价值三层网格，实现“空间感知的想象”。
3. **显式记忆无人机代理**（APEX、PRPSearcher、OctMem-Agent）：依赖 VLM/MLLM 查询或手动规则解码历史观测，属反应式决策；本文引入动力学模型进行前瞻性 rollouts，将探索从“回溯过去”升级为“预测未来”。
4. **基于仿真的 aerial object search 基准**（UAV-ON）：本文在该基准上首次引入学习型世界模型，填补了从无模型启发式/多模态代理到具身规划代理的方法空白。

## 局限性与未来方向
1. **纯仿真评估**：所有实验在 UE+AirSim 中进行，未验证真实飞行平台的传感器噪声、执行器动力学与控制延迟。
2. **理想感知假设**：依赖精确 6-DoF 位姿与 ground-truth 深度，且冻结 DINOv2/SigLIP 预训练编码器，跨域或退化感知下的鲁棒性未测。
3. **2D BEV 抽象损失垂直结构**：障碍物层仅以高度阈值判别，无法表征线缆、悬挑等细粒度垂直障碍。
4. **价值层训练-推理分布差**：训练标签使用真实目标坐标构造高斯先验，推理时目标未知，近目标区域的价值精度依赖世界模型泛化能力。
5. **未来方向**：引入深度/位姿噪声注入研究、跨模拟器 sim-to-real 迁移、实例级语义区分增强、前沿振荡抑制与迟滞选择机制。

## 研究启发与可借鉴点
1. **显式空间通道+隐式动力学解耦设计**：将环境几何/历史覆盖与预测动力学分置不同模块，可降低世界模型的表征负担，适用于任意具身长程任务（室内导航、扫地机器人、自动驾驶）。
2. **用解码价值场替代标量 Critic**：在稀疏/终端奖励场景下，通过空间价值先验引导想象规划，避免 critic 从零自举的方差爆炸问题，可迁移至任何 latent-world-model RL 管线。
3. **三阶段课程学习范式**：先学动态（Stage 1）→ 再学任务先验（Stage 2）→ 最后用想象微调移动策略（Stage 3），阶段间冻结/解冻策略清晰，可作为后续扩展多模态或分层动作空间的通用训练模板。
4. **停止动作概率锁定机制**：价值引导仅重分配移动动作概率而保持停止分布不变，有效防止 imagination-based 优化覆盖已习得的终止行为，对任何含“终止判定”的 POMDP 均有参考价值。

## 关键术语表
**RSSM（Recurrent State-Space Model）**：同时维护确定性递归状态与随机潜变量的世界模型架构，通过后验吸收观测、先验驱动想象推演。  
**BEV（Bird’s-Eye-View）**：以无人机位姿为参考的俯视图网格化空间表征，用于显式记录探索覆盖、障碍物与任务价值。  
**Spatial-Cognition Memory**：由探索层、障碍物层与解码价值层构成的三层显式空间记忆，具备物理坐标与可解释语义。  
**Cognition–Action Network**：将 RSSM 潜态解码为空间价值层（认知分支），并将该先验映射为动作分布（动作分支）的双分支网络。  
**Value-Grounded Imagination**：沿想象轨迹池化解码价值层覆盖的运动足迹，以空间效用替代标量回报指导策略更新。  
**UAV-ON**：开放世界无人机目标导航基准，包含 14 个 photorealistic 城市/自然场景与约 1.1 万指令驱动搜索任务。  
**Oracle Success Rate（OSR）**：只要智能体轨迹任意时刻经过目标附近即计为成功，用于衡量空间搜索覆盖率。  
**Three-Stage Curriculum**：分世界模型预训练、专家模仿、价值引导想象规划三阶段训练，逐步叠加动态、先验与规划能力。

## 可复现要素
- **数据集**：UAV-ON（公开基准），包含训练/测试/未见场景拆分与完整动作接口规范。
- **代码**：匿名仓库 https://anonymous.4open.science/r/test-1657/，训练脚本、数据收集流水线与评估协议已开源。
- **权重**：论文未提供独立权重下载链接，模型参数随匿名仓库一并发布。
- **关键超参**：AdamW（wd=0.01），Stage 1：lr=1e-5、batch=8、100 epoch、seq_len=8、β_KL=1e-3；Stage 2：lr=1e-5、batch=4（accum=3）、30 epoch、分类损失加权 10×；BEV 网格 256×256、分辨率 0.4m、覆盖 102.4×102.4m、感知半径 20m、视场 90°、障碍物高度阈 0.5m；Stage 3 想象步数 H 与温度 τ 按论文 Appendix A 配置；训练 8× NVIDIA H20，单 episode 评估 34.5s。
