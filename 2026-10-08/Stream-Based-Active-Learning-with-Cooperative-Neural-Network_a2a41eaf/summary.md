# 论文速读：Stream-Based-Active-Learning-with-Cooperative-Neural-Network

## 一句话总结
本文提出 CoNN-AL 框架，将流式主动学习集成到合作神经网络（CoNN-DAE）中，通过蒙特卡洛 Dropout 估计预测不确定性来实时指导样本查询决策；在超过 90 万样本的汽车玻璃密封条（GRC）数据集上，仅使用约 2.3%（20,000 个）标注数据即达到 R² = 0.967–0.982，相较随机采样减少 30–40% 的标注需求，并在最困难的 MM=6 条件下成为唯一达到 R² = 0.98 的策略。

## 研究问题与动机
1. **标注成本瓶颈**：工程逆设计中每个标注样本需经过 CATIA 建模 + MSC Marc 有限元仿真（FEA），获取代价高昂，难以构建大规模标注数据集。
2. **CoNN 未考虑标注成本**：此前提出的合作神经网络（CoNN）虽能处理约束感知推理，但假设拥有充足标注数据，未提供降低新标注样本获取成本的机制。
3. **随机采样效率低下**：随机采样不区分样本信息量，在已充分覆盖的设计区域浪费标注预算，在高维设计空间中"维度灾难"进一步加剧冗余。
4. **已有主动学习方法的局限**：现有结合主动学习与逆设计的工作主要基于池化设置（pool-based），且假设所有设计变量可自由选择，无法处理部分逆设计中部分变量被预先固定的约束场景。

## 核心贡献（创新点）
1. **首个流式主动学习 + 合作架构的部分逆设计框架**：将流式主动学习首次集成到合作代理-插补架构中，填补了昂贵评估约束下部分逆设计的数据效率空白；区别于传统池化策略，适应连续到达候选样本的真实工程工作流。
2. **基于 MC-Dropout 不确定性的获取策略**：在合作代理模型上应用蒙特卡洛 Dropout 估计预测方差，并以此作为流式主动学习的实时查询-丢弃信号；区别于标准主动学习仅依赖单一模型的不确定性估计，此处不确定性来自联合优化的代理网络，与插补任务形成闭环反馈。
3. **大规模真实工业数据集上的系统验证**：在 906,215 样本的 GRC 数据集上完成四类实验（上限基准、随机基线、流式主动学习、标签效率分析），证明 CoNN-AL 在 20,000 标注样本下达到 R² = 0.967–0.982，并在 MM=6 最困难条件下以 76,000 样本实现 R² = 0.9838，显著优于随机采样上限。
4. **公开 GRC 数据集**：以 CC BY-NC-SA 4.0 许可公开发布标准化后的 GRC 数据集（906,215 样本），为数据驱动逆设计研究提供大规模仿真基准。

## 方法详解
**CoNN-DAE 基础架构**：由两个互联网络组成——
- **代理模型**（Surrogate）：回归网络 $f(\cdot)$，将完整设计变量矩阵 $\mathbf{X} \in \mathbb{R}^{n \times d}$ 映射到目标性能输出 $\hat{\mathbf{y}}$，训练损失为标准 MSE：$\mathcal{L}_{REG} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$，预训练后冻结。
- **插补模型**（Imputation DAE）：接收原始完整记录 DO、 corrupt 副本 DC 和二进制掩码 MM 作为输入，编码器生成潜在表示 $\mathbf{z} = f_{enc}(DC \oplus MM)$，解码器输出经物理边界裁剪 $\hat{\mathbf{X}} = \text{clip}(g_{dec}(\mathbf{z}), X_{min}, X_{max})$，再恢复已知变量 $\mathbf{X}' = (1-MM) \odot \hat{\mathbf{X}} + DC$。

**联合优化**：插补模型总损失 $\mathcal{L}_{TOTAL} = \alpha \mathcal{L}_1 + (1-\alpha)\mathcal{L}_2$，其中 $\mathcal{L}_1 = \text{MSE}(X', DO)$ 为几何重建损失，$\mathcal{L}_2 = \text{MSE}(\hat{y}, y)$ 为通过冻结代理传播的性能损失；梯度经代理回传至插补网络，使重建结果同时满足几何保真与性能预测准确性。

**流式主动学习循环**：初始种子池 3,000 样本训练 CoNN-DAE；每轮 3,000 个未标注候选依次到达，通过 $T=20$ 次 MC-Dropout 前向传播估计预测方差 $\sigma^2(x_i) = \frac{1}{T}\sum_{t=1}^{T}(\hat{y}_{i,t} - \bar{\hat{y}}_i)^2$；选取方差最高的 750 个 + 随机 250 个共 1,000 个向 oracle（FEA）查询标注，其余 2,000 个丢弃；标注样本加入训练池，模型基于上一轮权重微调 10 个 epoch，循环 100 轮。

**部分逆设计问题设定**：用二进制掩码 MM 标记已知/缺失变量，MM 等级（MM=1 至 MM=6）表示每个样本最多缺失变量数，缺失位置和数量随机选取，模型需学习任意子集的变量重建。

## 实验与结果
**数据集**：GRC（Glass Run Channel）汽车玻璃密封条数据集，906,215 样本（885,735 原始 + 20,480 新增），12 个设计变量（Lip/Notch/Design 三组）+ 1 个输出（密封力 N/dm）；训练池 886,215，测试集 20,000（固定）；输入标准化，输出标准化，公开于 Zenodo。

**评估配置**：（1）上限基准：100,000 和 886,215 样本训练，100 epoch；（2）随机基线：10,000–100,000 样本步进，100 epoch；（3）流式 AL：种子 3,000，每轮 +1,000 标注，100 轮后约 103,000 标注；关键检查点：round 18（20,000）、round 74（76,000）、round 100（102,000）。

**主要结果**：
- **上限基准**：CoNN-DAE 在 100,000 样本时性能已饱和，与 886,215 样本差距可忽略，$R^2$ 在 0.97–0.99 之间，所有 MM 等级稳定。
- **随机基线**：性能在约 40,000 样本处进入平台期，达 $R^2 \geq 0.95$ 需 10,000（MM=1）或 20,000（MM=2–6）样本。
- **流式 AL**：Round 18（20,000 标注）即达到 $R^2$ = 0.967–0.982，相当于训练池的 2.3%；达 $R^2 \geq 0.95$ 仅需 11,000–14,000 标注，比随机采样少 30–40%。
- **标签效率（MM=6）**：达到 $R^2=0.96$ 需随机 30,000 vs AL 15,000（2.0×效率）；$R^2=0.97$ 需随机 40,000 vs AL 20,000（2.0×）；$R^2=0.98$ 仅 AL 以 76,000 样本达成，随机采样在 100,000 内未达此阈值。
- **最优检查点对比（MM=6）**：AL 76,000 样本 $R^2=0.9838$、MSE=0.0164，MSE 较随机 60,000（0.0260）和 UB 100,000（0.0259）降低约 37%，但 MAE 略高（0.0628 vs 0.0503）。

## 相关工作脉络
1. **CoNN 原始工作**（Nugraha et al., 2025, [9]）：提出合作神经网络框架处理部分逆设计，本文在此基础之上引入主动学习以减少标注成本；CoNN 假设充足标注数据，无样本选择机制。
2. **池化主动学习 + 逆设计**（如 AutoTandemML [21]、InvDesFlow-AL [22]、[23,25,27,28]）：采用固定候选池选择策略，且假设所有变量可自由选取，不适用于部分变量预固定的工程约束场景；本文改为流式设置并支持掩码变量。
3. **贝叶斯优化在约束设计中的应用**（[12,13,14]）：用于处理高成本黑盒优化，但在高维设计和大数据集下计算昂贵且敏感；本文以数据驱动代理模型替代迭代优化循环。
4. **蒙特卡洛 Dropout 不确定性估计**（Gal & Ghahramani, 2016, [34]）：理论基础，本文将其应用于合作代理网络的预测不确定性估计以驱动主动学习获取。
5. **生成式逆设计方法**（[8,15,16]）：使用 VAE/GAN 等生成模型进行逆设计，本文聚焦于约束感知的插补-代理合作架构，与生成方法互补。
6. **流式主动学习综述**（Cacciarelli & Kulahci, 2024, [18]；Settles, 2009, [17]）：本文属于流式主动学习在工程仿真场景的具体应用，区别于纯统计场景的流式主动学习研究。

## 局限性与未来方向
1. **确定性插补架构**：当前仅使用 CoNN-DAE（确定性去噪自编码器），无法捕捉设计空间的分布结构，难以提供多样候选解；未来可扩展至变分自编码器（VAE）或 Wasserstein 自编码器（WAE）。
2. **单一不确定性估计器**：仅依赖 MC-Dropout 估计不确定性，可能低估或误判真实预测不确定性；可探索深度集成（Deep Ensembles）作为替代或补充。
3. **单输出设定**：当前框架针对单一输出（密封力）的逆设计，未验证多输出目标（如同时优化多个性能指标）的适用性。
4. **领域泛化待验证**：仅在汽车 GRC 案例上验证，需在结构优化、材料设计、制造过程优化等其他工程领域验证通用性。

## 研究启发与可借鉴点
1. **合作架构 + 主动学习的范式迁移**：将确定性插补与代理模型的联合训练框架与不确定性感知的主动学习结合的思路，可迁移至其他高成本仿真的工程逆设计问题（如热管理、流体结构耦合）。
2. **MC-Dropout 不确定性作为获取信号**：在冻结代理模型上直接应用 MC-Dropout 估计方差，无需额外训练不确定性模型，计算开销低；适合在线/流式场景的实时决策。
3. **流式设置优于池化设置**：对于连续生成候选设计的工程工作流（如参数扫描），流式主动学习更贴合实际部署形态，避免预处理全量候选池的存储开销。
4. **性能饱和点的识别价值**：上限实验揭示 100,000 样本已足够饱和，提示在类似规模问题中应优先优化样本选择质量而非单纯扩大标注预算。
5. **混合获取策略**：AL 每轮保留 250 个随机样本（25% 比例）作为探索分量，有助于防止不确定性估计偏差导致的选择偏差，可借鉴为"探索-利用"平衡策略。

## 关键术语表
- **部分逆设计（Partial Inverse Design）**：仅部分设计变量可自由指定，其余由制造/材料/法规等约束预先固定，模型需推断缺失变量以使完成后的设计满足目标性能。
- **合作神经网络（Cooperative Neural Network, CoNN）**：由代理模型和插补模型联合训练的架构，插补模型通过代理模型的性能反馈信号学习，使重建的变量不仅几何保真且性能预测准确。
- **流式主动学习（Stream-Based Active Learning）**：未标注样本按序到达，模型实时决定是否向 oracle（仿真）查询标签或丢弃，适用于连续生成候选设计的工程场景。
- **蒙特卡洛 Dropout（MC-Dropout）**：推理时保持 Dropout 激活进行 T 次前向传播，以预测方差估计模型不确定性，作为贝叶斯近似的轻量级方法。
- **玻璃密封条（Glass Run Channel, GRC）**：安装于车辆车窗边框的橡胶密封组件，本文以密封力（N/dm）为目标性能的工业设计案例。
- **MM 等级（Masking Level）**：每个样本中缺失设计变量的最大数量（MM=1 至 MM=6），用于系统性评估不同设计不完整程度下的模型鲁棒性。
- **获取策略（Acquisition Strategy）**：基于不确定性等信号决定哪些候选样本应被标注的函数，本文采用"最高不确定性 75% + 随机 25%"的混合策略。
