# 论文速读：OUTPUT-AWARE-RESIDUAL-STREAM-PRUNING-FOR-LARGE-LANGUAGE-MODE

## 一句话总结
本文提出一种感知输出的残差流剪枝方法，通过引入模型输出对扰动方向的敏感度，将二阶 KL 散度近似与激活协方差结合，选择应剪除的残差方向，从而在保持模型行为方面显著优于仅最小化激活重构误差的 SliceGPT。

## 研究问题与动机
- 残差流剪枝（如 SliceGPT）仅通过最小化激活重构误差来选择待剪维度，隐含假设所有扰动方向同等重要，忽略了下游层对这些方向的敏感性差异。
- 相同幅度但不同方向的激活扰动，可能对模型输出分布产生截然不同的影响，仅凭激活能量无法区分。
- 现有方法缺乏对剪枝后输出分布 KL 散度的直接建模，导致在高压缩率下性能下降更明显。
- 需要在保留旋转不变性的结构化剪枝框架内，引入可计算的输出敏感度信息，以改进方向选择准则。

## 核心贡献（创新点）
- **输出感知的残差流剪枝目标**：基于原始与剪枝模型输出分布的 KL 散度二阶近似，推导出同时包含激活协方差与局部敏感度矩阵的目标函数，本质区别在于从“激活保真”转向“输出分布保真”。
- **敏感加权谱上界近似**：将难以直接优化的迹乘积目标转化为对加权矩阵 `τC + τ⁻¹H` 的特征分解，使得计算复杂度仍保持与 SliceGPT 同阶的谱方法水平。
- **统一框架下的灵敏度估计**：通过单次反向传播近似层内 Fisher 信息矩阵 `H`，避免了逐 token 存储高维 Hessian，兼顾精度与效率。
- **跨模型族的一致性提升**：在 Llama、Mistral、Phi 等多个指令微调模型及非指令模型上验证，方法在高稀疏率下仍能更好保留数学推理与指令跟随能力。

## 方法详解
- **残差流剪枝基础**：利用 Transformer 对残差流正交变换的旋转不变性，选择正交基 `Q = [V U]`，移除 `U` 张成方向后可将投影吸收进相邻线性层，直接缩小权重矩阵维度。
- **SliceGPT 目标回顾**：通过最小化 `Tr(UᵀCU)` 选择低方差方向，其中 `C` 为激活的二阶矩矩阵，等价于未中心化 PCA。
- **输出敏感度建模**：以 KL 散度 `D_KL(pθ(·|s) || pθ(·|s; x̂i))` 在原始激活处的二阶展开定义敏感度，Hessian `Hi(s)` 为对干预激活的 Fisher 信息矩阵。
- **层内共享曲率近似**：用所有校准 token 的平均曲率 `H = E[Hi(s)]` 替代 token 特异性 Hessian，得到目标 `L(U) = Tr(UᵀCUUᵀHU)`，仅增加一个 `d×d` 矩阵存储。
- **谱上界推导**：利用不等式 `(uᵀCu)(uᵀHu) ≤ ¼[λ_min(τC + τ⁻¹H)]²`，将子空间选择转化为对 `M_τ = τC + τ⁻¹H` 取最小特征值对应的特征向量，通过离散网格搜索 `τ` 并在各候选上评估原目标选优。
- **正则化解释**：联合优化上界等价于最小化 `L(U) + ||UᵀCU||_F ||UᵀHU||_F`，显式耦合激活能量与敏感度。
- **实现细节**：灵敏度矩阵通过单 token 采样加平均 log-prob 单次反向传播估计；协方差 `C` 与特征分解均用双精度；`τ` 搜索网格取 `{1, 7, 10, 30, 70}`。

## 实验与结果
- **模型与基线**：在 Llama-3.2 3B、Llama-3.1 8B、Mistral 7B v0.3、Mistral Nemo、Phi-3 Medium 五个指令微调模型上与 SliceGPT 对比，稀疏率 10%–30%。
- **校准数据**：语言建模与常识推理使用 1,024 条 FineWeb-Edu 序列（长度 2,048）；生成任务使用 1,024 条 Tulu3 对话样本，仅对 assistant token 计算敏感度。
- **主要指标**：KL 散度、Perplexity（WikiText-2）、下游平均准确率（WinoGrande、MMLU、ARC-E/C、HellaSwag、OpenBookQA、PIQA）以及数学推理（GSM8K）和指令跟随（IFEval）。
- **最强结果**：在 Llama-3.2 3B 30% 稀疏率下，方法将 PPL 从 57.17（SliceGPT）降至 30.14，平均准确率从 47.40% 提升至 49.43%；KL 散度从 1.5830 降至 0.9435。
- **跨模型一致性**：所有模型在所有稀疏率下，方法的 KL 与 PPL 均低于 SliceGPT，且在 GSM8K 与 IFEval 上指令跟随与推理能力保留更好。
- **额外实验**：使用 RedPajama 作为校准集仍获得一致提升；在非指令微调的 Llama-2/3 模型上同样有效；增加校准样本至 1,024 后性能趋于稳定；额外优化 `L(U)` 仅带来微小改进。
- **耗时**：在 Llama-3.1-8B 上灵敏度估计耗时 9 分钟，总校准时间较 SliceGPT 增加约 11 分钟（单卡 H100），开销可控。

## 相关工作脉络
- **SliceGPT（Ashkboos et al., 2024）**：残差流剪枝的代表作，通过旋转不变性与 PCA 移除低方差方向；本文在其基础上引入输出敏感度，从激活重构扩展到输出分布保持。
- **LLM-Pruner / LLM-Surgeon**：基于结构化剪枝与一阶/Fisher 信息的重要性估计，针对注意力头或 MLP 通道；本文专注于残差维度的整体剪枝，与块内剪枝形成互补视角。
- **YAQA（Tseng et al., 2026）**：从完整模型 KL 散度二阶近似推导量化目标；本文与其思路最接近，但应用于残差流方向选择而非权重量化。
- **SparseGPT / Wanda**：基于 Hessian 或权活乘积的单次剪枝方法，产生非结构化稀疏；本文保持密集权重结构，无需定制内核即可部署。
- **EvoPress / Tyr-the-pruner**：通过进化搜索优化剪枝配置以最小化输出分布 KL；本文提供解析化的谱近似方案，计算效率显著更高。

## 局限性与未来方向
- **层间与跨 token 曲率忽略**：共享层内 `H` 忽略了不同 token 间敏感度差异及层间相互作用，可能在敏感方向差异大的数据上表现受限。
- **参数开销**：残差流剪枝需引入过渡矩阵 `(V^(ℓ+1)ᵀV^ℓ)`，虽随保留维度平方降低，但仍额外增加存储与计算。
- **校准数据依赖性**：方向选择依赖校准集分布，若校准数据与下游任务差异较大，敏感度估计可能偏差。
- **未来方向**：探索跨层共享或参数高效的旋转变换、结合自适应 τ 搜索、扩展至非指令模型与多模态架构。

## 研究启发与可借鉴点
- **输出分布感知的设计范式**：将压缩目标从“中间激活保真”转向“输出分布保真”，为其他结构化剪枝/量化方法提供可迁移的评估视角。
- **谱上界简化高维优化**：利用特征分解将非凸迹乘积目标转化为可并行计算的谱搜索，兼顾理论严谨与工程效率。
- **敏感度高效估计技巧**：通过平均 log-prob 单次反向传播近似 Fisher 信息，避免逐样本 Hessian 计算，适合大规模模型后训练剪枝。
- **τ 网格搜索的工程可行性**：仅需 5 个 τ 值即可在候选子空间中找到优质解，便于集成到现有剪枝流水线。
- **校准集任务匹配设计**：对生成任务仅计算 assistant token 的敏感度，体现针对不同任务分布的针对性建模思想。

## 关键术语表
**Residual-stream pruning**：直接压缩 Transformer 残差流隐层维度的结构化剪枝方法，通过旋转不变性将方向移除吸收进相邻线性层。
**SliceGPT**：基于 PCA 与旋转不变性的残差流剪枝基线，通过最小化激活重构误差选择待剪方向。
**KL divergence**：衡量原始模型与剪枝模型输出概率分布差异的散度指标，本文用作输出保真度的代理目标。
**Fisher information matrix**：在干预激活处的 KL 散度二阶导数，刻画模型输出对该激活方向的敏感度。
**Sensitivity-weighted covariance**：将激活协方差 `C` 与敏感度矩阵 `H` 加权组合为 `M_τ = τC + τ⁻¹H`，用于谱方向选择。
**Rotational invariance**：Transformer 层对残差流正交变换的不变性，使旋转后可直接截断维度而无需重新训练。
**Transition matrix**：跨层残差连接中因正交基不同而引入的 `(d-k)×(d-k)` 变换矩阵，用于对齐保留子空间。
