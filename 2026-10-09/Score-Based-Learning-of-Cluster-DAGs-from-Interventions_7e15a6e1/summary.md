# 论文速读：Score-Based-Learning-of-Cluster-DAGs-from-Interventions

## 一句话总结
本文提出 **coarse**，首个基于分数的方法，用于从未知目标的多目标软干预数据中学习**干预粗化（interventional coarsening）**集群DAG。该方法通过干预特征直接确定集群划分与因果顺序，再用跨环境聚合的BIC分数进行局部搜索恢复边，在多项式时间内保持一致性，且边恢复速度较现有约束基线快最多**510倍**。

## 研究问题与动机
1. **细粒度因果发现不实用**：像素、神经元等高维变量不适合直接推理，且大规模DAG搜索是NP-hard。
2. **现有粗化学习方法依赖脆弱CI检验**：RePaRe等约束法在两阶段均需条件独立性检验，条件集增大时检验力下降，误差累积严重。
3. **缺乏基于分数的粗化学习框架**：传统分数方法针对单一DAG，无法直接用于学习变量聚类后的粗化图，尤其未知多目标干预情形。
4. **多目标干预的可识别性**：单目标干预下签名可识别粗化，多目标时现有方法不可识别，需扩展理论并设计新算法。

## 核心贡献（创新点）
1. **提出coarse**：首个基于分数的干预粗化学习算法，将两阶段模板中的CI检验替换为分数比较，本质区别在于避免多重检验误差，直接利用边际偏移信息。
2. **用干预签名确定因果顺序**：证明签名单调性使支撑顺序成为拓扑序，每个块的候选父块集无需全局搜索，区别于传统顺序搜索方法。
3. **设计聚合BIC分数**：在线性高斯假设下，块级模型为弯曲指数族，BIC跨环境聚合后保持可分解性与局部一致性，区别于单环境BIC或约束测试。
4. **理论扩展与效率保证**：将干预粗化扩展到未知多目标干预情形，证明coarse在Oracle假设下一致，最坏情况多项式时间，区别于仅适用于单目标的RePaRe。

## 方法详解
1. **干预签名与集群划分**：定义节点v的签名σ(v)={e≠0 | X_v边际分布在环境e与观测不同}。通过Welch t检验（或通用两样本检验）构建干预后代矩阵M，将相同签名行合并为块π，迭代细化得到分区Π̂^ε。
2. **支撑顺序与候选父块池**：由签名单调性（u→w ⇒ σ(u)⊆σ(w)）定义偏序π_a <supp π_b ⇔ supp(π_a) ⊊ supp(π_b)。任意线性扩展τ均为拓扑序，块π的候选父块池为pa*(π)={π' : supp(π') ⊊ supp(π)}，包含所有真父块且不含后代。
3. **块级线性高斯模型**：对块X_j（维度r_j）与其父块X_Pa_j（维度s_j），环境e中建模为X_j^(e)=B_j^(e)X_Pa_j^(e)+ε_j^(e)，ε_j^(e)~N(0,Σ_j^(e))。该模型为弯曲指数族，对数似然可分解为各块之和。
4. **聚合BIC分数**：对每个块j和环境e，BIC_j^(e)(π_j,Pa_j)=-n_e log|Σ̂_j^(e)|-λ log(n_e)d_j，其中d_j=r_j s_j+r_j(r_j+1)/2为参数维度。聚合BIC_j(π_j,Pa_j)=∑_e BIC_j^(e)，总BIC(H,D)=∑_j BIC_j。
5. **非贪心局部搜索**：对每个块π_j，在其候选父块池pa*(π_j)上运行得分版Grow-Shrink算法：增长阶段添加使BIC增加的候选块，收缩阶段移除使BIC减少的块，直到稳定，输出粗父集Pâ_j。
6. **完整算法流程**：输入数据D、检验水平α、惩罚λ。①构建M̂；②迭代细化得Π̂^ε；③计算各块支撑与父池；④对每块运行GrowShrink得Pâ_j；⑤输出粗DAG Ĝ。

## 实验与结果
- **数据集**：合成数据为ER图（d=10~1000，ρ=0.2，m=5，n_e=10^3~10^5）与尺度无关图；真实数据为光隧道因果实验台（d=20变量，1观测+5干预环境）。
- **基线**：RePaRe（约束法）、GIES、GnIES、UT-IGSP（细粒度方法）。
- **一致性**：随n_e增加，ARI与F1上升；d=200、n_e=10^5时F1=0.95，d=1000时F1=0.79。
- **与RePaRe对比**（Oracle分区下）：n_e=5×10^3起coarse F1≥0.99，d=500、n_e=10^5时两者均达1.00±0.01；**速度加速比最高达510倍**（d=500, n_e=10^5）。
- **真实数据**：coarse与RePaRe均恢复正确分区（ARI=1）；coarse块级F1=0.89，变量级F1=0.74，fit+search仅需0.42秒，远低于GnIES的376秒。
- **最强结果**：Oracle分区下d=500、n_e=10^5时F1=1.00，比RePaRe快329~510倍。

## 相关工作脉络
1. **RePaRe (Madaleno et al., 2026)**：约束两阶段学习干预粗化；本文用分数替代CI检验，避免多重检验误差累积。
2. **GIES (Hauser & Bühlmann, 2011)**：已知干预目标的细粒度学习；本文处理未知目标且学习粗化图。
3. **GnIES (Gamella et al., 2025)**：未知软干预目标的细粒度学习；本文目标为粗化图，无需估计目标。
4. **UT-IGSP (Squires et al., 2019)**：联合估计干预目标与图；本文不估计目标，直接通过签名识别块。
5. **FLOP (Wienöbst et al., 2026)**：顺序搜索局部结构；本文顺序由干预签名固定，无需搜索。
6. **因果抽象理论**：Rubenstein等（精确抽象）、Beckers等（抽象层次）；本文聚焦图形视图的可学习性。

## 局限性与未来方向
- **局限性**：
  1. 混合流水线：分区依赖d·m次检验，多重检验负担重，小样本误差易传播；Welch t检验仅检测均值偏移，高阶矩变化会被漏检。
  2. 聚合BIC偏宽松：单个环境证据即可保留边，可能产生假边；大块参数多，需更多样本。
  3. 分辨率受干预限制：多目标干预会合并本可区分的变量。
  4. 理论假设强：无环、线性高斯、无隐藏混淆、软干预、有观测基线；硬干预或无基线时不适用。
- **未来方向**：
  1. 用非参数或描述长度准则替代检验获取签名。
  2. 联合估计分区和边，替代两阶段分离。
  3. 开发目标感知的聚合分数以提高样本效率。
  4. 结合稳定性选择为每条边提供置信度。
  5. 扩展至循环图、无基线设置、非线性/非高斯模型。

## 研究启发与可借鉴点
1. **签名识别顺序思想**：利用数据异质性（干预导致的边际变化）直接确定部分顺序，避免全局顺序搜索，可迁移至其他因果发现任务。
2. **聚合分数设计**：跨环境聚合局部BIC，利用任一环境的依赖关系突破惩罚项，保证一致性，可推广至异构数据融合场景。
3. **高维降维变体**：kPC-coarse和avg-coarse通过主成分或均值压缩块维度，在n_e远小于块大小时仍可进行分数估计，为高维因果发现提供思路。
4. **实验设计借鉴**：使用负控制（negative control）评估算法是否优于随机猜测；详细消融超参数λ和α的影响。
5. **可结合方向**：将签名识别与深度学习特征提取结合，用于神经科学或图像中的高层次因果结构学习。

## 关键术语表
**Intervention signature**：节点v的干预签名σ(v)是使其边际分布发生变化的环境集合，用于识别节点所属集群。
**Interventional coarsening**：将干预无法区分的变量合并为块的粗化DAG，是本文学习的目标。
**Support order**：由块支撑集（签名）的包含关系定义的偏序，给出块之间的因果顺序。
**Pooled BIC**：聚合BIC，跨所有环境对块级回归的BIC求和，作为局部搜索的得分函数。
**Grow-shrink**：非贪心的局部结构搜索算法，通过反复添加和移除候选变量寻找Markov边界。
**Curved exponential family**：块级线性高斯模型构成弯曲指数族，保证BIC的分解性和局部一致性。
**Adjusted Rand Index (ARI)**：衡量预测分区与真实分区相似度的指标，1表示完全一致。
**Negative control**：随机生成的DAG作为基线，用于判断算法是否真正优于随机猜测。

## 可复现要素
- **代码开源**：https://github.com/tedescoG/coarse
- **数据集**：合成数据由`semler`包生成（ER图、尺度无关图），参数可复现；真实数据为light-tunnel causal chamber（Gamella et al., 2025），已公开发布。
- **关键超参**：检验水平α（默认10^{-4}，可通过交叉验证选择）、惩罚系数λ（默认1）、块降维参数k（用于kPC-coarse）。
- **评估指标**：ARI（分区恢复）、Precision/Recall/F1（边恢复）、运行时间。
