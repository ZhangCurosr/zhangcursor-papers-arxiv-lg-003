# 论文速读：Using-Weisfeiler-Leman-Features-for-Algorithm-Selection-in-C

## 一句话总结
本文针对约束规划（CP）中的算法选择问题，提出了一种基于Weisfeiler-Lehman（WL）图核与新型“Cut”机制的自动化图特征提取方法，将FlatZinc模型转化为有向结构图并生成轻量级固定维度特征，成功弥合了传统机器学习“结构盲区”与图神经网络计算开销之间的鸿沟，在MiniZinc Challenge基准上显著提升了SVM的算法选择性能。

## 研究问题与动机
- **核心问题**：CP算法选择高度依赖对问题实例的特征表征，传统方法（如`fzn2feat`）依赖人工设计的实例级统计量，难以捕获变量与约束之间的复杂底层结构。
- **现有方法不足**：图神经网络（GNN）虽能捕捉图结构，但需大量训练数据且推理延迟高，不适用于对特征提取效率敏感的算法选择场景；而传统非深度方法普遍缺乏结构感知能力。
- **需求gap**：亟需一种既保留图结构语义、又无需训练深度模型、且计算轻量的特征提取范式，以无缝兼容SVM/RF/MLP等经典机器学习架构。
- **动机**：利用WL图核的理论表达能力（等价于1-WL测试，可近似GNN的区分能力上限）并结合自定义的“Cut”机制，使特征对约束运算符的变长输入具有不变性，从而提供更精细、更稳定的预测信号。

## 核心贡献（创新点）
1. **提出面向约束规划的定制化有向图转换框架**：将FlatZinc模型分解为变量、参数、算子、约束与求解目标五类节点，并设计Lead/Trailing/Global三种有向边，主动省略域值节点以避免图规模爆炸。与现有二分图或三分图方案相比，本转换专为局部约束分解与有向信息传播设计，兼顾表达力与计算可行性。
2. **引入“Cut”机制的WL特征提取（WLc）**：通过冻结特定切割节点（cut nodes）的颜色聚合过程，并用集合（set）替代多重集（multiset）进行最终颜色更新，使相同类型的全局约束/算子即使参数量不同也能获得一致的结构表征。相比标准WL或WLn/WLe，该设计从根本上解耦了度敏感性，提供更鲁棒的结构性预测信号。
3. **构建轻量级图特征流水线并验证其与经典ML的兼容性**：将WL图核生成的直方图特征与辅助结构特征结合，经归一化与全局词表对齐后直接输入SVM/RF/MLP。与依赖端到端训练的GNN方案不同，本方法无需训练即可产出特征，且提取耗时普遍低于1秒，适合在线/批量算法选择部署。

## 方法详解
- **图转换（Graph Conversion）**：从FlatZinc模型提取五种节点（Variable, Parameter, Operator, Constraint, Solution）及对应子类型；边为有向，分为Lead（无序操作数/左侧操作数）、Trailing（有序操作数右侧）、Global（连接全局约束）三类；优化问题中Solution节点连向目标变量，可满足性问题中Solution节点孤立；排除域值节点以控制图规模与噪声。
- **WL特征提取**：对转换后的有向图执行T步颜色细化，初始颜色为节点类型与子类型的哈希；聚合时结合入边邻居颜色（可选加入边类型与节点类型信息）；本文仅采用最后一步的直方图（经附录F消融实验验证，与全步拼接无统计学显著差异）。
- **Cut机制（WLc）**：针对`all_different`、`cumulative`等变长参数的全局约束/算子节点设为cut nodes；在迭代过程中冻结其颜色更新（跳过正常聚合），但仍向后传播；聚合完成后，用其初始邻居颜色的**集合**重新哈希生成最终颜色，从而消除度差异影响；同时生成（原初颜色, cut节点颜色）的节点对直方图以保留度信息。
- **辅助特征与后处理**：增加变量出度（参与约束/算子的平均数量）与参数出度（参与操作的平均数量）；原始直方图按节点总数|V|归一化至[0, 1]；构建全局颜色词表并对齐缺失颜色（测试集新颜色丢弃），最终拼接为固定维度向量供下游ML模型使用。

## 实验与结果
- **数据集**：2023–2025 MiniZinc Challenges 共300个实例（剔除1个不可解实例后剩余289个）。
- **基线**：Single Best Solver (SBS)、Majority Classifier (MC)、`fzn2feat`（95维手工特征）。
- **任务设置**：(1) Borda Count最大化（三求解器：OR-Tools CP-SAT, Chuffed, CPLEX）；(2) 预测准确率最大化。采用重复5折嵌套交叉验证（10个随机种子）。
- **主要结果**：
  - **Borda Count任务**：SVM搭配`WLc-n-1`平均得分0.48、中位数0.51，显著优于`fzn2feat`（平均0.45、中位数0.47）；RF与MLP上`fzn2feat`略占优或持平。
  - **准确率任务**：SVM搭配`WLc-n-1/2`平均准确率达0.69、中位数0.68/0.69，明显高于`fzn2feat`（平均0.66、中位数0.67）；RF/MLP上两者差异微小（RF上`fzn2feat`稍好，MLP上Cut特征稍好）。
  - **提取成本**：绝大多数实例的Cut特征提取时间<1秒，虽绝对耗时高于`fzn2feat`，但处于可接受范围，且当前实现未充分优化。
- **结论**：Cut-based WL特征在SVM上稳定超越传统手工特征，证明了轻量级图结构特征可有效提升经典ML在CP算法选择中的表现；多聚合步数对结果影响可忽略。

## 相关工作脉络
- **SATzilla / CPHydra / SUNNY**：经典算法选择器，依赖手工特征（如`fzn2feat`）与kNN/RF等模型；本文定位为其在特征表示层面的升级，用自动化的图结构特征替代部分手工统计量。
- **MIPGNN / GNN for CP (Cappart et al., 2023)**：利用图神经网络学习问题实例表示；本文与之的本质区别在于避免深度模型的训练开销与推理延迟，专注于与SVM/RF/MLP兼容的无训练图核特征。
- **Boisvert et al. (2024)**：提出类抽象语法树的约束图表示；本文借鉴其分解思路但进一步省略域值节点、采用有向边，并明确针对算法选择场景的提取效率进行优化。
- **WL Kernel / Graph Neural Networks (Xu et al., 2018; Morris et al., 2023)**：1-WL测试界定了标准消息传递GNN的表达能力上限；本文直接采用WL图核作为特征提取器，无需训练即获得理论上有界的结构表征。
- **Cheminformatics / Automated Planning中的WL应用 (Young, 2022; Chen et al., 2024)**：WL核已验证于分子图与规划领域；本文首次将其系统性地引入约束规划算法选择，并创新性地加入“Cut”机制以适应CP中变长全局约束的特性。

## 局限性与未来方向
- **当前局限**：图转换未包含域值节点，可能对依赖值域分布的任务损失信息；Cut机制仅针对特定全局约束/算子节点设计，泛化性有待验证；特征提取管道未充分优化（串行实现），大规模实例下延迟可能上升。
- **未来方向**：优化提取效率（并行化独立图操作）；探索Cut特征与`fzn2feat`等经典特征的融合策略；将框架迁移至动态/在线算法选择场景；拓展至除算法选择外的其他CP学习任务（如分支策略预测、参数调优）。

## 研究启发与可借鉴点
- **“结构不变性”设计的通用启发**：Cut机制通过集合聚合替代多重集聚合，有效解耦了图节点度与语义结构的耦合，该思想可迁移至任何存在“变长参数/子结构”的图特征提取任务（如程序分析、分子图同构判别）。
- **经典ML + 图核的轻量化路线**：在资源受限或需快速迭代的工业场景中，放弃端到端GNN训练而采用WL图等无训练提取器，可显著降低部署成本；本工作提供了完整的工程化范式（转换→提取→归一化→词表对齐）。
- **实验设计值得借鉴**：采用Borda Count与Accuracy双任务并行评估，结合SVM/RF/MLP三种异构模型交叉验证特征普适性；使用嵌套交叉验证与Wilcoxon显著性检验，评估严谨。
- **可扩展创新机会**：可将Cut机制推广至边权重/动态约束场景；结合本团队研究方向（如组合优化神经启发式、自动化机器学习特征工程），探索将WLc特征与其他结构特征（如谱特征、子图计数）联合建模。

## 关键术语表
- **Algorithm Selection**：根据问题实例特征从算法组合（portfolio）中自动选择最优求解器的机器学习任务。
- **Weisfeiler-Lehman (WL) Kernel**：基于图节点颜色细化的迭代算法，通过统计最终颜色直方图来度量图的结构性相似性，表达能力受限于1-WL同构测试。
