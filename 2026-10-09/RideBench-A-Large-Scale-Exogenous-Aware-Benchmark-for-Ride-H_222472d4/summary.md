# 论文速读：RideBench-A-Large-Scale-Exogenous-Aware-Benchmark-for-Ride-Hailing-Time-Series-Forecasting

## 一句话总结
本文发布 Ride-Hailing 数据集与 RideBench 基准，首次系统评估未来可知外生变量（天气、节假日、大型活动）对网约车时间序列预测的帮助，揭示当前模型在外生扰动捕捉与长周期多目标平衡上的双重局限。

## 研究问题与动机
1. **现有基准忽视外生感知需求**：主流时序预测基准侧重内生模式与多元相关性，缺乏对未来可知分类外生信号（节假日类型、大型活动）的系统支持。
2. **空间异质性建模缺失**：网约车市场在不同区域呈现截然不同的出行结构与外生响应，但现有基准未提供多区域全局训练与迁移评估设置。
3. **长周期运营规划缺乏评测**：平台除周度调度外还需8周以上战略规划，但现有基准最大评估 horizon 仅 512-900 步，且缺少趋势质量与近期可靠性的联合度量。
4. **点误差与宏观趋势脱节**：长周期预测需同时保持低点误差、准确的大趋势方向和可靠的近期精度，现有模型未能在三者间取得均衡。

## 核心贡献（创新点）
1. **发布 Ride-Hailing 合成数据集**：基于滴滴真实市场数据脱敏生成，覆盖200个区域、4年半小时间隔、1400万+记录，包含天气扰动、节假日效应、大型活动影响三类外生场景。
2. **提出 RideBench 双任务基准**：常规周预测（336步）与长周期8周预测（2688步），前者评估点精度与场景鲁棒性，后者额外引入日级 Acc. 与 Corr. 衡量趋势质量。
3. **建立全局多区域训练协议**：将200个区域样本池化训练单一模型，逼近真实部署场景，同时检验模型在异质区域间的泛化与迁移能力。
4. **揭示外生利用与长周期规划的双重局限**：证实未来可知外生变量对常规预测有明确收益，但现有外生感知模型仍无法充分捕捉扰动诱导的模式变化；长周期预测中点精度、趋势质量、近期可靠性难以兼顾。

## 方法详解
- **数据切分**：前3年训练、中间6个月验证、最后6个月测试，滑动窗口生成样本，样本归属由其完整预测窗口决定，避免跨分裂泄露。
- **归一化策略**：内生变量与连续外生变量使用训练期统计量标准化，离散外生变量保留为整数标识符，预测后反变换回原始尺度。
- **预测设置**：
  - 周预测：1344步历史（4周）→ 336步未来（1周），stride=48（1天）。
  - 8周预测：4704步历史（14周）→ 2688步未来（8周），stride=336（1周）。
- **评估指标**：
  - 点精度：WMAPE、MAE、RMSE。
  - 趋势质量（长周期）：Acc.（日级方向准确率）与 Corr.（日级皮尔逊相关），将半小时预测聚合为日值后计算。
  - 近期可靠性：First-week WMAPE/MAE/RMSE。
- **损失函数**：统一使用 MAE loss（因扰动导致误差重尾，MSE 对异常值过敏感）。
- **优化**：AdamW，学习率搜索 $\{3\text{e-}5, 1\text{e-}4, 3\text{e-}4, 1\text{e-}3, 3\text{e-}3\}$，batch size 128，早停 patience=3。
- **外生编码适配**：对原有仅支持连续外生的模型，引入 ordinal、one-hot、可学习 categorical embedding 三种离散编码策略，并扩展其接口以支持预测期的未来外生输入。

## 实验与结果
- **数据集规模**：200 区域 × 4 年 × 半小时 = 14,025,600 条记录，9 个内生目标变量，3 类外生变量（天气影响因子、3 种节假日类型、2 种大型活动类型），2 个日历协变量（小时、星期）。
- **基线覆盖**：30+ 方法，涵盖 SeasonalNaive/Mean、DLinear/PatchTST/PETformer/SegRNN 等通道独立模型、Crossformer/iTransformer/PMDformer 等多变量模型、TiDE/CATS/XLinear/DAG 等外生感知模型、Chronos-2/TimesFM 2.5/Moirai 2.0 等基础模型。
- **常规周预测最强**：TiDE 以 WMAPE 0.1043、MAE 3.996、RMSE 12.43 全面领先，平均 rank 第1；外生感知模型整体优于内生模型，证实未来可知外生变量的价值。
- **8周预测格局反转**：ModernTCN（WMAPE 0.1262）与 PETformer（WMAPE 0.1278）领先，TiDE 反而退居中游，说明长周期更依赖稳定时序结构而非外生信号。
- **趋势质量与点精度脱钩**：高 Acc./Corr. 模型（如 TiDE Acc. 0.6137）不一定点误差最低，反之亦然。
- **外生利用分析**：TiDE 引入外生后相对提升 10.4% 最大；节假日与大型活动场景增益小于天气，因分类信号语义稀疏且区域响应异质。
- **区域扩展实验**：固定10个测试区域，逐步增加训练区域至200个，任务特定模型持续改善，基础模型在训练数据充足时优势减弱。
- **Lookback 实验**：28天（约4周）为默认，过长（98天）反而轻微退化；基础模型对 lookback 更敏感，需至少28天才接近任务特定模型。

## 相关工作脉络
1. **Monash / TSlib / BasicTS+ / ProbTS**：通用时序预测基准，缺乏未来外生变量支持，无多区域与长周期场景评估，RideBench 在其基础上引入外生感知与运营导向任务。
2. **TFB / GIFT-Eval / TIME**：关注公平性、零样本与可扩展协议，但仍未针对市场驱动型需求、分类外生信号与长周期多目标设计评测。
3. **fev-bench**：支持未来外生连续/离散变量，但最大 horizon 仅168步、无多区域与趋势评估，RideBench 将 horizon 扩展至2688步并引入场景细分评测。
4. **QuitoBench**：高质量开放基准，最大 horizon 512步，无外生与多区域设置，RideBench 补全这些运营刚需维度。
5. **现有外生感知模型（TiDE / XLinear / TimeXer / DAG / CrossLinear / CATS）**：主要面向连续协方差或历史上下文设计，RideBench 揭示其对分类信号与异质区域响应的不足。
6. **时序基础模型（Chronos-2 / TimesFM / Moirai / Timer-S1）**：零样本泛化强，但在细粒度外生驱动场景下仍落后于任务特定训练模型，且对足够长历史上下文依赖显著。

## 局限性与未来方向
1. **数据合成与隐私折衷**：Ride-Hailing 为脱敏合成数据，虽保留核心时序信号与外生关系，但可能与原始业务数据存在分布偏移，影响模型在真实生产环境的泛化验证。
2. **外生编码的实用主义妥协**：为适配现有模型引入的离散外生编码（one-hot/embedding）属工程修补，未提供原则性方案理解分类信号的语义结构与跨区域异质响应。
3. **长周期多目标权衡未解**：当前无模型能同时优化点误差、趋势质量与近期可靠性，缺乏显式多目标损失或架构设计。
4. **大型活动样本稀疏**：事件类外生变量在时空分布上极不均衡，现有模型难以学习可靠的事件响应模式，需更完善的稀缺事件建模策略。
5. **基础模型领域适应不足**：零样本基础模型在任务特定大数据面前优势减弱，未来需在预训练阶段融入领域外生知识与多区域异质结构。

## 研究启发与可借鉴点
1. **趋势质量评估的可迁移设计**：Acc. 与 Corr. 两个日级聚合指标简洁有效，可推广至任何需同时关注点精度与宏观轨迹的长周期预测任务（如电力负荷、零售需求）。
2. **全局多区域训练协议的价值**：将多区域样本池化训练单一模型既逼近部署现实，又强制模型学习可迁移时序结构，值得在交通、气象等空间异质领域复用。
3. **外生变量类型敏感性分析框架**：通过 Weather/Holiday/Event 三类场景的差异化增益对比，清晰揭示连续 vs 分类、密集 vs 稀疏外生信号的不同利用难度，可作为外生感知模型评估的标准范式。
4. **MAE vs MSE 的扰动鲁棒性选择**：在重尾误差场景（如受极端天气影响的网约车需求）中 MAE 优于 MSE，这一结论对含异常值或突变点的时序预测任务具有普适参考价值。
5. **基础模型对历史长度依赖的发现**：Chronos-2 等零样本模型在 lookback < 28 天时性能显著下降，提示在实际部署中需根据基础模型特性调整输入窗口长度，而非盲目沿用短窗口。

## 关键术语表
- **Ride-Hailing 数据集**：基于滴滴市场数据合成的网约车时间序列数据集，200区域、4年半小时间隔、1400万+记录，含三类外生场景。
- **RideBench 基准**：面向外生感知网约车预测的综合评测基准，支持周预测与8周预测双任务及多区域全局训练。
- **未来可知外生变量**：在预测时刻已确定或可提前获取的外部信号，如天气预报、节假日日历、已排期大型活动。
- **通道独立建模**：各目标变量分别建模而忽略变量间交叉依赖的策略，如 PatchTST、PETformer。
- **Exogenous-Aware 模型**：显式引入外部协变量（连续或分类）辅助预测的模型，如 TiDE、XLinear、TimeXer。
- **时序基础模型**：在大规模跨域数据上预训练、可直接零样本应用于下游预测任务的大模型，如 Chronos-2、TimesFM、Moirai。
- **Acc.（Directional Accuracy of Day）**：长周期预测中日级趋势方向准确率，衡量预测序列与真实序列增减方向的一致性。
- **Corr.（Correlation of Day）**：长周期预测中日级轨迹的皮尔逊相关系数，衡量预测整体形状与真实形状的匹配程度。

## 可复现要素
- **数据集**：Ride-Hailing 已公开于 outreach.didichuxing.com/opendata/datasets（脱敏合成版本）。
- **代码**：RideBench 基准代码开源至 github.com/ACAT-SCUT/ridebench。
- **关键超参**：学习率搜索集合 $\{3\text{e-}5, 1\text{e-}4, 3\text{e-}4, 1\text{e-}3, 3\text{e-}3\}$，batch size 128，MAE loss，AdamW 优化器，早停 patience=3，默认 lookback 28天（1344步周预测 / 4704步8周预测），stride 分别为48步与336步。
- **硬件环境**：Python 3.11 + PyTorch，8× NVIDIA RTX A6000 GPU 集群。
