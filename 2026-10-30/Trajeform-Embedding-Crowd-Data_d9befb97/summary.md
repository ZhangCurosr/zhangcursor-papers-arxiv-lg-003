# 论文速读：Trajeform-Embedding-Crowd-Data

## 一句话总结
论文提出 **Trajeform** 框架，通过训练基于真实轨迹数据的重建型 VAE 学习行为语义连续的隐空间嵌入，将合成轨迹与真实轨迹投影到同一空间后进行分布级行为相似性度量，弥补了传统轨迹特征指标对行为层面的刻画不足。

## 研究问题与动机
- **现有评价指标局限于轨迹级几何特征**：如 DFG（目标偏差）、OP（最优路径）等聚合指标难以捕捉行为语义（例如左转与右转行为不同但路径可能相似）。
- **已有 embedding 方法要么依赖合成数据，要么缺乏可控性**：学习到的表征对 in-the-wild 真实人群数据的泛化能力受限。
- **人群模拟器评估缺乏统一的行为相似度度量**：不同来源的轨迹（合成 vs 真实）难以在一致空间中进行可解释比较。
- **小样本场景下需要更鲁棒的表征学习**：真实轨迹数据集规模有限（约 2k 条），需避免过拟合场景特有模式。

## 核心贡献（创新点）
1. **提出 Trajeform 框架**：通过轨迹重建 VAE 直接从未标注的真实数据中学习行为对齐的连续隐空间，无需显式行为标签。与 Crowd Space 等手工定义嵌入方式本质不同——本方法让模型自由学习特征。
2. **构建可采样的隐空间后验分布（MoG）**：对真实轨迹隐编码进行 k-means 聚类，以聚类中心和密度构建高斯混合分布作为行为基线，支持生成新轨迹和分布比较。与 VQ-VAE 等离散方案相比，保留连续可微特性便于采样与编辑。
3. **提出归一化隐空间度量（Latent Metric）**：定义为 $||z - z_s||_2 / ||z - \tilde{z}||_2$，其中 $\tilde{z}$ 为真实轨迹重构造再编码的结果，值<1表示行为匹配。该度量与 MMD、SWD、JSD 等多维指标趋势一致，提供互补的行为相似度视角。
4. **展示三大应用场景**：（a）评估不同模拟器（CCP/RVO/MPACT/GREIL/CEDRL）生成的轨迹与真实数据的行为贴近度；（b）可视化不同数据来源（控制实验、自行车轨迹）在隐空间的覆盖情况；（c）指导模拟器参数选择，通过隐空间编辑将合成分布推向真实分布。

## 方法详解
**整体流程**：预处理 → VAE 训练 → 隐空间聚类 → MoG 后验构建 → 合成数据投影与比较。

**模型架构**：
- 采用 **conv2gru** 结构（卷积编码器 + GRU 解码器），经消融实验验证优于 conv2conv、gru2gru 等组合。
- 编码器输出 8 维隐变量 $z \in \mathbb{R}^8$，引入 Mixture of Gaussians (MoG) 作为先验。
- 额外添加前馈长度预测头，从隐空间预测轨迹长度分类（CrossEntropy 损失），以 mask 形式输入解码器提升生成质量。

**损失函数**：
$$\mathcal{L} = \mathcal{L}_{VAE} + \mathcal{L}_{len}$$
$$\mathcal{L}_{VAE} = \text{MSE}(\tau) + \beta \cdot \mathcal{L}_{KL}, \quad \beta = 0.1$$
低 β 值权衡重建质量与隐空间对标准正态先验的拟合。

**数据预处理**：
- 过滤短轨迹（$L < 5$），截断长轨迹（$L > 104$）
- 空间归一化：平移至原点、旋转运动方向至 x 轴正向、翻转至第一象限
- 可选标准化 $(z - z_{mean})/z_{std}$ 和噪声增强 $\epsilon \sim \mathcal{N}(0,1)$

**隐空间度量**：
- 自洽性检查：从 MoG 采样 → 解码 → 编码回隐空间，计算分布距离（得分 0.705 < 1，证明空间自洽）
- 行为相似性：$||z_R - z_{syn}||_2 / ||z_R - \tilde{z}_R||_2$，值越小表示合成轨迹越接近真实行为

## 实验与结果
**数据集**：
- 真实数据：Flock (24条)、Students (849条)、Zara (531条)、ETH (750条)，采样间隔 0.4s，最终训练集约 2k 条，最大长度 104 帧
- 测试集：Zara3（保留不参与训练）
- 合成数据：来自 CCP、modCCP、RVO、MPACT、CEDRL、GREIL、PAG 等模拟器

**实验设置**：
- 硬件：Intel i7-11800H CPU, RTX 3070 GPU
- 超参：batch size=16, dropout=0.2, lr=$3 \times 10^{-4}$, 200 epochs（VAE 100 + 长度头 100）
- 聚类数 k=3（经消融确定）

**主要结果**：
- 测试集重建损失 0.959，长度损失 3.634，平均隐损失 0.582
- **MoG 后验分布**在多数指标上最优：MMD=0.705、SWD=0.008、Energy=0.328、JSD_x=0.007、JSD_speed=0.004
- **MPACT** 模拟器表现次优（Latent Metric=1.867），RVO 第二（2.732），CCP 最差（4.433）
- Hold-out 实验表明模型未过拟合单一数据集（如剔除 ETH 后损失从 1.286 升至 2.160，反映 ETH 行为独特性）
- 消融验证：conv2gru 架构测试隐损失 0.381，MoG 先验略高于标准正态（0.443 vs 0.381）但仍可接受；VQ-VAE 重建损失 1.187 显著高于 VAE

## 相关工作脉络
- **Crowd Space [15]**：基于熵特征的降维方法，用于选择最佳模拟器；本文聚焦嵌入学习而非分类，且采用连续 VAE 而非离散码本。
- **Morphable Crowds [7] / GREIL [6]**：数据驱动轨迹建模；本文不使用逆向强化学习或固定行为预置，而是端到端学习隐表示。
- **DFG/OP 等传统指标 [17]**：关注轨迹几何聚合特征；本文方法捕捉行为语义层面的相似性，二者互补。
- **Perceptually-Validated Metrics [13]**：结合人工感知评估；本文完全数据驱动，避免人为偏见。
- **MPACT [4]**：基于 modCCP 参数空间训练轨迹预测模型；本文在此基础上进一步学习行为隐分布，实现参数空间的指导优化。

## 局限性与未来方向
- **未显式建模环境信息**（POIs、障碍物），限制了隐空间的语义可解释性（无法直接映射到动作标签）。
- **真实数据规模有限**（~2k 条），难以覆盖全部行为模式；Transformer 等更复杂架构因数据量不足未采用。
- **缺乏统一的基准评测协议**：现有文献缺少标准化的 benchmark 和 baseline scores，难以全面对比。
- **邻居交互与群体行为未显式建模**：虽在轨迹中隐式编码，但未直接利用多智能体上下文信息。

## 研究启发与可借鉴点
1. **小样本下的隐空间正则化策略**：低 β 值（0.1）平衡重建与 KL 散度的设计，可迁移至其他轨迹/序列建模任务。
2. **归一化隐距离度量设计**：$||z - z_s||_2 / ||z - \tilde{z}||_2$ 的分子-分母归一化思想，可推广至其他领域的时间序列生成质量评估。
3. **隐空间后验建模（MoG）指导数据采样**：用聚类中心构建先验分布并指导参数搜索，适用于模拟器校准、数据增强等场景。
4. **预处理规范化提升泛化**：平移/旋转/翻转消除位置朝向偏差，对任意轨迹嵌入任务具有通用参考价值。
5. **多指标交叉验证**：Latent Metric 与 MMD/SWD/JSD 趋势一致但关注不同维度，提示多维度评估的重要性。

## 关键术语表
- **Trajeform**：本文提出的基于 VAE 的人群轨迹行为嵌入框架，将轨迹映射到连续隐空间。
- **MoG（Mixture of Gaussians）**：高斯混合模型，用于对真实轨迹隐编码进行聚类后建模隐空间后验分布。
- **Latent Metric**：归一化隐空间距离度量，用于量化合成轨迹与真实轨迹的行为相似性。
- **conv2gru**：本文选用的最优架构组合，卷积编码器 + GRU 解码器，兼顾特征提取与序列平滑生成。
- **DFG（Deviation From Goal）**：传统轨迹评估指标，测量 agent 当前位置到目标的最短路径偏差。
- **SWD（Sliced Wasserstein Distance）**：通过随机 1D 投影计算 Wasserstein 距离，适用于无配对轨迹的分布比较。
- **In-the-wild**：指非受控环境下采集的真实人群轨迹数据，与 controlled environment（控制实验）相对。
- **Canonicalization**：轨迹预处理步骤，包括平移、旋转、翻转，使模型聚焦行为特征而非空间位置。
