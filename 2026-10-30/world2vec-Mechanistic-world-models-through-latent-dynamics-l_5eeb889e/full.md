# world2vec: Mechanistic world models through latent dynamics learning

Tobias Schmidt<sup>∗</sup>, Rodrigo Gonzalez Laiz<sup>∗</sup>, Krisztián Szuppinger & Steffen Schneider<sup>†</sup> Helmholtz Munich & Munich Center for Machine Learning (MCML)

## Abstract

World models can achieve strong control performance without faithfully capturing the dynamics of their environment, limiting their potential for mechanistic interpretability and scientific discovery. Here, we introduce world2vec to learn mechanistic world models without reward information directly from observations and actions. World2vec learns latent dynamics that faithfully reproduce the true system over long prediction horizons, with at least one order of magnitude fewer parameters than DreamerV3, TD-MPC2 and LeWM. This enables state of the art performance in controlling continuous environments from pixels and accurate system identification across a benchmark of 71 attractors, demonstrating how world models are amenable to scientific discovery.

## 1 Introduction

Estimating models of dynamically changing systems and environments is an important problem at the frontier of representation learning, with applications in physical AI and scientific discovery <sup>1–7</sup>. Here we focus on the problem where a state s evolves under actions a according to dynamics f, and we observe this state through a non-linear mixing function g:

$$
{ \dot { \pmb { s } } } = \mathbf { f } ( { \pmb { s } } , \pmb { a } ) , \qquad \ \pmb { x } = \mathbf { g } ( { \pmb { s } } ) .\tag{1}
$$

Then, latent world modeling<sup>6</sup> is the problem of jointly estimating, from observations and actions alone, an encoder h that maps observations to a representation $z = \mathbf { h } ( \pmb { x } )$ and a latent dynamics model <sup>ˆ</sup>f that describes how this representation evolves in time. Ideally, the representation is a change of coordinates of the state, $z = \mathbf { r } ( s )$ with $\mathbf { r } = \mathbf { h } \circ \mathbf { g }$ invertible, and the latent dynamics reproduce the true evolution in these coordinates<sup>8</sup>,

$$
{ \dot { z } } = { \hat { \mathbf { f } } } ( z , a ) , \quad z ( 0 ) = \mathbf { r } ( s ( 0 ) ) \quad \Longrightarrow \quad z ( t ) = \mathbf { r } ( s ( t ) ) { \mathrm { ~ f o r ~ a l l ~ } } t \geq 0 .\tag{2}
$$

If this condition holds, the world model (h, <sup>ˆ</sup>f) can support model-predictive control or model-based reinforcement learning to steer the environment into desired target states. Over the past years, this type of world modeling has become feasible and gained theoretical grounding. Common objectives are reconstruction-based forecasting<sup>9</sup>, reconstruction-free planning in latent space, either trained with rewards <sup>10,11</sup> or reward-free using the joint-embedding predictive architecture <sup>6,12,13</sup> (JEPA).

Importantly, world modeling extends beyond solving a particular control task. We also seek to ensure that the world model accurately reflects the world in a statistical sense: Does the learned dynamics model reproduce the relevant dynamics when the statistical assumptions used to build it are satisfied? If satisfied, an appropriate parameterization can further enable mechanistic interpretability by allowing us to read out the environmental dynamics. This has value both for interpretability and scientific applications. World models with these properties have recently been characterized as mechanistic world models<sup>14</sup>. Building on ideas from non-linear independent component analysis<sup>15</sup>, it has been shown that self-supervised learning is able to provably estimate latent representations and their dynamics from data <sup>16</sup> across a range of objective functions. <sup>17,18</sup> Transferring these theoretical guarantees into algorithms that scale to challenging control problems is the goal of this present work.

In this paper, we propose world2vec (Fig. 1A) to advance the shared goal of building a world model that (i) achieves state-of-the-art performance on control tasks after training on offline data alone, (ii) faithfully models the environment, measured via long-range rollouts and predictions, and (iii) is mechanistically interpretable and thus suitable for scientific applications. World2vec is agnostic to its exact training objective, provided it belongs to a class of objectives known to yield identifiable representations under idealized conditions. We consider LeJEPA<sup>12,19</sup> and dynamics contrastive learning<sup>16</sup> (DCL) as two possible approaches to achieving this goal. These objectives encode statistical assumptions with different implications on numerical estimation, and an increasing body of theoretical work addresses the identifiability of these objectives<sup>16,17,20,21</sup>.

Across three considered environments, world2vec jointly achieves high reward and performance in forecasting (Fig. 1B), enabling successful model predictive control in 2 of 3 environments, none of which were solvable by the previous best JEPA-based approach<sup>12</sup>. In the remainder of the paper, we introduce the idea of dynamics matching and the world2vec framework (§2), which we benchmark on control across several MuJoCo environments (§3) and on symbolic regression (§4).

## 2 The world2vec framework for mechanistic world modeling

Mechanistic world modeling<sup>14</sup> seeks to recover a representation of the physical state, a faithful model of its evolution, and ideally an interpretable description of the governing equations. For the system in Eq. 1, we observe x and a, but have no direct access to s or f. We aim to learn an encoder h that maps observations to latent states $z = \mathbf { h } ( \pmb { x } )$ , and their dynamics $\dot { \pmb z } = \hat { \bf f } ( \pmb z , \pmb a )$

Faithful latent dynamics. When does this learned model faithfully describe the physical system? Let r = h ◦ g denote the mapping from physical to latent states. If r is invertible, the latent representation is simply a change of coordinates of the physical state. The model is then faithful<sup>8</sup> if encoding the evolved physical state yields the same trajectory as evolving the encoded state in latent space (Eq. 2). Integrating the latent dynamics over a horizon T, we require:

$$
\hat { z } _ { t } ( T ) : = z ( t ) + \int _ { 0 } ^ { T } \hat { \mathbf { f } } \left( \hat { z } _ { t } ( \tau ) , a ( t + \tau ) \right) d \tau \overset { ! } { = } \mathbf { h } \big ( x ( t + T ) \big ) \qquad \mathrm { f o r ~ a l l ~ } t , \ T \geq 0 .\tag{3}
$$

Importantly, both sides of this condition can be computed from observations and actions alone, without access to the states s or the ground truth dynamics f.

The world2vec objective. To learn the encoder–dynamics pair $( \mathbf { h } , \hat { \mathbf { f } } )$ in practice, we collect a dataset D with observations sampled at intervals $\Delta t ,$ i.e., at times $t _ { n } = n \Delta t$ , and recorded actions. Under partial observability, a single observation does not necessarily determine the state; for example, velocities cannot be inferred from a single frame. The encoder therefore takes a short history ${ \pmb X } _ { n } = ( { \pmb x } _ { n - H + 1 } , \ldots , { \pmb x } _ { n } )$ of length H, chosen such that the state can be recovered from it, $\mathrm { i . e . }$ such that the map from $s ( t _ { n } )$ to $X _ { n }$ is injective <sup>16</sup>, and maps it to the latent state $z _ { n } = \mathbf { h } ( X _ { n } )$ For training, we sample starting points $n \sim p _ { D }$ and select observations $\pmb { x } _ { n - H + 1 : n + K }$ and actions $\pmb { a } _ { n : n + K - 1 }$ so we can roll out the model for K steps.

The dynamics model $\hat { \mathbf { f } } ( z , \pmb { a } )$ predicts the latent rate of change, which a numerical integration step Φ uses to advance the state by $\Delta t .$ We hold each action constant within its sampling interval and obtain the latent rollout

$$
\begin{array} { r } { \hat { z } _ { n , 0 } = \mathbf { h } ( X _ { n } ) , \qquad \hat { z } _ { n , j + 1 } = \Phi ( \hat { z } _ { n , j } , { \pmb { a } } _ { n + j } ) , } \end{array}\tag{4}
$$

where $\hat { z } _ { n , j }$ is the inferred latent state predicted j steps ahead from starting point n, to be compared to the encoded observation $z _ { n + j } = \mathbf { h } ( X _ { n + j } )$ . Our main experiments use explicit Euler integration:

$$
\Phi ( z , { \pmb a } ) = z + \Delta t \hat { \bf f } ( z , { \pmb a } ) .\tag{5}
$$

Evaluating Eq. 3 at $T = j \Delta t$ for $j = 1 , \ldots , K$ then gives the training objective

$$
\operatorname* { m i n } _ { \mathbf { h } , \mathbf { \hat { f } } } \mathbb { E } _ { n \sim p _ { D } } \left[ \sum _ { j = 1 } ^ { K } w _ { j } \left\| \mathbf { h } ( \mathbf { X } _ { n + j } ) - \hat { z } _ { n , j } \right\| _ { 2 } ^ { 2 } \right] + \lambda \mathcal { R } ( \mathbf { h } , \mathbf { \hat { f } } ) \quad ( w o r l d 2 v e c o b j e c t i v e ) ,\tag{6}
$$

where $w _ { j }$ are optional weightings for each step and $\mathcal { R } ( { \bf h } , \hat { \bf f } )$ is a regularizer, weighted by $\lambda \geq 0$ , to prevent representational collapse (a constant encoder trivially satisfies Eq. 3). In dynamics contrastive learning (DCL), prediction scores based on squared distances are normalized against sampled negative embeddings<sup>16</sup>. In the LeJEPA instantiation, SIGReg regularizes embedding projections toward an isotropic Gaussian<sup>19</sup>. We refer to the resulting models as world2vec-dcl and world2vec-sigreg and give details on the full objectives in Appendix A.

From single-step to multi-step dynamics matching. Equation 3 is a condition on “latent velocities”. Integrated along the latent rollout, the learned velocity field $\hat { \mathbf { f } }$ must reproduce the change of the encoded state ${ \boldsymbol { z } } ( t + T ) - { \boldsymbol { z } } ( t )$ . We term this principle latent dynamics matching. For a single step $( K = 1 )$ , the world2vec objective matches velocities directly, up to a finite-difference approximation:

$$
\left\| \dot { z } ( t _ { n } ) - \hat { \mathbf { f } } ( z _ { n } , a _ { n } ) \right\| _ { 2 } ^ { 2 } \approx \left\| \frac { z _ { n + 1 } - z _ { n } } { \Delta t } - \hat { \mathbf { f } } ( z _ { n } , a _ { n } ) \right\| _ { 2 } ^ { 2 } \propto \left\| \left[ z _ { n } + \Delta t \hat { \mathbf { f } } ( z _ { n } , a _ { n } ) \right] - z _ { n + 1 } \right\| _ { 2 } ^ { 2 } ,\tag{7}
$$

where the right-hand side is the single-step term of Eq. 6, computed with the residual predictor of Eq. $^ { 5 , }$ similar to the approach in Neural $\mathrm { O D E s } ^ { 2 2 }$ . Over multiple steps, the terms of Eq. 6 match the encoded displacement with the velocities accumulated along the model’s predicted trajectory:

$$
\left\| \frac { z _ { n + j } - z _ { n } } { \Delta t } - \sum _ { \ell = 0 } ^ { j - 1 } \hat { \mathbf { f } } ( \hat { z } _ { n , \ell } , \pmb { a } _ { n + \ell } ) \right\| _ { 2 } ^ { 2 } \propto \left\| \hat { z } _ { n , j } - z _ { n + j } \right\| _ { 2 } ^ { 2 } .\tag{8}
$$

Training on this residual exposes how small one-step errors compound over long rollouts. We hypothesize that modeling state change through a learned velocity field provides a useful inductive bias for world modeling.

Empirical identifiability of latents and their dynamics. The world2vec algorithm is a numerical implementation of learning principles that have been extensively studied theoretically and are known to produce representations that are consistent up to at least affine transformations<sup>17,20,21</sup>. The challenge lies in the numerical estimation to obtain this guarantee in practice. As an empirical measure of identifiability, we check whether independently trained encoders recover equivalent representations up to an affine change of coordinates, termed consistency<sup>23</sup>. To estimate consistency, we report the $\hat { R } ^ { 2 }$ after optimal affine alignment for the two encoders $\mathbf { h } _ { 1 }$ and $\mathbf { h } _ { 2 }$

$$
\operatorname * { m a x } _ { L , b } R ^ { 2 } \left[ \{ { \bf h } _ { 2 } ( X _ { n } ) \} _ { n } , \{ { \cal L } { \bf h } _ { 1 } ( X _ { n } ) + b \} _ { n } \right] ,\tag{9}
$$

across independent training runs. Within each model, we also assess whether the learned dynamics reproduce the evolution of its representation using Latent Rollout Consistency $\mathrm { ( L R C ) } ^ { 8 }$

$$
\mathrm { L R C } _ { j } = R ^ { 2 } [ \{ { \bf h } ( X _ { n + j } ) \} _ { n } , \{ \hat { z } _ { n , j } \} _ { n } ] ,\tag{10}
$$

where $j$ is the prediction horizon. This score compares predictions and encoded futures from the same encoder–dynamics pair, but can be prone to collapse (i.e., a trivial embedding could get a high LRC). Hence, we also adopt the accuracy-based equivariance measure of Schmidt et al. <sup>24</sup> which for our time series case we denote as Equivariance Accuracy (EQA). EQA is the top-1 retrieval accuracy of the encoded future observation among negative candidates. We select model hyperparameters based on validation EQA and use 512 negatives in all experiments.

Dynamics parameterization. The function class for $\hat { \mathbf { f } }$ can be flexibly chosen within the world2vec framework. For our main experiments focused on control, we utilize an MLP that maps latent state and action to the rate of change. As a more interpretable parameterization, we build on $\mathrm { \dot { S } I N D y } ^ { 2 5 }$ and the more recent $\mathrm { D Y S C O } ^ { 2 6 }$ and fit the structured dynamics model

$$
\hat { \bf f } ( z , { \pmb a } ) = \Xi \pmb { \theta } ( z , { \pmb a } ) ,\tag{11}
$$

where $\pmb \theta ( \pmb z , \pmb a ) \in \mathbb { R } ^ { p }$ is a fixed vector of library features and $\Xi \in \mathbb { R } ^ { d \times p }$ contains learned coefficients for a d-dimensional latent space. Our SINDy instantiation uses polynomial features for θ and an $L _ { 1 }$ penalty on $\Xi ^ { 2 5 , 2 7 , 2 8 }$

Model-predictive control. Given a sequence of target frames $X ^ { \star }$ , we define $z ^ { \star } = \mathbf { h } ( X ^ { \star } )$ as the goal state. Starting from the current history $X _ { n } .$ , we sample candidate action sequences of planning horizon P with the cross-entropy method ${ \| { \tilde { 2 9 } } }$ (CEM) using the rollout in Eq. 4 and minimize

$$
\operatorname* { m i n } _ { \substack { a _ { n : n + P - 1 } } } \sum _ { j = 1 } ^ { P } \beta _ { j } \Vert \hat { z } _ { n , j } - z ^ { \star } \Vert _ { 2 } ^ { 2 } , \qquad \mathrm { s . t . ~ } \beta _ { j } \geq 0 , \quad \sum _ { j = 1 } ^ { P } \beta _ { j } = 1 ,\tag{12}
$$

subject to the environment’s action bounds. The controller executes a prefix of the selected plan and replans from newly observed data, using neither a learned reward model nor a state decoder.

## 3 Faithful dynamics modeling for continuous control

## 3.1 Experimental Setup

Environments and dataset collection. We evaluate world2vec on the Pendulum, Reacher, and Cartpole environments from the MuJoCo-based DeepMind Control Suite<sup>30</sup> (Fig. 2). We collect 200k RGB frames with 64×64 px resolution using random policies in each environment: uniform random actions for Reacher, and temporally correlated Ornstein–Uhlenbeck actions for Pendulum and Cartpole (details in Appendix D). For identifiability analysis, we construct a variant of this dataset with non-visual, non-linear observations.

tional and angular coordinates (but not velocities) are passed through a randomly initialized, injective MLP of varying depth and projected to 50 dimensions.

Model families and training. Encoders take a short sequence of $H = 3$ observations as input. A small vision transformer encodes each frame $( 1 6 \times 1 6$ patches, 2 layers of width 64 with 4 heads, and a keypoint readout) and is followed by an MLP head (2 hidden layers of 128 units) that maps the sequence of frame representations to the latent state. On nonlinear-mixing observations, we concatenate the observation sequence and pass it through an MLP encoder (3 hidden layers of 128 units). Dynamics models are MLPs with 3 hidden layers of 128 units. To model continuous-time dynamics, the MLP parametrizes the vector field <sup>ˆ</sup>f and Φ is one Euler step (Eq. 5). As a baseline close to existing JEPA-setups, we parameterize discrete-time dynamics by replacing the Euler step (Eq. 5) with $\bar { \Phi ( z , \pmb { a } ) } = \bar { \mathrm { M L P } } ( z , \bar { \pmb { a } } )$ , where the MLP directly predicts the next latent state. With a latent dimensionality of $d = 3 2$ , the main world2vec model has 263k parameters (221k for the encoder, 42k for the dynamics). All models are trained for 20k iterations with Adam using learning rate $1 0 ^ { - 3 }$ and cosine decay.

Model predictive control. We control the environments with model predictive control (MPC) in latent space without access to reward. Instead, we assume knowledge of an observation sequence that shows the desired target. We encode this sequence to obtain a goal latent that describes which part of the latent space the environment should be driven towards. For Pendulum and Cartpole, this is a sequence of frames that show the pole or pendulum upright at rest, with the cart centered. For Reacher, the target changes in every episode, and the goal is underspecified since two arm configurations place the fingertip on the target. We therefore compute, per episode, the arm configuration that places the fingertip on the target via inverse kinematics, render it, and use its encoding as the goal. Both possible elbow configurations are planned and the average between them is reported. We then sample candidate action sequences using the cross-entropy method<sup>29</sup> (CEM), predict future latent states with the dynamics model and rank them via their distance to the goal state (Eq. 12). We execute the first actions of the best sequence, observe the environment, and plan again. Because the continuous-time dynamics can be integrated with a different step size, it is possible to use different sampling rates for training and testing.

Implementation. We implemented world2vec in PyTorch. For the considered control tasks, small models with 64×64 px frame inputs are sufficient, while the framework allows encoders with larger inputs. Closed-loop control takes about 20–50 ms per control step, including simulation and rendering. Beyond empirical performance, this efficiency enables downstream applications in robotics and closed-loop experimental settings.

## 3.2 Results

World2vec faithfully models dynamics and enables long-range predictions and control. World2vec improves latent prediction substantially, enabling successful model predictive control in 2 of the 3 environments, none of which were solvable by the previous best JEPA-based approach, for which rewards remain low on all three tasks (Fig. 1B; Tab. 1; Fig. 3). Combining multistep prediction $( K \in [ 1 0 , 2 0 , 4 0 ] )$ with an Euler-integrated latent vector field raises 1-second LRC from 37–51% in our one-step baselines to 96–98%, and mean rewards from chance to 434–826 on Pendulum and 570–895 on Reacher (Tab. 1). At a 30-step horizon the same LRC comparison is 0% versus 73–86% (Fig. 3). The gains in rollout consistency are most noticeable for Pendulum and CartPole (Fig. 3), which have substantial intrinsic dynamics. Reward-based models attain high rewards on all three tasks but have poor latent prediction, except on Reacher (Fig. 1B, gray). As predicted by theory on linear identifiability<sup>31</sup>, our results also demonstrate that latent world models learn representations that remain consistent across training runs. World2vec and LeWM obtain an average consistency score of > 95% in contrast to 87.5% in TD-MPC2 and 43.4% in DreamerV3.

Model predictive control with world2vec solves the task in the Reacher and Pendulum environments (Tab. 1). World2vec-dcl outperforms DreamerV3 on both and TD-MPC2 on Reacher, and improves over LeWM by more than 800 points on each task. World2vecsigreg also solves both tasks with slightly lower reward. Due to the low reward of LeWM in this evaluation setup, we also benchmark its goal-reaching protocol on Reacher, where world2vec is on par for goals 25 steps ahead and clearly outperforms LeWM on longer term planning over 200 steps, while planning is 3-8 times faster (Tab. 2). A sufficiently large training horizon and latent dynamics matching are essential for latent world modeling. We next investigated the importance of the architectural innovations in world2vec. Compared to our baseline, world2vec uses a multi-step rollout as well as an ODE-formulation as its predictor. First, multi-step prediction is a crucial component across all environments. Increasing the training horizon drastically improves the model’s performance for both world2vec-dcl (Tab. 3a) and world2vec-sigreg (Tab. 3b). For world2vec-sigreg, increasing the horizon from 1 step to 20 steps improves the LRC from 59.3% to 90.2% for pendulum, from 61.5% to 98.7% for reacher, and from 0.0% to 86.4% for cartpole. Embedding geometry qualitatively reflects environment structure. As a qualitative assessment of the coordinates learned by world2vec, we visualized a PCA projection of the embeddings obtained on the Reacher environment in Fig. 4. This environment can be represented

through two angles $( \theta _ { 0 } , \theta _ { 1 } )$ that describe the current configuration of the two arms. While $\theta _ { 0 }$ is executing full 360 degree movements during data collection, $\theta _ { 1 }$ is constrained to rotating left and right relative to the first arm without observing full circular movements. This is reflected in the embedding, where $\theta _ { 0 }$ is encoded with circular boundaries, while $\theta _ { 1 }$ is represented linearly with open boundaries.

Continuous-time ODE parameterization allows flexible sampling. An important benefit of modeling state change through ODE dynamics is the possibility of adapting to a different sampling rate at inference time. As a demonstration, we train a world2vec model on Reacher at 10 Hz and use it for model predictive control at this rate, and at 50 Hz by reducing the step size of the Euler integrator accordingly (Fig. 5). Holding each action for two time steps gives a control rate of 25 Hz. The retimed controller performs at least as well as the native one (returns of 952 and 903).

Empirical identifiability of world2vec. Identifiable representation learning denotes the property where two models converge to the same representation. This property has been studied extensively in the context of representation learning and world models, and for the given objective, we expect that the representations derived from training will be consistent up to an affine transformation, and that dynamics will be modeled faithfully over time <sup>17,18,20</sup> as detailed in $\ S 2 ;$ note that we do not expect to recover the state linearly due to missing variability<sup>31</sup> along some dimensions in the considered (noiseless) systems. We focus our analysis on the CartPole environment, which was not solvable by any reward-free world model from raw observations. We study this environment in the setting from Gonzalez Laiz and Schneider <sup>8</sup>, where we replace pixel information by an increasingly non-linear mixing function, as detailed in the experimental setup. Under such a systematic increase in task difficulty, we observe a decline across the different metrics. LRC and EQA decline as the mixing depth increases, from about 90% and 75–85% at one mixing layer to 60–75% and 35–50% at five layers, while the one-step baselines collapse for two or more layers. World2vec-dcl degrades least, keeping an LRC above 75% at five layers (Fig. 6). Reward declines only slightly, from about 850 to 700, so both world2vec variants still solve CartPole from non-linearly mixed observations, whereas the baselines remain around 200–300. The gap between EQA in this task and under pixel observations is modest; we anticipate the possibility to transfer this result to pixel observations with additional improvements in the dynamics model estimation in future work.

## 4.2 Results

World2vec-SINDy outperforms the identity baseline and matches an MLP vector field. Across the latent state and dynamics recovery metrics, world2vec-SINDy substantially improves over the identity predictor and performs comparably to the MLP model (Fig. 7a). For latent process noise $\alpha = 0 . 1$ , we recover highly consistent ensembles across all three dynamics model families. For SINDy and MLP, this consistency is accompanied by high affine recovery $R ^ { 2 }$ for many of the 71 systems. Furthermore, for multiple systems, the SINDy and MLP rollouts agree with both the encoder’s future embeddings and the aligned ground-truth rollouts, as measured by $\mathrm { L R C _ { 5 0 } }$ and iDyn $R _ { 5 0 } ^ { 2 }$ (which measures the recovery of the dynamical system itself<sup>16</sup>).

Increasing process noise enables linear state recovery. Adding process noise to the ground truth states adds variations across all dimensions, which should enable linear recovery of the state information <sup>16,17</sup>. We empirically investigate this property across four noise levels, $\alpha \in \{ 0 , 0 . 1 , 0 . 5 , 1 . 0 \}$ showing medians and interquartile ranges (25th–75th percentiles) across systems for all four metrics (Fig. 7b). As α increases from 0 to 1.0, median affine recovery $\dot { R } ^ { 2 }$ rises from approximately 0.8 to 0.98 for MLP, from 0.7 to 0.97 for SINDy, and from 0.4 to 0.8 for the identity model which lines up with previous findings on latent dynamics learning<sup>16</sup>. Consistency is high across all models, but slightly increases until it reaches approximately 0.99 for all three models at $\alpha = 1 . 0$ . The process noise sets an upper limit on the LRC (optimal latent prediction is no longer possible), which decreases as noise increases. In cases where linear state discovery is obtained $( \alpha > 0 . 5 )$ the median iDyn $R _ { 5 0 } ^ { 2 }$ is a meaningful metric to measure the faithfulness of the dynamics in absence of LRC; indeed it approaches close to 100% for high noise levels, and substantially outperforms the identity baseline.

World2vec-SINDy can recover analytical equations of latent dynamics. Most relevant for mechanistic interpretability, unlike the “black-box” flow field of the MLP, the SINDy parameterization enables recovery of interpretable equations from the nonlinearly mixed high-dimensional observations. Among the ten systems with the highest validation LRC for SINDy, we visualize the system with the smallest mean pairwise Frobenius distance between aligned coefficient matrices. To express the recovered equations in the ground-truth coordinate basis, we estimate the affine indeterminacy via least-squares regression from the learned embeddings to the ground-truth states, transform the SINDy coefficient matrix accordingly, threshold coefficients at 0.1, and visualize the resulting equation (Fig. 7c). In future work, it would be interesting to extend these experiments with the unsupervised symbolic regression technique by Muratore and Mathis <sup>26</sup> and explore options to replace the fixed library with end-to-end learning of basis functions using tools from mechanistic interpretability<sup>34,35</sup>.

## 5 Conclusion

We introduced world2vec, a framework for learning mechanistic world models by jointly fitting representations and latent dynamics from observations. To the best of our knowledge, world2vec is the first reconstruction- and reward-free algorithm to jointly learn explicit dynamics and achieve successful control in environments with autonomous dynamics. This is enabled by combining multi step rollouts, latent dynamics matching, and model selection using metrics grounded in identifiability theory. Despite these advances, the environments considered remain relatively simple. We see improving and scaling data collection (potentially through online data collection), training across multiple environments, and studying the identifiability of our objective functions under less idealized conditions as promising directions for extending world2vec towards solving more complex tasks.

## A Training objectives

All world2vec models are trained via gradient descent to minimize Eq. 6. By default, we set the optional weighting factor $w _ { j }$ for the multi-step dynamics matching described in Eq. 6 to be uniform and normalized to $w _ { j } = 1 / \check { K }$ for a K-step rollout.

World2vec-sigreg and world2vec-dcl differ in their training objectives in the way they regularize the encoder model. Intuitively, choosing either one of these methods specifies a certain type of prior on how the embedding space is expected to be distributed. By choosing world2vec-sigreg, one specifies a Gaussian prior on the embedding space <sup>19</sup>, whereas choosing world2vec-dcl corresponds to specifying a Uniform distribution over the support of the dataset <sup>20,36</sup>. Other marginal distributions are possible<sup>16</sup> but not further considered here. Therefore, the choice of SIGReg vs. DCL is mainly a choice about which prior is better suited for the dataset/environment at hand.

World2vec-sigreg uses the SIGReg regularizer as in LeJEPA<sup>19</sup>, which pushes the distribution of embeddings towards an isotropic Gaussian $\mathcal { N } ( \mathbf { 0 } , \pmb { I } )$ . For a set of embeddings $\begin{array} { r } { \{ z _ { b } \} _ { b = 1 } ^ { B } , } \end{array}$ SIGReg projects them onto a set A of directions u drawn uniformly on the unit sphere and compares each one-dimensional projection with $\mathcal { N } ( 0 , 1 )$ using the Epps–Pulley test statistic,

$$
\mathrm { S I G R e g } \big ( \{ z _ { b } \} _ { b = 1 } ^ { B } \big ) = \frac { 1 } { | \mathcal { A } | } \sum _ { u \in \mathcal { A } } B \int _ { - \infty } ^ { \infty } w ( t ) \big | \hat { \varphi } _ { u } ( t ) - e ^ { - t ^ { 2 } / 2 } \big | ^ { 2 } d t , \qquad \hat { \varphi } _ { u } ( t ) = \frac { 1 } { B } \sum _ { b = 1 } ^ { B } e ^ { \mathrm { i } t u ^ { \top } z _ { b } } ,\tag{13}
$$

where $\hat { \varphi } _ { \pmb { u } }$ is the empirical characteristic function of the projections and $e ^ { - t ^ { 2 } / 2 }$ is the characteristic function of $\mathcal { N } ( 0 , 1 \bar { ) }$ . By the Cramér–Wold theorem, matching all one-dimensional projections matches the joint distribution. As in $\mathrm { L e W M } ^ { 1 2 }$ , SIGReg is applied to a batch of embeddings. With multi-step rollouts, each starting point contributes an embedding at every step $j = 0 , \ldots , K \colon$ : the embeddings at the starting state and at the K prediction targets. We apply SIGReg independently to the batch of embeddings at each step and average the results:

$$
\mathcal { R } _ { \mathrm { S I G } } ( { \bf h } ) = \frac { 1 } { K + 1 } \sum _ { j = 0 } ^ { K } \mathrm { S I G R e g } \big ( \{ { \bf h } ( X _ { n _ { b } + j } ) \} _ { b = 1 } ^ { B } \big ) ,\tag{14}
$$

where $n _ { 1 } , \ldots , n _ { B }$ are the starting points of a batch. The encodings at one step come from independent starting points, whereas encodings along one rollout are strongly correlated. As in the released implementations of LeJEPA and LeWM, we use the weight $w ( t ) = e ^ { - t ^ { 2 } / 2 }$ and evaluate the integral over [−3, 3] with the trapezoidal rule: since the integrand is even in t, it suffices to evaluate it at 17 equally spaced nodes on [0, 3] and double the result. We use $\vert \mathcal { A } \vert = 1 0 2 4$ directions (64 for nonlinear-mixing observations), resampled at every iteration. We select $\lambda \in \{ 0 . 0 1 , 0 . 1 , 1 \}$ for pixel observations and $\lambda \in \{ 0 . 0 0 1 , 0 . 0 1 \}$ for nonlinear-mixing observations on validation EQA.

World2vec-dcl is based on a variant of the contrastive regularizer used in DCL<sup>16</sup>. We additionally sample M negative samples $m _ { 1 } , \hdots , m _ { M } \sim p _ { D }$ uniformly across the training set (in practice, one set per batch, shared by all starting points) and measure how close the encoded starting state is to them,

$$
S _ { n } = \sum _ { i = 1 } ^ { M } e ^ { - \| \mathbf { h } ( \pmb { X } _ { n } ) - \mathbf { h } ( \pmb { X } _ { m _ { i } } ) \| _ { 2 } ^ { 2 } } .\tag{15}
$$

With the prediction error $d _ { n , j } = \| \hat { z } _ { n , j } - \mathbf { h } ( X _ { n + j } ) \| _ { 2 } ^ { 2 }$ from Eq. 6, the regularizer is

$$
\begin{array} { r l } & { { \mathcal { R } } _ { \mathrm { { D C L } } } ( { \bf h } , \hat { \bf f } ) = { \mathbb { E } } _ { n , m _ { 1 : M } } \left[ \displaystyle \sum _ { j = 1 } ^ { K } w _ { j } \log \left( e ^ { - d _ { n , j } } + S _ { n } \right) \right] } \\ & { \quad \quad \quad = \underbrace { { \mathbb { E } } _ { n , m _ { 1 : M } } \left[ \log S _ { n } \right] } _ { \mathrm { u n i f o r m i t y ~ ( e n c o d e r o n l y ) } } + \underbrace { { \mathbb { E } } _ { n , m _ { 1 : M } } \left[ \displaystyle \sum _ { j = 1 } ^ { K } w _ { j } \log \left( 1 + \frac { e ^ { - d _ { n , j } } } { S _ { n } } \right) \right] } _ { \ge 0 } , } \end{array}\tag{16}
$$

where the second line uses $\textstyle \sum _ { j } w _ { j } = 1$ . The first part depends only on the encoder and is the core of the regularizer. It is the uniformity term of contrastive learning <sup>37</sup>: it penalizes the encoded state for being close to the encoded negatives, most strongly to the nearest ones, thereby spreading the embeddings of different observations across the embedding space. This is how world2vec-dcl prevents collapse. In contrast to DCL, where the negatives are compared with the prediction of the dynamics model, we compare them with the encoded starting state. The uniformity term contributes no gradient to the dynamics model, and the prior towards a uniform embedding acts on the encoder alone. The second part compares each prediction error with the distances to the negatives. It keeps the objective bounded below, since each horizon contributes $d _ { n , j } + \log ( e ^ { - d _ { n , j } } + \bar { S } _ { n } ) \geq 0$ to Eq. 6; without it, scaling up the embedding could decrease the objective without bound. It is the only place where the dynamics model enters the regularizer, and it only rescales the gradient of the prediction term: the derivative of each horizon’s contribution with respect to $d _ { n , j } \mathrm { i s } 1 { - } \acute { e } ^ { - d _ { n , j } } / ( e ^ { - d _ { n , j } } \acute { + } S _ { n } ) \in ( 0 , 1 )$ . The dynamics model is thus always trained to reduce its prediction error. We use $M \in \{ 1 2 8 , 5 1 2$ , 1024} for pixel observations and $M = 1 0 2 4$ for nonlinear-mixing observations.

## B Metrics

Latent Rollout Consistency (LRC). Following Gonzalez Laiz and Schneider <sup>8</sup>, LRC measures the agreement of the encoder and dynamics models in an unsupervised way. Given a sequence of observations $\{ \boldsymbol { x } _ { t } \} _ { t = 0 } ^ { T } .$ , we encode this sequence into latent space using the encoder ${ \boldsymbol z } _ { t } = { \bf h } ( { \boldsymbol x } _ { t } )$ . The latent dynamics model predicts $\hat { z } _ { t + k } = \Phi ^ { k } ( z _ { t } )$ and we compute the LRC for horizon k as the score between $z _ { t + k }$ and $\hat { z } _ { t + k }$

Evaluation pipelines. Table 1 and STabs. 1 and 4 use a separate evaluation pipeline shared with all baselines; the ablations in Tabs. 3 and 4 use our world2vec training pipeline. The latter averages the $\mathrm { L R C } ~ \dot { R } ^ { 2 }$ uniformly over latent dimensions instead of weighting by variance, and evaluates the 8.3 Hz Reacher models on the 8.3 Hz test split instead of every third frame of the 25 Hz test split with averaged actions. LRC, and EQA for Reacher at 8.3 Hz, should therefore be compared within a table.

Equivariance Accuracy (EQA) . Following Schmidt et al. <sup>24</sup> , EQA is a retrieval-based extension of LRC. It measures how well we can recover a future observation via KNN decoding in an unsupervised way. We encode a sequence of observations; we predict the future latents $\hat { z } _ { t + k }$ but then we do a KNN lookup to identify the embedding in latent space that is closest to $\hat { z } _ { t + k }$ . To be able to do this, we randomly sample $N = 5 1 2$ observations from the training dataset, we add the observations $\{ \pmb { x } _ { t } \} _ { t = 0 } ^ { T }$ we compute our metric on to the pool of candidates. We encode these into latent space, find the closest latent, compute a Top-k accuracy score on this classification task, and report Top-1 accuracy.

Embedding Consistency (Cons.) measures how well multiple models (different seeds) trained on the same data agree with each other. This is done by taking the same set of observations, encoding them into latent space with each model $Z ^ { ( k ) } = \dot { \mathbf { h } _ { k } } ( X )$ . Then we fit a linear regression to map $Z ^ { ( i ) } \to Z ^ { ( j ) }$ for every $i , j \in [ 1 , . . . , K ]$ , we score how well each of those mappings works via $R ^ { 2 }$ and average these scores to arrive at the embedding consistency score.

Cumulative Reward measures how well a model performs in solving a given task. We use the reward as measured by the MuJoCo-based DeepMind control environments: Pendulum (swingup), Reacher (hard), Cartpole (swingup). We set episode length and control rate to a) match the setup for LeWM as used in Maes et al. <sup>12</sup> and b) constrain per-episode reward to be within 0 and 1000 as maximum cumulative episode reward.

State Decoding measures how well we can decode the state provided by the environment. We split the validation dataset into two parts: one to train a decoder (Linear Regression or MLP decoder) and the second part on which we evaluate these.

Identifiable Latents $R ^ { 2 } ( \mathbf { i L a t } R ^ { 2 } )$ measures how well the encoder recovers the true latent representation up to an affine transform. This is the metric as it is proposed and used in $\mathrm { D C L } ^ { 1 6 }$ and corresponds to state decoding via an affine map (linear regression).

Identifiable Dynamics $R ^ { 2 } ( \mathbf { i D y n } R ^ { 2 } )$ measures how well the recovered dynamics model aligns with the ground truth latent dynamics models. This metric corresponds to the $\mathsf { \bar { \cdots } D y n } R ^ { 2 } \mathsf { \ " }$ metric proposed for DCL<sup>16</sup> at horizon k. As part of this metric, we fit an affine map from the encoder’s embeddings into the ground truth latent space. The same map as the Identifiable Latents $R ^ { 2 }$ metric uses. However, instead of scoring the embeddings, we score how well future embeddings align with the ground truth dynamics.

## E Baselines

We reproduced TD-MPC2 (ref. 11), DreamerV3 (ref. 9) and LeWM<sup>12</sup> from the authors’ implementations and default configurations (four seeds each). TD-MPC2 and DreamerV3 use 64×64 frames, learn online for up to one million environment steps with their original optimisation settings and no per-task tuning, and are evaluated with their learned controllers.

LeWM uses 224×224 frames, rendered at this resolution, with a three-frame context. We keep the original LeWM configuration, including a frameskip of 5, so that on 25 Hz data the model runs at 5 Hz. On Pendulum and CartPole, LeWM is trained on the same datasets as world2vec (Appendix D). On Reacher, we train two versions. LeWM (original data) uses the dataset released with LeWM, collected with random actions at an action repeat of 2 (25 Hz) without the target rendered<sup>12</sup>. LeWM (our data) uses our 25 Hz Reacher dataset. Both share the same model step. LeWM is trained for 40 epochs with the SIGReg weight selected per environment (0.001 for CartPole, 0.1 for Pendulum and Reacher), and is controlled with its own CEM planner. Rewards are the sum of the native rewards over 500-step episodes. Tables 1 and 2 use LeWM (original data) for Reacher, and STab. 4 compares both versions.

All baselines are evaluated on the test episodes of our datasets. For LeWM (original data), this is a shift away from its training distribution, which explains its low LRC and EQA on Reacher.

Rollout metrics and planning decouple for LeWM. Trained on the same Reacher data as world2vec, LeWM (our data) reaches a 1 s LRC of 95.2% and an EQA of 85.6%, yet obtains a reward of 21 and reaches only 14.7% of goals 25 steps ahead (STab. 4). Since both LeWM versions share similar data-collection policy, model step and configuration, we attribute this gap to generalization: LRC and EQA are measured on held-out random-action episodes, whereas CEM evaluates action sequences and reaches states that are rare in this distribution, where the predictor can extrapolate poorly. Conversely, LeWM (original data) transfers poorly to our test split (LRC 0.0%) but plans better under the original protocol (81.6% success). For world2vec, rollout metrics and planning agree, which we hypothesize is due to the vector-field parameterization and multi-step training.

## F Experimental Details: Symbolic Regression with world2vec

Datasets. The learned latent dynamics are evaluated on 71 systems from the dysts collection $^ { 3 2 }$ . For each system, we generate 1,000 ground-truth trajectories of 1,000 steps using a fourth-order Runge– Kutta (RK4) integrator with a step size $\Delta t _ { s }$ equal to ten times the system-specific value defined by $\mathrm { G i l p i n } ^ { 3 2 }$ . To choose the initial conditions, we first simulate a noise-free, 1,000-step reference trajectory from the system’s canonical initial state, then discard the first 100 states, determine the minimum and maximum values reached by each state coordinate over the remaining trajectory, and draw each coordinate of a new initial condition uniformly between these bounds. Trajectories containing nonfinite states or exceeding $1 0 ^ { 6 }$ in absolute value are resampled. After each RK4 step, independent Gaussian noise is added to the simulated physical state: $\pmb { s } _ { t + 1 } = \pmb { \Phi } _ { \mathrm { R K 4 } } ( \pmb { s } _ { t } ) + \pmb { \epsilon } _ { t }$ . For state variable $i \in \{ 1 , \ldots , d \}$ , the noise has standard deviation $\alpha \sigma _ { s , i } \sqrt { \Delta t _ { s } / T _ { s } }$ , where $\sigma _ { s , i }$ is that variable’s attractor standard deviation reported in the dysts metadata and $T _ { s }$ is the system’s reference period. We use $\alpha \in \{ 0 , 0 . 1 , 0 . 5 , 1 . 0 \}$ , with $\alpha = 0$ giving noise-free trajectories. This is followed by applying a fixed, injective mixing function $\mathbf { g } : \mathbb { R } ^ { d }  \mathbb { R } ^ { n }$ to the true latent trajectory $\pmb { s } \in \mathbb { R } ^ { d }$ , yielding observed time series $\pmb { x } = \mathbf { g } ( \pmb { s } ) \in \mathbb { R } ^ { n }$ . Following Zimmermann et $\mathrm { a l . } ^ { 2 0 }$ , the mixing function consists of a fixed four-layer MLP followed by a linear projection to $n = 5 0$ dimensions. Entire trajectories are assigned to training, validation, and test sets in a 70:15:15 ratio. All models use a three-layer MLP encoder with 128 hidden units, trained with the one-step world2vec objective.

Models. Three dynamics models are evaluated on the generated datasets. Identity dynamics provide a baseline without a learned dynamics model: $\hat { z } _ { t + 1 } = z _ { t }$ . The MLP dynamics model parameterizes a continuous-time flow field, $\dot { \pmb z } = \hat { \mathbf { f } } ^ { \mathrm { M L P } } ( \pmb z )$ , whose one-step prediction is obtained by RK4 integration. Finally, the SINDy model represents the flow field as $\dot { z } = \Xi \theta ( z )$ , where $\pmb \theta ( \boldsymbol z ) \in \mathbb R ^ { p }$ contains all monomials of z up to degree $q ,$ including the constant, with the dysts system-specific maximum degree $q \in \{ 2 , 3 \}$ being assumed to be known, and $\Xi \in \mathbb { R } ^ { d \times p }$ is a sparse coefficient matrix whose $k \mathrm { - }$ th row gives the governing equation of $z _ { k }$ . Finally, an $L _ { 1 }$ penalty, $\lambda _ { \mathrm { S I N D y } } \Vert \Xi \Vert _ { 1 }$ with $\lambda _ { \mathrm { S I N D y } } = 1 0 ^ { - 5 }$ encourages sparse coefficients, and (unlike for other SINDy implementations $^ { 2 5 , 2 7 , 2 8 } )$ ), no coefficient thresholding is applied during training. All models are trained for 10,000 iterations, and we tune only the weight of the DCL Regularizer (Appendix A) over a grid of $\lambda \in \{ 0 . 0 1 , 0 . 1 , 0 . 5 , 1 . 0 \}$ (Eq. 6). During analysis, for all systems, (except for the qualitative rollout plots), we select the ensemble across uniformity weights that has the highest mean $\mathrm { L R C _ { 5 0 } }$ on the validation set and then report the results on the validation set.

Evaluation. The performance of the resulting models is assessed across four metrics. Affine recovery $R ^ { 2 }$ measures how well the physical state can be recovered from the learned representation. Consistency quantifies mean pairwise affine agreement between representations learned from three different model seeds. $\mathrm { i D y n } \dot { R } _ { 5 0 } ^ { 2 }$ compares ground-truth and learned 50-step rollouts after affine alignment, while $\mathrm { L R C _ { 5 0 } }$ compares learned rollouts with encodings of the observed future.

Symbolic regression. For qualitative inspection of rollouts and recovered equations in Fig. 7, we first rank the recovered SINDy systems by $\mathrm { L R C _ { 5 0 } }$ and retain only the top ten systems. Among these, we select the system whose learned SINDy models are most consistent across seeds. Because each seed learns its own latent coordinate system, we first express all three SINDy models in a common space, choosing the seed r with the highest validation $\mathrm { L R C _ { 5 0 } }$ as the reference. For each seed $j \neq r ,$ we fit the affine transformation $z ^ { ( r ) } \approx L _ { j  r } z ^ { ( j ) } + b _ { j  r }$ by least squares on paired embeddings. Since $\dot { z } ^ { ( r ) } = L _ { j  r } \dot { z } ^ { ( j ) }$ , the SINDy coefficient matrix learned by seed $j$ becomes $\Xi _ { j  r } = { \cal L } _ { j  r } \Xi _ { j } M _ { j  r }$ in the reference coordinates, where $M _ { i \to r } \in \mathbb { R } ^ { p \times p }$ describes how the polynomial features transform under the affine coordinate change $^ { 2 6 } , \theta \big ( L _ { j  r } ^ { - 1 } ( z ^ { ( r ) } - b _ { j  r } ) \big ) = M _ { j  r } \theta ( z ^ { ( r ) } )$ . The reference model remains unchanged, $\Xi _ { r  r } = \Xi _ { r }$ . Once all three models are expressed in the same coordinate system, we quantify their agreement using the mean pairwise Frobenius distance between their coefficient matrices, $\begin{array} { r } { D = \frac { 1 } { 3 } \sum _ { 1 < j < k < 3 } \| \mathbf { \bar { E } } _ { j  r } - \boldsymbol { \Xi } _ { k  r } \| _ { F } . } \end{array}$ Among the candidate systems, we select the one with the smallest $D _ { : }$ , corresponding to the SINDy models with the highest agreement across seeds. Importantly, both the alignment and the coefficient-distance criterion depend only on the learned embeddings and the learned SINDy coefficients and therefore do not require access to the ground-truth latent states or dynamics.
